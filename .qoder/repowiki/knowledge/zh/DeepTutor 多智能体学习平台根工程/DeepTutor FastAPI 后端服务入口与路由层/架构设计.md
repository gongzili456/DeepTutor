模块以 `main.py` 中的 `FastAPI` 实例为唯一进程入口：通过 `asynccontextmanager` 定义的 `lifespan(app)` 在启动时依次初始化 LLM 客户端、EventBus、Partner Manager、Cron、PocketBase 连接并执行 v1→v2 记忆迁移，关闭时按相反顺序释放 MCP、LLM 池、Agentic 池等资源；每个外部依赖的初始化/停止均用 try/except 包裹并以 warning 记录失败，保证单组件异常不阻断整体启停。

路由按领域拆分为 `routers/` 下的独立模块（chat、auth、knowledge、sessions、tools、mcp_settings、voice、unified_ws、quiz_judge 等），每个模块暴露一个 `router = APIRouter()`，由 `main.py` 统一 `include_router` 并挂载到 `/api/v1/<domain>` 前缀；`auth`、`outputs`、`attachments` 使用独立前缀，`settings.public_router` 先于受保护路由注册以提供无鉴权的 UI 设置读取。

鉴权边界集中在 `routers/auth.py`：HTTP 端点通过 `dependencies=[Depends(require_auth)]`（或叠加 `require_admin`）实现，WebSocket 因 FastAPI 不支持 WS 依赖而在处理器内调用 `ws_require_auth` / `ws_require_auth_failed` 完成鉴权。

静态输出文件通过自定义 `SafeOutputStaticFiles` 白名单校验后挂载到 `/api/outputs`，防止路径穿越；CORS 根据 `AUTH_ENABLED` 动态切换严格模式（仅允许配置的 origin）与宽松模式（允许任意 HTTPS origin）。

`utils/` 提供跨路由共享的基础设施：`progress_broadcaster` 按 KB 名广播进度、`task_id_manager` 与 `task_log_stream` 管理任务 ID 与日志流、`tool_options` 封装工具参数解析。

依赖方向单向向下：API 层仅依赖 `deeptutor.services.*`、`deeptutor.agents.*`、`deeptutor.multi_user.*` 等业务层，不被业务模块反向引用。

`run_server.py` 作为 uvicorn 启动脚本，处理 Windows 事件循环切换至 `WindowsProactorEventLoopPolicy`、从运行时配置读取端口、配置开发热重载排除目录以及传入 WS 最大帧大小。
