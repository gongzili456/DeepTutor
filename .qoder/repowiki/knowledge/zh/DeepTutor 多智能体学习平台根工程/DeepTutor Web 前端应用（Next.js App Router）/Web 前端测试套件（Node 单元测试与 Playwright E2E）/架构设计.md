测试按运行方式分层组织：根目录下每个 `*.test.ts` 文件对应一个被测模块或特性，通过 `import` 直接引入 `../lib/*`、`@/components/*` 等源码进行单元测试；`e2e/` 子目录集中存放基于 Playwright 的浏览器级审计用例（如可访问性、错误提示），依赖 `WEB_BASE_URL` / `NEXT_PUBLIC_API_BASE` 环境变量定位目标站点；`fixtures/` 提供 JSON 格式的共享测试数据（如 provider trace events）。测试不依赖 React 渲染环境，仅对纯函数、状态机、API 契约及页面 DOM 行为断言，从而保证快速、稳定的 CI 执行。
