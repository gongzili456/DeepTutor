模块采用“类型 + API 层 + UI 组件”三层结构：`types.ts` 定义 `GrantPayload`（用户授权载荷）与 `MultiUserResources`（管理员可分配的可用资源集合），作为前后端契约；`api.ts` 封装对 `/api/v1/multi-user/admin/resources` 和 `/api/v1/multi-user/users/{userId}/grants` 的 GET/PUT 请求，统一通过 `@/lib/api` 的 `apiFetch`/`apiUrl` 发起并解析错误；`components/GrantEditor.tsx` 是唯一的 React 客户端组件（标记 `use client`），在 `useEffect` 中并发拉取资源与当前用户授权，使用 `structuredClone` 进行不可变更新，并通过 JSON 指纹比较实现未保存变更状态提示。UI 以三列网格组织 Models/Knowledge/Skills/Partners/System tools/MCP tools/Code execution 等授权维度，其中 System tools 与 MCP tools 共用 `ModeSwitch` 支持 Default/Custom 双模式切换，MCP 工具列表复用 `@/components/common/McpToolGroups` 组件进行分组勾选。依赖方向单向：组件 → api → 共享 lib，不反向引用。
