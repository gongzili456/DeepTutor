模块基于 Next.js App Router 的 `(workspace)` 路由组组织三个页面：`page.tsx` 列出所有合作伙伴并按 `useAuthStatus()` 区分管理员（可创建/管理）与普通用户（仅查看并自动连接子代理后跳转 `/home?agent=...`）；`[partnerId]/page.tsx` 是动态详情页，通过 `Suspense` 包裹内部组件以支持流式加载，使用本地 `tab` 状态在 Chat / Configure / Channels / Archive 四个标签间切换，其中 Chat 标签始终挂载以保持 WebSocket 与实时 trace 存活；`new/page.tsx` 实现五步向导（Identity → Soul → Mind → Library → Review），集中维护表单状态并在最后一步调用 `createPartner` 后跳转到对应详情页。页面通过 `@/lib/partners-api`、`@/lib/subagents-api`、`@/lib/chat-export`、`@/lib/partner-session` 等库与后端交互，UI 复用 `@/components/partners/*`（PartnerAvatar、PartnerChat、PartnerChannels、PartnerConfigure、PartnerArchives、SoulPicker、ToolPicker、AssetPicker、FaceEditor 等）以及 `@/components/notebook/SaveToNotebookModal` 完成导出到笔记本功能。依赖方向单向：页面 → 业务 API 库 → 共享 UI 组件，不反向引用。
