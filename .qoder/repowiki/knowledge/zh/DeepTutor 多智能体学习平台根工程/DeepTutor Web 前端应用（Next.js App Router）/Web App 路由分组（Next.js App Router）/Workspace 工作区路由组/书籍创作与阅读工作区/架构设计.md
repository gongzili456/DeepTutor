模块以 `page.tsx` 作为单一客户端入口（"use client"），通过内部 `view` 状态在 list/creator/spine/reader 四种视图间切换，集中管理 Book、Page、Block、Spine、进度等全局状态，并通过 `bookApi` 与 WebSocket 事件（`reduceBookEvent` + `BookProgressTimeline`）驱动长任务进度。
- 顶层编排：`page.tsx` 负责路由选择、数据加载（`refreshBooks`/`loadBookDetail`）、深链跳转（`?book=`）、WebSocket 事件分发以及各子组件回调桥接。
- 子组件按职责分层：`components/` 下为页面级组件（`BookCreator`、`SpineEditor`、`PageReader`、`BookSidebar`、`BookLibrary`、`BookChatPanel`、`BookHealthBanner`、`BookProgressTimeline`、`PageOutlineNav`），`components/blocks/` 下为可插拔的内容块实现。
- 内容渲染采用策略模式：`BlockRenderer.tsx` 根据 `block.type` 分派到对应 Block 组件（text/callout/quiz/code/timeline/flash_cards/figure/interactive/animation/deep_dive/concept_graph/section/placeholder），新增块类型只需新增文件并加入 switch 与 `INSERTABLE_TYPES`/`CHANGEABLE_TYPES` 白名单。
- 数据契约集中在 `@/lib/book-types`，API 调用集中在 `@/lib/book-api`，进度归约在 `@/lib/book-progress`；本模块仅消费这些共享库，不直接访问后端。
- 依赖方向单向：page → components → blocks → 共享 lib；blocks 之间无相互引用，仅通过 props 与父级回调通信。
