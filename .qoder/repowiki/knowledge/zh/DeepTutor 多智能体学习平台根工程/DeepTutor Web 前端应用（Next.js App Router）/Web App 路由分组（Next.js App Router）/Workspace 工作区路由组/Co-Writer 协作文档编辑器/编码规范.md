- 所有页面组件声明为 Client Component（文件首行 `"use client"`），并通过 `useRouter` 进行导航。
- 异步副作用统一使用 `useCallback` + `useEffect` 组合，并以 `isUnmountedRef` / `cancelled` 标志防止卸载后 setState。
- 错误处理遵循 `err instanceof Error ? err.message : String(err)` 的归一化模式，再设置统一的 `error` state 展示。
- 用户偏好（分割比例、滚动同步开关）通过固定 key 前缀（如 `deeptutor.co_writer.*`）读写 `window.localStorage`。
- 草稿与自动保存通过 `ref` 追踪上一次已保存内容，仅在 `markdown !== lastSavedContentRef.current` 时触发防抖保存。
- 对用户的破坏性操作（清空、替换模板、删除草稿）采用二次确认模式：先设置 `pending*` state，再在 UI 中显示确认按钮。
