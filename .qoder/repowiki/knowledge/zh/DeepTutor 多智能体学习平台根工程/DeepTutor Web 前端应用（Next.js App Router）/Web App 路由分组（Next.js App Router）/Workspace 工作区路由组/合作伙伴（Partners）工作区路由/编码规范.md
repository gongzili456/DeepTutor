- 每个页面文件顶部以 "use client" 指令声明为客户端组件，并通过 `useTranslation` 进行文案国际化。
- 异步数据加载统一采用 `useState` + `useEffect` + `useCallback` 模式，配合 loading/busy 状态与 `Loader2` 旋转图标展示加载中。
- 错误与操作反馈通过本地 `toast` 状态 + 超时清除函数显示，而非全局通知库。
- 详情页使用本地 `tab` 字符串状态驱动多标签渲染，并通过 `Suspense` 包裹以支持流式加载占位。
- 导航与路由跳转统一通过 `next/navigation` 的 `useRouter().push` 完成，参数使用 `encodeURIComponent` 编码。
- 管理员/普通用户的差异化行为通过 `useAuthStatus()` 的 `isAdmin` 字段在渲染与事件处理中分支，而非拆分子页面。
