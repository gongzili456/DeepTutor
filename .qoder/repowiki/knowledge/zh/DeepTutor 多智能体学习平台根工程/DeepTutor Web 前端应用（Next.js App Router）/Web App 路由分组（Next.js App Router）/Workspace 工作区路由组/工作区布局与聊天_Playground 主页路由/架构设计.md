本模块由三部分构成：
- `layout.tsx`：作为 `(workspace)` 路由组的共享布局，通过 `AppShell` 包裹 `WorkspaceSidebar`，并以 `CapabilityAccessProvider`、`UnifiedChatProvider`、`CapabilityGate` 三层 Provider/Guard 嵌套，为所有子路由提供统一的能力访问控制与聊天上下文。
- `playground/page.tsx`：一个独立的“能力调试器”客户端页面，内置 `ToolExecutor`、`TracePanel`、`DeepQuestionTester`、`CapabilityResultPanel` 等组件，直接调用 `/api/v1/plugins/tools/{tool}/execute-stream` 与 `/api/v1/plugins/capabilities/{cap}/execute-stream` 的 SSE 流式接口，并通过 `@/lib/playground-config` 动态加载后端注册的能力/工具元数据来渲染表单。
- `home/[[...sessionId]]/page.tsx`：主聊天会话页，使用 Next.js 动态路由 `[...sessionId]` 支持新建会话与历史会话切换；通过 `useUnifiedChat` 管理消息、分支、LLM 选择、工具开关等全局状态，右侧以 `SessionViewerPanel` + `FilePreviewDrawer` 提供活动面板与文件预览；能力配置（Quiz/Visualize/Research）通过 `dynamic()` 懒加载对应面板并持久化到 localStorage。
依赖方向单向向下：页面 → `@/context/*` 状态/Provider → `@/components/*` 展示组件 → `@/lib/*` API/类型工具；不反向引用其他路由。
