本模块以 Next.js App Router 的路由组（带括号的目录名）作为核心组织方式：
- (auth) 提供无外壳的登录/注册页，独立于业务路由；
- (workspace) 承载 book、co-writer、partners、playground、home 等核心功能，共享 workspace 布局与侧边栏上下文；
- (utility) 聚合 agents、knowledge、memory、notebook、profile、settings、space 等与主聊天无关的工具型页面，复用 utility 布局；
- (admin) 隔离后台管理（如 admin/users），与用户端路由解耦。
所有路由组共用 web/app/layout.tsx 作为根布局（注入全局 CSS、Provider 等），各子路由组再在其下叠加自身 layout.tsx 形成嵌套外壳。路由之间不直接互相引用，而是通过 Next.js 内置的客户端导航与共享的 store/context（位于路由组之外）进行状态通信，从而实现功能域之间的松耦合。
