模块采用 Next.js App Router 的路由组 `(auth)` 结构：`layout.tsx` 作为共享布局，使用 CSS 变量（`--background`、`--foreground`、`--card`、`--border`、`--primary` 等）实现主题化居中卡片；`login/page.tsx` 与 `register/page.tsx` 各自为客户端组件（`"use client"`），通过 `next/navigation` 的 `useRouter`、`useSearchParams` 处理导航与查询参数（如 `next`、`registered`）。两个页面均依赖 `@/lib/auth` 中的 `login`、`register`、`fetchAuthStatus`、`checkIsFirstUser` 等函数完成鉴权逻辑，并在已登录或首用户场景下自动重定向到目标页或注册页。登录页通过 `Suspense` 包裹内容以支持流式加载，注册页在提交前进行密码一致性校验。
