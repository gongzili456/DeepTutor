- 每个页面顶部声明 `"use client"`，将表单交互与路由跳转放在客户端组件中执行。
- 所有用户可见文案通过 `react-i18next` 的 `t()` 函数包裹，避免硬编码字符串。
- 表单状态统一使用 `useState` 管理输入值、错误信息、加载状态，并通过 `handleSubmit` 内调用 `@/lib/auth` 对应 API 后根据 `result.ok` 分支处理成功/失败。
- 页面进入时通过 `useEffect` 调用 `fetchAuthStatus` 检查已登录状态并 `router.replace` 到目标路径，防止重复访问认证页。
- UI 样式全部基于 Tailwind 类名配合 CSS 变量（如 `bg-[var(--background)]`、`text-[var(--foreground)]`、`focus:ring-[var(--primary)]`），不直接写颜色字面量。
- 登录/注册页面采用一致的卡片布局结构：标题区 + 可选提示条 + 表单卡片 + 底部互链 + 品牌标语。
