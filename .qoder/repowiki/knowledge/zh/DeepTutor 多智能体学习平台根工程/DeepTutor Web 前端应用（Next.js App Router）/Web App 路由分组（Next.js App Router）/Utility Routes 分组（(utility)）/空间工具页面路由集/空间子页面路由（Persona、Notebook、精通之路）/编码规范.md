- 路由页作为薄壳：仅负责 import 对应 Section 组件并 return 它，业务逻辑下沉到 `@/components/space/*` 或 `@/lib/learning-api`。
- 前端文案统一通过 `useTranslation()` 配合 `tr(cn, en)` 工具函数进行中英双语切换，避免硬编码字符串。
- 异步数据加载使用 `useState` + `useCallback` + `useEffect` 组合，并通过 `loadingList`/`loadingDetail` 双态区分列表与详情的加载 UI。
- 危险操作（删除、重置进度）在发起请求前先以 `window.confirm` 弹窗二次确认，再调用对应的 mutation API。
