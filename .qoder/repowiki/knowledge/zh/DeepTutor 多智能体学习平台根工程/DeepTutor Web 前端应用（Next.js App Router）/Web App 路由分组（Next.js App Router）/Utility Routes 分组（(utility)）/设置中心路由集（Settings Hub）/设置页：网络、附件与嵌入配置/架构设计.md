模块由三个独立的 Next.js Route Handler 页面组成（`network/page.tsx`、`attachments/page.tsx`、`embedding/page.tsx`），均位于 `(utility)/settings/` 路由组下，作为客户端组件（`"use client"`）渲染。
- `network/page.tsx`：通过 `apiFetch(apiUrl("/api/v1/settings/network"))` 拉取并 PUT 保存后端端口、前端端口、公共 API base 和 CORS 来源；内嵌 `ChatResponseTimeoutSection` 子组件单独调用 `/api/v1/settings/chat-response-timeout` 调整聊天超时，并通过 `registerExtension('chat-timeout', ...)` 注册到全局 Settings 工具栏的 Apply 流程。
- `attachments/page.tsx`：通过 `/api/v1/settings/chat-attachments` 读写单文件大小、消息总大小、每文档/每消息字符上限等字段，使用服务端返回的 `bounds` 约束输入范围，并以 `registerExtension('chat-attachments', ...)` 接入全局保存。
- `embedding/page.tsx`：最薄的一层，仅展示 `SettingsPageHeader` 并委托给共享组件 `ServiceConfigEditor`（`service="embedding"`）完成通用服务配置编辑。
依赖方向单向向外：页面 → `@/components/settings/shared`（SettingRow/SettingSection/Header）、`@/components/settings/SettingsContext`（全局 dirty/save 扩展点）、`@/lib/api`（HTTP 封装），不互相引用。
