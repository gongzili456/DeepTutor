本模块由 Next.js App Router 的 `(utility)/settings` 路由组下的三个独立 `page.tsx` 组成，各自承担单一职责：
- `mcp/page.tsx`：纯重定向组件，使用 `next/navigation` 的 `redirect("/space/mcp")` 将旧版设置入口迁移到 Learning Space 的 MCP 管理页，保留书签兼容性。
- `tools/page.tsx`：客户端组件，通过 `apiFetch(apiUrl("/api/v1/tools"))` 拉取内置工具清单与已启用工具集合，按 `toggleable` / `coming_soon` / `capability` 字段分组为“体验增强”“内置工具”“能力工具”三段展示；切换时乐观更新本地 `enabled` 状态并调用 `PUT /api/v1/settings/enabled-tools` 持久化，成功后调用 `invalidateEnabledOptionalToolsCache()` 使其他页面共享缓存失效。
- `capabilities/page.tsx`：客户端组件，通过 `GET/PUT /api/v1/capabilities/settings` 读写按能力（chat/solve/research/question/co_writer/vision_solver/math_animator）组织的 LLM 参数；使用 `serverSnapshot` + JSON 比较计算 `dirty`，并通过 `useSettings().registerExtension("capabilities", { dirty, save })` 将保存逻辑注册到全局设置栏；对后端返回的 DTO 用 `isValidCapabilitiesDTO` 做运行时结构校验。
依赖方向单向指向 `@/lib/api`、`@/components/settings/shared` 和 `@/components/settings/SettingsContext`，不反向引用父级路由。
