Document Parsing 页面依赖后端 `/api/v1/settings/document-parsing`（GET/PUT）、`/api/v1/settings/document-parsing/install`（POST 触发 pip 安装）、`/api/v1/settings/document-parsing/models/download`（POST 触发模型权重下载）以及 `/api/v1/settings/document-parsing/job/status?cursor=...`（轮询日志）和 `/api/v1/settings/document-parsing/job/cancel`（取消任务）。
