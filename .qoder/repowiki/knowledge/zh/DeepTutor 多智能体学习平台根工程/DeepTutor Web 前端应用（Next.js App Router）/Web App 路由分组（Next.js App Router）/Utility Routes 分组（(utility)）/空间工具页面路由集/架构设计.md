本模块作为 Next.js App Router 的 (utility)/space 路由组，由 layout.tsx 提供统一的 SpaceMain 布局容器，page.tsx 作为空间首页直接渲染 SpaceDashboard；各子目录（chat-history、questions、skills、personas、notebooks、learning、cli-apps、mcp）各自独立实现一个 page.tsx 页面组件，所有页面均复用同一布局壳层，形成“单一布局 + 多页面”的扁平路由结构。子页面之间不直接通信，仅通过共享的 @/components/space/* 组件进行 UI 复用。
