该模块以 Next.js App Router 的路由组 `(utility)` 作为命名空间隔离，所有子目录均为独立功能域：agents/knowledge/notebook/profile 提供轻量工具页；memory 通过 layout.tsx 提供记忆工作区的统一壳并承载 L1/L2/L3 及 graph/resolve 子路由；settings 以 layout.tsx + SettingsProvider 聚合二十余个配置子页面；space 以 SpaceMain 布局聚合空间级工具。各子模块之间不直接互相引用，仅通过共享的 `@/components` UI 库、`@/lib` 工具以及各自 layout.tsx 提供的上下文（如 SettingsProvider、SpaceMain）完成跨页面状态共享，整体构成一个与主聊天路由并列的“辅助能力”路由树。
