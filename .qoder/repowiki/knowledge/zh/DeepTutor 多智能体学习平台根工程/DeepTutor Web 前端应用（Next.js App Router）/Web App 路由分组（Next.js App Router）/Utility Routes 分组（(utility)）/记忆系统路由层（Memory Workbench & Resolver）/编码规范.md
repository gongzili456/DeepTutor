- 所有客户端路由页在顶部声明 `"use client"`，并将使用 `useSearchParams`/`useParams` 的逻辑抽到 `Inner` 函数中以适配 App Router 的 Suspense 边界。
- 动态路由段（`[surface]`、`[slot]`）配合模块级常量白名单数组进行校验，非法值调用 `notFound()` 返回 404。
- 深度链接通过 URL query 参数传递：L1 使用 `?ref=...&?surface=...` 双格式兼容，L2/L3 使用 `?focus=<entry_id>` 触发滚动高亮。
- 路由页本身保持极简，仅做参数解析与 props 透传，UI 渲染完全委托给 `@/components/memory/*` 中的工作区组件。
