- 设置项统一通过 `useSettings()` 解构状态与对应的 `updateXxx` 方法，避免在页面内维护本地副本状态。
- UI 结构采用 `SettingSection` 包裹多个 `SettingRow`，标题与描述均通过 `t(...)` 进行 i18n 翻译。
- 可选值列表（如语言、主题、代码块主题）以常量数组形式声明，再 `.map` 渲染为按钮或 `<option>`，选中态通过 CSS class 条件切换。
- 需要富交互的第三方组件（如 `RichCodeBlock`）通过 `next/dynamic` 配合 `{ ssr: false }` 懒加载，避免服务端渲染开销。
- 对已废弃的路由（如 `/settings/status`）采用 `next/navigation` 的 `redirect` 进行服务端跳转，而非返回空白页面。
