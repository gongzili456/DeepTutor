本模块由 Next.js App Router 的三个并列路由组成，均位于 `(utility)/space` 路由组下：`personas/page.tsx`、`notebooks/page.tsx`、`learning/page.tsx`。前两个是纯展示型路由，仅导入并渲染 `@/components/space/PersonasSection` 与 `@/components/space/NotebooksSection` 两个组件，自身不持有状态；`learning/page.tsx` 是唯一的客户端组件（`"use client"`），内联实现了精通之路（Mastery Path）的列表侧边栏与右侧知识图谱视图，通过 `@/lib/learning-api` 提供的 `fetchAllProgress`、`fetchMasteryMap`、`deleteProgress`、`redoProgress` 等函数与后端交互，并以本地 `useState` 维护路径列表、选中项与详情加载状态。依赖方向单向向下：路由 → 共享组件 / 学习 API → 后端服务，路由层不直接调用 fetch。
