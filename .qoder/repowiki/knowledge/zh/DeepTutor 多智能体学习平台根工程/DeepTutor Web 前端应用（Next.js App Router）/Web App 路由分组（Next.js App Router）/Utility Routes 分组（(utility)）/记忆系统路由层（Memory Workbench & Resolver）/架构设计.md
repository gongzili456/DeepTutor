基于 Next.js App Router 的 `(utility)` 路由组，`layout.tsx` 仅提供带 CSS 变量的 `main` 容器，各页面自行管理滚动与内边距。根 `/memory/page.tsx` 渲染 `MemoryHub` 作为入口；`/memory/l1`、`l2`、`l3` 分别挂载 `MemoryL1Workbench`、`MemoryWorkbench(layer='L2')`、`MemoryWorkbench(layer='L3')`，其中 L2/L3 通过 `[surface]` 与 `[slot]` 动态段配合白名单校验（`SURFACES`、`SLOTS`）并调用 `notFound()` 拦截非法路径；`/memory/graph` 直接渲染 `MemoryGraph`；`/memory/resolve` 是外部引用（如 L3 文档中的 `m_<ULID>` 脚注）的跳转中间页，调用后端 `/api/v1/memory/resolve_entry/{id}` 解析出目标 layer/key 后 `router.replace` 到对应 `/memory/{layer}/{key}?focus={entry_id}`。所有使用 `useSearchParams`/`useParams` 的客户端组件均用 `Suspense` 包裹以兼容 App Router 的 Suspense 要求。依赖方向单向向下：路由页仅负责参数解析与导航，业务 UI 全部委托给 `@/components/memory/*` 中的 React 组件。
