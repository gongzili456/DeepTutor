- 每个设置子路由都是一个独立的 `'use client'` 默认导出函数组件，并通过 `SettingsPageHeader` 统一展示标题与描述。
- 可保存的设置页通过 `useSettings().registerExtension(name, { dirty, save })` 向 SettingsContext 暴露脏检查与保存回调，并在卸载时注销。
- 服务端数据通过 `apiFetch(apiUrl(...))` 获取，并以 TypeScript interface（如 `MemorySettingsDTO`）强类型化响应结构。
- 表单字段采用组合模式：用 `SettingSection` 包裹一组 `SettingRow`，数值/开关/选择控件各自封装为独立组件并复用相同的 props 契约（label/help/value/onChange）。
- 对嵌套 DTO 的更新统一通过 `patch(sectionKey, partialValue)` 浅合并生成新 state，避免直接 mutate。
- 所有用户可见文案通过 `useTranslation()` 的 `t(...)` 进行 i18n 包装。
