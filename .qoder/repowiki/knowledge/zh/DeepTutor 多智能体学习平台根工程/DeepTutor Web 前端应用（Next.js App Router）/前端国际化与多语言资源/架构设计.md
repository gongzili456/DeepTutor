模块以 i18next + react-i18next 为核心，按职责拆分为四个文件：init.ts 负责 i18next 单例初始化（设置默认命名空间 app、禁用 keySeparator、fallbackLng=en），并通过动态 import 在首次需要时懒加载 zh/app.json；I18nProvider.tsx 在模块顶层调用 initI18n() 避免渲染期副作用，并在 useEffect 中监听 language prop 变化调用 ensureLanguage 和 i18n.changeLanguage，同时同步 html lang 属性；I18nClientBridge.tsx 作为客户端入口从 AppShellContext 读取当前语言并透传给 Provider；index.ts 统一导出对外 API。翻译资源位于 web/locales/{en,zh}/ 下，按功能域拆分为 app.json（业务文案）与 common.json（通用文案），其中英文为静态导入、中文为按需懒加载，形成英文常驻加中文按需的加载策略。
