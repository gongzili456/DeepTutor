- 配置面板统一通过 `CollapsibleConfigSection` + `summary` 函数（如 `summarizeQuizConfig` / `summarizeResearchConfig`）提供可折叠的摘要行，并以可选的 `collapsed`/`onToggleCollapsed` props 控制是否包裹该容器。
- 表单字段使用共享的 `Field` 组件与 `INPUT_CLS` 类名，通过 `width` prop 控制列宽，保持 quiz/research 配置面板视觉一致。
- 所有用户可见文案通过 `useTranslation()` 的 `t(...)` 调用，选项 label 也采用 i18n key 而非硬编码字符串。
- 异步副作用（笔记查询/写入、会话回填、LLM 选项加载）统一使用 `useCallback` 包裹并通过 `void` 调用，错误以空 catch 降级为 best-effort。
- 流式/长任务句柄集中保存在 `useRef`（如 `judgeHandlesRef`、`dragRef`、`composerRef`）中，在组件卸载或重置时显式清理以避免泄漏。
- 图片资源通过统一的 `resolveImageSrc` 辅助函数将相对 AttachmentStore URL 转换为绝对地址，确保 `<img src>` 在不同端口部署下可用。
