- 第三方重型库（GeoGebra 脚本、Mermaid 模块）采用模块级 Promise 缓存 + 条件创建的方式实现单次加载复用。
- 所有需要 DOM 操作的组件使用 `useEffect` + `useRef` 管理生命周期，并通过 `cancelled` 标志位处理卸载后的异步回调。
- 用户可见文案统一通过 `react-i18next` 的 `useTranslation().t()` 获取，组件自身不硬编码字符串。
- 样式统一基于 Tailwind 原子类配合 CSS 自定义属性（`--border`、`--card`、`--foreground`、`--muted` 等）实现主题适配。
- 可配置的外部资源（如 GeoGebra 命令、Mermaid 图表源码）以 props 传入，组件保持无副作用的纯渲染职责。
- 头像与图标通过集中映射表（`AVATAR_ICONS`、`AVATAR_COLORS`）进行白名单校验，未知值回退到确定性默认值以保证健壮性。
