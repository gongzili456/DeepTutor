本模块由五个相互独立的客户端 React 组件组成，均位于 `web/components/` 下，按职责单一拆分：
- `Geogebra.tsx`：通过动态注入 `<script>` 加载 geogebra.org CDN 的 `deployggb.js`，使用模块级 `ggbLoader` Promise 去重保证全局只加载一次；在 `appletOnLoad` 回调中逐行解析并调用 `evalCommand` 驱动几何画板。
- `Mermaid.tsx`：使用 `import("mermaid")` 动态导入并在首次渲染时缓存模块；通过 `subscribeToThemeChanges` 监听主题切换，每次重新读取 CSS 自定义属性（`--card`、`--foreground` 等）以让图表颜色跟随主题。
- `SessionList.tsx`：纯展示 + 交互组件，接收 `sessions`、`onSelect`、`onRename`、`onDelete` 等回调，内部用 `useMemo` 按 `getDayGroupKey` 分组并按“今天/昨天/近7天/更早”组织；支持 compact 与经典两种布局模式，并提供内联标题编辑与状态指示器。
- `ThemeScript.tsx`：服务端组件（无 `'use client'`），通过 `dangerouslySetInnerHTML` 将一段 IIFE 直接内联到 SSR HTML 中，在 React hydration 之前从 `localStorage('deeptutor-theme')` 恢复主题类名，避免闪烁。
- `UserAvatar.tsx`：根据 `avatar` marker 解析为图标或图片，图标映射表 `AVATAR_ICONS` 覆盖 `lib/avatar` 中的全部名称；管理员角色在尺寸 ≥40px 时叠加盾牌徽章，图片加载失败时回退到确定性默认头像。
依赖方向单向向外：仅依赖 `@/lib/*`（theme、session-api、message-content、relative-time、avatar、profile-api）、`react-i18next`、`lucide-react`，不互相引用。
