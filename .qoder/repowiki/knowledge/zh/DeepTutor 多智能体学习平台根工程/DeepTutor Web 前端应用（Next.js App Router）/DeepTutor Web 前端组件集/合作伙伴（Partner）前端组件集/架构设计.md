本模块是 Partners 功能的纯客户端 UI 层，按职责拆分为多个独立 React 组件：
- 聊天与会话：`PartnerChat.tsx` 通过 `WebSocket(wsUrl('/api/v1/partners/{id}/ws'))` 建立实时连接，处理 `stream_event`/`content`/`done`/`stopped`/`proactive`/`error` 等帧，复用 `@/components/common/AssistantResponse` 和 `@/components/chat/home/TracePanels.AssistantActivity` 渲染流式响应；`PartnerArchives.tsx` 负责历史会话列表与消息浏览。
- 配置面板：`PartnerConfigure.tsx` 聚合身份（FaceEditor）、Soul（SoulEditor）、模型（PartnerModelSelect）、工具（ToolPicker）与资产库（AssetPicker），调用 `@/lib/partners-api` 的 `updatePartner`/`savePartnerSoul`/`addPartnerAssets` 等接口。
- 通道配置：`PartnerChannels.tsx` 使用共享的 `schema-form.tsx` 根据后端 JSON Schema（`GET /api/v1/partners/channels/schema`）动态渲染任意 channel 的配置表单，支持 secret 字段掩码与 `anyOf`/`Optional` 解析。
- 辅助 UI：`AssetPicker`、`ChannelIcon`、`PartnerAvatar`、`PartnerComposer`、`PartnerModelPicker`、`SoulPicker`、`ToolPicker`、`FaceEditor`、`SoulEditor` 等作为可复用子组件被上层组合。
依赖方向单向向下：组件 → `@/lib/partners-api`、`@/lib/api`、`@/lib/unified-ws`、`@/lib/stream` 等共享库，以及 `@/components/common` 中的通用渲染器；组件之间仅通过 props 通信，无全局状态耦合。
