- 所有组件均为 `'use client'` 的 React 函数组件，通过 `useState`/`useEffect`/`useCallback`/`useMemo` 管理本地状态，避免全局 store。
- 用户可见文案统一通过 `useTranslation().t(...)` 获取，不硬编码字符串。
- 异步保存操作遵循「loading 状态 + try/catch + onToast 反馈」模式，按钮在 `saving*` 期间禁用并显示 `Loader2` 旋转图标。
- 表单字段值变更采用不可变更新：对对象使用 `{ ...obj, [k]: next }`，对数组使用 `[...arr].filter/push`，确保 React state 触发重渲染。
- WebSocket 消息处理集中在 `onmessage` 中按 `data.type` 分派，将流式事件累积到 effect 作用域内的 `live` 引用后再发布快照，避免竞态。
- 可选/nullable 字段通过 `isNullable` 检测并在空输入时写回 `null`，以匹配 Pydantic `Optional[...]` 校验语义。
