模块按职责分为两层：`web/components/ui/` 存放原子级基础控件（Button、ConfirmDialog、Tooltip），不依赖业务逻辑；`web/components/common/` 存放复合业务组件（Modal、RichMarkdownRenderer、InlineFileCard、McpToolGroups、ModelThinkingCard、ProcessLogs、BrandIcon、ProviderIcon、PickerShell/PickerHeader、ToastViewport、Tooltip 等），组合基础控件并对接业务上下文。

- 模态框体系：`Modal.tsx` 作为可复用的 dialog 基座，封装 Escape 关闭、backdrop 点击关闭、body 滚动锁定、焦点陷阱与初始 focus 恢复；`ConfirmDialog.tsx` 在其之上实现确认/取消语义的轻量弹窗，两者均通过 `role="dialog"` / `role="alertdialog"` + `aria-modal` 保证无障碍。
- Markdown 渲染管线：`RichMarkdownRenderer.tsx` 基于 react-markdown + remark-gfm，通过动态 import 按需加载 remark-math/rehype-katex/rehype-raw，并将 mermaid、GeoGebra (`ggbscript`)、代码块（`RichCodeBlock`）、文件卡片（`InlineFileCard`）等重节点路由到专用子组件；`SimpleMarkdownRenderer.tsx` 与 `MarkdownRenderer.tsx` 提供轻量变体，三者共享同一 props 契约。
- 主题与样式：统一使用 CSS 变量（`--primary`、`--card`、`--border`、`--overlay` 等）+ Tailwind 类名，避免硬编码颜色；代码高亮主题集中在 `code-block-themes.ts`，并通过 `react-syntax-highlighter-prism-themes.d.ts` 声明类型。
- 依赖方向：ui → common（无反向引用），common 内部通过 `@/lib/*`（latex、markdown-display、markdown-anchors）处理内容预处理，业务状态由调用方注入。
