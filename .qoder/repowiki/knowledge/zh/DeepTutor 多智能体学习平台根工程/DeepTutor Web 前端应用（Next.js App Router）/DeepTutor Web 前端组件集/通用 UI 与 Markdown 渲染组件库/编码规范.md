- 所有组件以 "use client" 指令开头，确保可在浏览器端运行并访问 DOM/事件。
- UI 样式统一通过 Tailwind 类名配合 CSS 变量（如 `bg-[var(--card)]`、`text-[var(--foreground)]`）定义，避免硬编码颜色。
- 模态/弹窗组件统一实现 Escape 关闭、backdrop 点击关闭、`role="dialog"`/`role="alertdialog"` + `aria-modal` 及焦点管理，保证键盘无障碍。
- 重型第三方功能（Mermaid、katex、rehype-raw、RichCodeBlock、GeogebraOpenCTA）一律使用 `next/dynamic` 懒加载并配置 `ssr: false`，减少首屏包体积。
- Markdown 渲染通过 react-markdown 的 `components` 映射表对原生节点进行重写，并按 `variant`（default/trace/prose/compact）切换样式策略。
- 组件对外暴露明确的 props 接口（TypeScript interface），默认值通过解构赋值提供，可选行为通过布尔开关（如 `closeOnEscape`、`enableMath`、`allowHtml`）控制。
