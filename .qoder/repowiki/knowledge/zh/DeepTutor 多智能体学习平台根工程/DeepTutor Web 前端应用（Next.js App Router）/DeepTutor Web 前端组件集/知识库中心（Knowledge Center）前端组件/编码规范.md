- 所有组件均以 "use client" 指令声明为客户端组件，并通过 `useTranslation()` 进行 i18n 文案处理。
- 视图切换通过顶层 `useState` 的 `view` 枚举（"home" | "kb" | "engine"）配合 URL searchParams 双向同步，使用 `router.replace` 保持深链一致。
- 异步操作统一包裹在 `try/catch` 中并调用父级传入的 `setError` 回调展示错误，避免在子组件内自行管理全局错误。
- 只读保护通过检查 `kb.read_only` 字段并在其为真时直接返回空 Promise，阻止上传、删除、设置默认等写操作。
- 引擎/KB 状态展示复用 `resolveKbStatus`、`kbProvider`、`kbDocCount`、`kbNeedsReindex` 等来自 `@/lib/knowledge-helpers` 的纯函数，组件内不重复计算状态。
- UI 样式统一使用 Tailwind 原子类与 CSS 变量（如 `var(--background)`、`var(--muted-foreground)`），并通过 lucide-react 图标表达语义化视觉。
