模块以 `KnowledgePage.tsx` 为路由级入口，集中持有 `useKnowledgeBases` hook 提供的状态（kbs/providers/uploadPolicy/tasksByKb/historyByKb），通过 URL searchParams（`?kb`、`?engine`）驱动三视图切换：`KnowledgeHome`（概览+搜索引擎网格）、`EngineDetail`（按 provider id 配置引擎模式/模型）、`KnowledgeBaseDetail`（单 KB 的 files/add/versions/settings 四标签页）。子组件职责清晰：`CreateKbModal` 统一承载新建/链接 Obsidian/链接本地 index/连接 LightRAG Server 四种创建路径；`KbFilesTab` 采用左右 master-detail 布局配合 `KbDocumentList` 与 `KbFilePreview`；`KbStatusBadge`、`IndexVersionChip`、`KbUpdateHistory`、`PageIndexSettingsModal`、`FileDropZone` 等为可复用 UI 片段。数据层完全依赖外部 `@/lib/knowledge-api`（REST/MCP 调用）和 `@/hooks/useKnowledgeBases`、`useKnowledgeProgress`、`useKnowledgeHistory` 等状态 hook，本模块不维护业务状态，仅做视图编排与用户交互。
