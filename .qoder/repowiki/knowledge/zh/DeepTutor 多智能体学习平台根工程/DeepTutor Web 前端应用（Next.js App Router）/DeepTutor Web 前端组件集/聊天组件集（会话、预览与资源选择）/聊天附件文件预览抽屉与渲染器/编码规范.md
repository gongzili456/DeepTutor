- 每个文件类型对应一个独立的 `previewers/<Type>Preview.tsx` 组件，并通过 `previewKindFor` 中的扩展名/MIME 集合进行匹配注册。
- 所有需要网络数据的渲染器统一使用 `useTextSource` 或 `useBinarySource` Hook 管理 loading/ready/error 状态，避免在各组件内重复实现 fetch 逻辑。
- Hook 内部使用递增 `reqIdRef` 与 `AbortController` 来取消过期请求并处理组件卸载/URL 切换时的竞态。
- 对大文件进行 content-length 前置检查，超过阈值直接返回错误提示而非拉取完整内容（二进制 25MB、文本 8MB）。
- 无法渲染的文件统一走 `FallbackPreview`，通过 `reason` 区分 legacy（历史消息无存储）与 unsupported（不支持的类型）两种文案。
- Drawer 主体通过 `bodyMounted` 延迟挂载重型渲染树，确保滑入动画期间主线程不被 Markdown/语法高亮阻塞。
