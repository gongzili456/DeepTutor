- 所有资源选择器采用统一的 props 契约：`open`、`onClose`、`onApply`（以及可选的 `initialXxx` 初始值），并在 `open` 变为 true 时重置本地搜索与选择状态。
- 选择器内容统一包裹在 `PickerShell` + `PickerHeader` 中，并通过 `labelledBy` 属性传入唯一标题 id 以满足无障碍要求。
- 列表项使用复选框样式（`Check` 图标 + `border-[var(--primary)] bg-[var(--primary)]` 表示选中）配合 `selectedIds.includes(id)` 判断选中态，并提供 Clear 按钮清空选择。
- 异步数据加载使用 `mounted` / `cancelled` 标志位防止组件卸载后 setState，并在 finally 中统一清除 loading 状态。
- 用户可见文案一律通过 `useTranslation()` 的 `t(...)` 包装，包括标题、副标题、占位符、空态提示与计数文案。
- 搜索过滤在 `useMemo` 中对 `query.trim().toLowerCase()` 匹配标题/描述字段，未命中时渲染统一的「No matching ... found」空态区域。
