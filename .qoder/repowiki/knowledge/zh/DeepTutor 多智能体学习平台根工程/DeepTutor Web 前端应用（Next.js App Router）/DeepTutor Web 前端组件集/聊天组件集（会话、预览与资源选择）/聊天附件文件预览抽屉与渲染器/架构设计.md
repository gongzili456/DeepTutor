模块以 `FilePreviewDrawer.tsx` 作为唯一对外入口，是一个固定定位在右侧的滑出面板（无遮罩），通过 `next/dynamic` 按需懒加载各渲染器以避免首屏体积。
- 路由分发：`previewerFor.ts` 定义 `PreviewKind` 联合类型与 `previewKindFor()` 启发式函数，依据扩展名、MIME 和后端 `type` 字段将 `FilePreviewSource` 映射到 pdf/image/svg/markdown/code/text/docx/xlsx/office-text/fallback 十种 kind；同时提供 `resolveSourceUrl()` 把 `url` 或 `base64` 转换为浏览器可加载的 URL。
- 渲染层：`previewers/` 下每个 `<XxxPreview>.tsx` 对应一种 kind，统一接收 `url`/`filename` 等 props；`OfficeTextPreview` 额外消费后端预提取的 `extractedText` / `extractedTextUrl`。
- 数据获取：`useBinarySource.ts` 与 `useTextSource.ts` 是共享 Hook，封装了基于 `apiFetch` + `AbortController` 的异步拉取、content-length 大小上限保护（二进制 25MB、文本 8MB）、竞态取消与 loading/ready/error 状态机，被 Docx/Xlsx/Text 等渲染器复用。
- 降级策略：`FallbackPreview.tsx` 作为兜底，对加密 PDF、未知二进制或历史消息（无 URL）仅展示图标与下载按钮。
- 依赖方向：Drawer → previewerFor（kind 判定 + URL 解析）→ 具体渲染器 → use*Source Hook → `@/lib/api`；渲染器之间相互独立，新增类型只需添加一个 `.tsx` 并在 `previewKindFor` 中注册。
