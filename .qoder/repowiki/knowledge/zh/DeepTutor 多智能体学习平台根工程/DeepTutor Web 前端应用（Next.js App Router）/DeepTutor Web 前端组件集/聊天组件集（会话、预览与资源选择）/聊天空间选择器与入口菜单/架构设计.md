模块由两类组件构成：
- 入口菜单 `ChatSpaceMenu.tsx`（位于 `space/`）：一个受控的弹出式导航面板，通过 `variant="toolbar" | "mention"` 切换紧凑工具栏与 @提及键盘导航两种形态；使用固定 `ITEM_ORDER` 数组驱动渲染顺序，并借助 `setPickerOrigin` 把触发按钮的矩形传给全屏选择器以做展开动画。
- 具体资源选择器（`BookReferencePicker`、`HistorySessionPicker`、`MyAgentsPicker`、`PersonaPicker`、`QuestionBankPicker`、`MemoryPicker`）：每个文件是一个独立的 React 客户端组件，统一通过共享的 `PickerShell` + `PickerHeader` 包裹全屏模态，内部维护本地 `open`/`selected`/`query` 状态，打开时调用各自对应的 `@lib/*-api`（如 `bookApi`、`session-api`、`partners-api`、`notebook-api`、`personas-api`）拉取数据，关闭时通过 `onApply(selection)` 回调将选中结果回传父组件。
依赖方向单向向下：选择器 → `@/components/common/*` 壳组件 → `@/lib/*-api` 后端接口；选择器之间互不引用（仅 `MyAgentsPicker` 引用 `HistorySessionPicker` 的 `SelectedHistorySession` 类型），入口菜单通过字符串 key 路由到各选择器，使新增资源只需在 `SPACE_ITEMS` 和对应选择器中注册。
