- 所有可交互视图组件以 `"use client"` 指令声明，并通过 `next/dynamic` 按需加载重依赖（如 MathAnimatorViewer、chart.js）以规避 SSR。
- 用户可见文案统一通过 `react-i18next` 的 `useTranslation().t()` 获取，避免硬编码字符串。
- SVG 内容经 `sanitizeSvg` 清洗后以 `dangerouslySetInnerHTML` 注入，并对多 `<svg>` 块拆分、按页面序列号重命名 id 以避免引用冲突。
- 错误态采用统一的红色边框卡片布局（`border-red-200 bg-red-50 dark:border-red-900/60 dark:bg-red-950/30`）展示错误标题与堆栈。
- 全屏覆盖层通过 `react-dom/createPortal` 挂载到 `document.body`，绕过聊天气泡所在祖先容器的 transform/overflow 限制。
- 配置面板使用受控 `value` + `onChange` 模式，并通过泛型 `update<K extends keyof T>(key, val)` 函数实现类型安全的字段更新。
