模块由两个并列的子目录组成：`visualize/` 提供通用可视化渲染入口 `VisualizationViewer.tsx`，根据 `VisualizeResult.render_type`（svg/chartjs/mermaid/html）分派到对应的内部 Renderer（`SvgRenderer`/`ChartJsRenderer`/`HtmlRenderer`），并通过 `isManimResult` 判断走 `math-animator/MathAnimatorViewer` 分支；`math-animator/MathAnimatorViewer.tsx` 独立处理 Manim 产出的视频/图片/代码及视觉审查提示。两者均通过 Next.js `dynamic({ ssr: false })` 动态导入以避免 SSR 依赖 DOM。跨 iframe 通信通过 `postMessage` + `window.dispatchEvent('dt:visualize-prompt')` 事件桥接回聊天输入框。样式集中在 `svg-theme.css`，为 LLM 生成的 SVG 提供主题化 class（.c-*/.box/.arr/.node）并支持 light/dark 模式。配置面板 `VisualizeConfigPanel.tsx` 复用 composer 的 `Field`/`CollapsibleConfigSection` 暴露 render_mode、quality、style_hint 等表单字段。
