本模块以业务域为维度组织子目录（chat/knowledge/memory/settings/space/mcp/partners/quiz_research/auth_access/agents/layout_shell/common_ui/visualize_math/root_shells），每个子目录对外暴露一组无状态或轻状态的 React 组件，通过 props、Context 与 Next.js 路由进行组合；跨域协作主要依赖共享的 common_ui 基础组件（Button、Modal、Tooltip、Markdown 渲染）以及根级 shell（AppShell、SidebarShell、ThemeScript）作为页面外壳。各子模块不直接互相 import，而是由上层页面（如 /space、/settings、聊天首页）按需拼装，从而保持领域隔离。
