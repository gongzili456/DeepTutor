模块以 React Hook + 无状态 UI 组件的形态组织：`useNotebookSelection.ts` 是核心状态钩子，封装 `listNotebooks`/`getNotebook` 等 notebook API 调用，维护 notebooks、expandedNotebooks、notebookRecordsMap、selectedRecords 及 loading 状态，并提供 toggle/selectAll/deselectAll/clearAll 等动作；`NotebookSelector.tsx` 是纯展示型选择器，接收 hook 暴露的状态与回调，渲染可折叠的笔记本-记录树并处理勾选交互；`NotebookRecordPicker.tsx` 作为入口模态框，组合 `PickerShell`/`PickerHeader` 与 `NotebookSelector`，在打开时触发 `fetchNotebooks` 并通过 `onApply` 将选中的 `SelectedRecord[]` 回传给调用方；`SaveToNotebookModal.tsx` 独立实现“保存到笔记本”流程，支持可选的消息选择模式（基于 `message_count`/`selected_message_indexes` 元数据），通过 `apiFetch` POST 到 `/api/v1/notebook/add_record_with_summary`，并以自定义 `parseSseEvents` 解析服务端 SSE 事件流（summary_chunk / error / result）实时更新摘要预览。类型定义统一来自 `@/lib/notebook-selection-types`，API 调用来自 `@/lib/notebook-api` 与 `@/lib/api`，UI 壳复用 `@/components/common/PickerShell` 与 `PickerHeader`。依赖方向单向：组件 → hook → API 层，组件之间仅由 `NotebookRecordPicker` 组合 `NotebookSelector`。
