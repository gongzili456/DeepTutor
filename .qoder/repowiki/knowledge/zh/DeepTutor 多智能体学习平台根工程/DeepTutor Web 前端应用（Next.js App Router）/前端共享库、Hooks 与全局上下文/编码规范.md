- HTTP 调用统一走 `api.ts` 的 `apiFetch`，并通过 `skipAuthRedirect: true` 标记需要把 401 当作业务错误而非跳转登录的端点（如 login/register）。
- URL 构造一律通过 `apiUrl` / `wsUrl` 包装，禁止在调用方拼接硬编码后端地址，以支持代理重写。
- 全局状态采用 React Context + useReducer 模式，action 用字面量联合类型（`type: 'X'`），通过 `updateSelectedSession` 等辅助函数进行不可变更新。
- WebSocket 连接封装为类（`UnifiedWSClient`），对外暴露 `connect`/`send`/`setResumeState` 等方法，内部自行管理心跳、超时与指数退避重连。
- 跨标签页/跨组件的状态同步通过 localStorage 键 + `storage` 事件广播（见 `app-shell-storage.ts` 中的 `*_STORAGE_KEY` 常量）。
- 异步数据获取 hook（如 `useAuthStatus`）使用模块级 `inflight` Promise 去抖并发请求，并在 finally 中清理，避免重复网络调用。
