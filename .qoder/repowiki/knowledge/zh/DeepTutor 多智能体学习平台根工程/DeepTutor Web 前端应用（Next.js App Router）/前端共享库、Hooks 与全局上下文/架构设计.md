模块按职责分为三层：
- `web/lib/`：纯函数与类库，无 React 依赖。核心是 `api.ts`（`apiUrl`/`wsUrl`/`apiFetch` 透传到 `web/proxy.ts`，集中处理 401 跳转）、`unified-ws.ts`（基于 `/api/v1/ws` 的 UnifiedWSClient，封装心跳、指数退避重连、`resume_from` 续流）以及按领域切分的 API 客户端（`session-api`、`knowledge-api`、`book-*`、`mcp-*`、`co-writer-*` 等）。`chat-import/` 子目录实现多来源聊天导入协议。
- `web/context/`：应用级 React Context，`UnifiedChatContext.tsx` 使用 `useReducer` + 不可变更新维护多 session 消息树、分支选择、流式事件合并与乐观 ID；`AppShellContext.tsx` 通过 `app-shell-storage` 持久化主题、语言、侧边栏折叠与代码块设置，并监听 `storage` 事件跨标签页同步。
- `web/hooks/`：面向组件的副作用封装，如 `useAuthStatus` 缓存单次 `fetchAuthStatus` 请求、`useSmoothStreamText`、`useVoiceRecorder`、`useKnowledgeBases` 等。
依赖方向严格单向：hooks 与 context 消费 lib；lib 之间仅通过相对路径引用，不反向依赖 React。
