- 页面按 Next.js App Router 路由组 `(auth)`、`(workspace)`、`(utility)`、`(admin)` 组织，每个组内使用独立的 `layout.tsx` 承载该域的布局与权限逻辑。
- UI 组件按业务域拆分至 `components/<domain>/` 目录，并在 `app/` 对应路由中按需引入，避免跨域耦合。
- 跨页面状态通过 `context/` 中的 React Context（如 `AppShellContext`、`UnifiedChatContext`）提供，而非局部 state。
- 后端通信统一封装在 `lib/` 下的独立模块（如 `session-api.ts`、`knowledge-api.ts`、`mcp-api.ts`），组件仅调用这些函数而不直接发起 fetch。
- 国际化文案通过 `i18n/` 提供的 `useTranslation` 钩子读取，新增功能需同步更新 `locales/en` 与 `locales/zh` 并经由 `i18n:check` 校验。
- 测试以文件名匹配对应源码文件的方式组织在 `tests/` 下，Node 单元测试覆盖纯函数逻辑，Playwright 用例覆盖 UI 审计场景。
