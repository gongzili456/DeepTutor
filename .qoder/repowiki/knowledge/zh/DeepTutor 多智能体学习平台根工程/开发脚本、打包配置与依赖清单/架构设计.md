本模块由三类互补资产组成：
- `scripts/`：一组独立可执行的 Python 工具与 Windows 批处理入口，职责互不依赖。
  - `_cli_kit.py` 是共享 CLI 输出库（banner/log_success/log_error），被多个脚本复用；
  - `docker_compose.py` 从 `data/user/settings/{system,integrations}.json` 渲染端口到 `docker.env`，再调用 `docker compose --env-file` 拉起后端/前端/PocketBase 容器；
  - `pb_setup.py` 通过 `pocketbase` SDK 读取集成配置并幂等创建 sessions/messages/turns/turn_events/knowledge_bases 集合；
  - `prepare_web_package.py` 将 Next.js standalone 构建产物拷贝进 `deeptutor_web` 包目录，供打包阶段使用；
  - `start_web.py`、`start_tour.py`、`start_backend.bat`、`start_frontend.bat` 作为用户友好的启动入口，转发到 `deeptutor.runtime.launcher` 或对应服务；
  - `update.py` 封装 git 操作，实现安全的 fast-forward 更新流程，检测分支分歧、未提交变更并给出依赖重建提示。
- `packaging/deeptutor-cli/pyproject.toml`：定义 `deeptutor-cli` 发行包，使用 setuptools build backend，动态版本来自 `deeptutor.__version__`，仅包含 `deeptutor*` 与 `deeptutor_cli*` 包并排除 `deeptutor_web*`，暴露 `deeptutor` 控制台脚本。
- `requirements/`：按运行场景切分的 pip 依赖文件（`cli.txt`、`server.txt`、`dev.txt`、`matrix*.txt`、`partners.txt`、`math-animator.txt`），其中 `server.txt` 通过 `-r cli.txt` 组合基础依赖，并在注释中声明需与主 `pyproject.toml` 保持同步，用于 Docker/CI 在无源码环境下的安装。
依赖方向：所有脚本均位于项目根目录下，通过相对路径解析 `PROJECT_ROOT` 后导入顶层 `deeptutor` 包或调用外部命令（git/docker/npm），不引入业务逻辑耦合。
