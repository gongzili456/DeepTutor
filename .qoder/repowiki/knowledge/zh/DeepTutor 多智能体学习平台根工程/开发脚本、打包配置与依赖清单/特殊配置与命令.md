- 首次使用 PocketBase：先启动容器，再执行 `python scripts/pb_setup.py`，需在 `data/user/settings/integrations.json` 中配置 `pocketbase_url`、`pocketbase_admin_email`、`pocketbase_admin_password`。
- 启动容器化服务：`python scripts/docker_compose.py [up|down|...]`，端口取自 `system.json`/`integrations.json` 并写入 `data/user/settings/docker.env`。
- 构建 Web 包：`python scripts/prepare_web_package.py [--skip-build]`，要求 `web/.next/standalone/server.js` 已存在。
- 安全更新仓库：`python scripts/update.py [--yes] [--repo PATH]`，仅允许 fast-forward pull。
- 依赖安装：`pip install -r requirements/cli.txt` 或 `pip install -r requirements/server.txt`，后者会级联安装 `cli.txt`。
