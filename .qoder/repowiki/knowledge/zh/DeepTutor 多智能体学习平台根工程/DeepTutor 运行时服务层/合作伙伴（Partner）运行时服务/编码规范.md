- 对外暴露的公开 API 集中在 `__init__.py` 的 `__all__` 中统一导出，子模块仅暴露最小接口集合。
- 对敏感字段（token/secret/password/api_key 等）通过 `mask_channel_secrets` 递归替换为 `***` 后再序列化输出，避免泄露渠道密钥。
- 配置写入采用临时文件 + `replace` 的原子写策略（`.yaml.tmp` → `.yaml`），保证并发下的配置一致性。
- 长耗时或外部依赖通过函数内 `from ... import ...` 延迟导入，避免模块加载时的循环依赖与冷启动开销。
- partner id 一律经 `slugify_partner_id` / `slugify_soul_id` 转换为 ASCII URL-safe 字符串，纯非拉丁名称回退到 SHA1 短哈希以保证稳定性。
- 异步任务统一命名形如 `partner:{partner_id}:runner/router/ch:{name}` / `partner:{partner_id}:turn` / `partner:{partner_id}:webturn`，便于调试与按前缀取消。
