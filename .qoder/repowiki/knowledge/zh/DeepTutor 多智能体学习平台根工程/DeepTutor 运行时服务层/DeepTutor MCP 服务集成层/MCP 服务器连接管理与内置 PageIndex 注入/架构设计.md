模块由三层组成：
- 配置层（config.py）：使用 Pydantic 定义 `MCPServerConfig`（支持 stdio/sse/streamableHttp 三种传输、工具白名单/黑名单、OAuth 标记、catalog_entry 溯源）与 `MCPConfig`（按名称索引的服务器字典），并通过 `load_mcp_config` / `save_mcp_config` 以原子写入（.tmp + os.replace）持久化到管理员工作区的 `mcp.json`。
- 连接管理层（manager.py）：`MCPConnectionManager` 是进程单例，按 `(owner, server_name)` 键管理 `_ServerConnection`；每个服务器通过 `asyncio.create_task` 启动独立连接任务，持有 `AsyncExitStack` 生命周期，在任务内完成 transport → ClientSession → list_tools → 注册适配器 的全流程。通过 `ensure_started` / `reload` / `ensure_scope` 懒加载并按 owner 隔离（共享部署级 vs 用户级 scope），配合 per-owner `asyncio.Lock`、指数退避重试、冷 scope 超时驱逐（TTL 900s、上限 64）控制资源。工具调用经 `MCPToolAdapter.execute` 转发到 `call_tool`，封装 transient 错误重试、超时、取消语义，并将 MCP 进度回调映射为 trace `tool_progress` 事件。
- 内置注入层（pageindex_server.py）：`with_builtin_servers` 在加载配置时把 `pageindex` 服务器条目叠加到 `MCPConfig` 上，但用户同名条目优先，且该条目不持久化。
依赖方向单向：manager 依赖 config 与 pageindex_server；transport 打开（stdio/sse/streamableHttp）、OAuth、URL 校验、secret 引用解析等通过运行时 import 延迟加载，使 mcp SDK 成为可选依赖。
