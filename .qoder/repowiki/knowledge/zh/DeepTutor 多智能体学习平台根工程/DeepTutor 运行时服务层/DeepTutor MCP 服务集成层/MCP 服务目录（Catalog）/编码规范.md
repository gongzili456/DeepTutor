- 所有公开数据模型使用 `dataclass(frozen=True, slots=True)` 并以 `__post_init__` 集中执行不变式校验，而非外部验证器。
- 字符串枚举通过 `typing.Literal[...]` 声明并由 `get_args` 导出为运行时元组（如 `CATALOG_CATEGORIES`、`TRANSPORTS`），用于 UI 过滤与校验。
- 多语言文本统一采用 `{lang: text}` 字典存储，并通过 `localized_text` 按 `lang → lang.split('-')[0] → en` 顺序降级取值。
- 传输类型通过 `normalize_transport` 归一化到 `streamableHttp` 等标准拼写，避免在比较处散落别名判断。
- 搜索与筛选逻辑集中在 `loader.py` 的纯函数中，路由层仅做参数翻译，使 CLI 与未来接口共享同一套语义。
- 敏感字段在构建配置时用 `secret_reference` 替换为 `${secret:...}` 引用，原始明文单独返回供 secrets 存储，确保持久化配置不含明文。
