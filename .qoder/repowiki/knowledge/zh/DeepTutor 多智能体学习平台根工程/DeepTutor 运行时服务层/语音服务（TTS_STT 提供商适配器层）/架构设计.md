模块采用适配器模式组织：`base.py` 定义 `BaseTTSAdapter` / `BaseSTTAdapter` 抽象基类、统一的 `VoiceProviderError` / `VoiceProviderHTTPError` 异常体系以及 `build_auth_headers`、`join_audio_path`、`strip_markdown_for_speech` 等共享工具；`config.py` 用 dataclass 描述 TTS/STT 运行时配置（model、provider_name、adapter、auth_style、base_url、api_key、request_style 等），作为模型目录到 HTTP 适配器的只读桥接；`adapters/openai_compat.py` 实现具体 HTTP 调用——`OpenAICompatTTSAdapter` 调用 `/audio/speech`，`OpenRouterTTSAdapter` 在其失败时回退到 `/chat/completions` 流式音频输出，`OpenAICompatSTTAdapter` 支持 multipart 与 base64_json 两种 STT 请求风格；顶层 `__init__.py` 暴露 `synthesize_speech` / `transcribe_audio` 两个入口，通过 `resolve_tts_runtime_config` / `resolve_stt_runtime_config` 从全局 model catalog 解析配置并委托给 `get_tts_adapter` / `get_stt_adapter` 选择的适配器，依赖方向为入口 → config → base → adapters，对外仅暴露统一异步 API。
