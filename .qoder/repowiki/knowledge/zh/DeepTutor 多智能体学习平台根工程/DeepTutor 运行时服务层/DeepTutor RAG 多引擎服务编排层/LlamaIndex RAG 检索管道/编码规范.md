- 所有对 LlamaIndex 阻塞 I/O（索引构建、检索）的操作通过 `asyncio.get_running_loop().run_in_executor` 放入线程池执行，使 `pipeline.py` 的 API 保持 async 语义。
- 可选依赖（faiss、BM25 检索器）采用 try/except ImportError 延迟导入并在不可用时返回 None 或降级到默认路径，确保功能可用而非抛出异常。
- 配置统一通过 dataclass（如 `RetrievalConfig`）+ 从环境变量/持久化设置加载的工厂函数暴露，调用方不直接拼字符串。
- 索引持久化目录按 embedding signature 版本化，读写分别走 `resolve_storage_dir_for_read` / `resolve_storage_dir_for_rebuild` / `resolve_storage_dir_for_write`，写入成功后调用 `write_version_meta` 记录元数据。
- 错误处理统一收敛到 `errors.search_error_result`，根据异常消息模式（invalid embedding provider response、shape mismatch、invalid persisted index）分类为 `error_type` 与 `needs_reindex` 字段。
- 跨进程共享的重资源（已加载的 VectorStoreIndex）通过模块级 `OrderedDict` + `threading.Lock` 缓存，并以文件 mtime 派生的 freshness token 失效，限制最大条目数并定期清理空闲项。
