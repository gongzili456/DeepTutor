- 通过构造函数注入 `client` 与 `config_provider` 参数，便于测试时替换为 mock 或自定义实现
- 所有对 PageIndex REST API 的调用统一经 `PageIndexClient._open()` 创建临时 `httpx.AsyncClient`，并在 `with` 块内使用以确保连接生命周期管理
- 对外部 API 错误统一转换为自定义异常（`PageIndexAPIError`、`PageIndexNotConfiguredError`），并在调用方捕获后返回带 `error_type` 字段的标准结果字典
- 本地状态以清单文件形式持久化到 `version-N` 目录，读写均走 `storage.py` 提供的 `read_manifest`/`write_manifest`/`upsert_doc` 等函数，避免直接操作文件系统
- 异步批量操作使用 `asyncio.gather(..., return_exceptions=True)` 并发发起请求并收集异常，保证单个失败不影响整体流程
