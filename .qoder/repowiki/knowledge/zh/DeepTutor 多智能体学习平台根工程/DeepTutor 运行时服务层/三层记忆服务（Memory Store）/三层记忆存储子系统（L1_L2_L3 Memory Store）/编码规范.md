- 对磁盘写入统一采用「写临时文件 + `replace`/`os.replace`」的原子替换模式，避免部分写入导致文档损坏。
- 所有 I/O 密集或阻塞的文件操作通过 `asyncio.to_thread` 放入线程池执行，保持异步接口不被阻塞。
- 用户可配置项以 frozen dataclass 描述，并通过递归的 `_from_dict` 进行类型强制与数值范围钳制，缺失字段回退到默认值。
- 跨进程并发写同一文档时，使用 `MemoryStore._write_locks` 按物理路径分配 `asyncio.Lock`，保证单文件串行写入。
- LLM 提示词按语言拆分为 `prompts/en/*.yaml` 与 `prompts/zh/*.yaml`，并通过 `_meta.yaml` 元数据管理，代码侧不硬编码自然语言。
- 文档解析器同时兼容新格式（HTML 注释 `<!--m_xxx-->` 锚点 + 整数脚注）与旧格式（`[^m_xxx]` 尾标 + entry-keyed 脚注），序列化一律输出新格式以实现渐进迁移。
