- 所有模式通过统一的 `OnEvent` 回调发射阶段事件（trace_loaded/chunked/progress/facts_extracted/refs_dropped/doc_updated/done），事件字典包含 stage、turn、label 等字段用于工作区追踪。
- 对外部资源（prompt YAML、focus meta）采用模块级 dict 缓存，键为 `(language, name)` 或 `language`，避免重复磁盘读取。
- 文档与元数据写入一律使用 temp 文件 + `os.replace` 的原子写模式，失败时清理临时文件，保证并发安全。
- 跨模块调用（如 update 触发 dedup/merge）使用 `from ... import` 的延迟导入，避免启动时循环依赖。
- LLM 调用统一走 `call_llm`，先尝试流式 `llm_stream`，捕获异常后回退到 `llm_complete`，并在两种路径下都通过 `clean_thinking_tags` 剥离 `<thinking>` 块。
- 增量更新通过 `*.meta.json` 中 `seen_entity_refs` / `seen_l2_entry_ids` 集合差计算“自上次更新以来新增”的内容，而非依赖 mtime 或时间戳。
