- 对外暴露的公共 API 通过 `__all__` 显式声明，内部辅助函数以下划线前缀命名（如 `_terminate`、`_load`、`_save`）。
- 所有异步资源释放均放在 `finally` 块中执行，确保消费者提前中断或取消时子进程不会被遗留（如 `stream_process_lines` 中 cancel pump 任务并调用 `_terminate`）。
- 事件类型以模块级常量（`EVENT_*`）集中定义，并通过 `KNOWN_EVENT_KINDS` frozenset 做白名单校验，避免硬编码字符串散落。
- I/O 操作使用 try/except 包裹并以 `logger.debug`/`logger.warning` 记录异常而非向上抛出，保证流式管道健壮性。
- 会话键统一通过 `session_key(chat_session_id, connection)` 构造，并以 `::` 分隔符拼接，便于后续按连接后缀批量清理。
