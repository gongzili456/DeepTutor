模块以 `base.py` 中的抽象类 `LLMProvider` 为核心契约，统一暴露 `chat` / `chat_stream` / `chat_with_retry` / `chat_stream_with_retry` / `aclose` / `get_default_model` 等异步方法，并通过 `ToolCallRequest`、`LLMResponse`、`GenerationSettings` 三个 dataclass 作为跨厂商的输入输出协议。各厂商实现（`anthropic_provider.py`、`openai_compat_provider.py`、`azure_openai_provider.py`、`github_copilot_provider.py`、`openai_codex_provider.py`）均继承自该基类，仅负责消息格式转换与 SDK 调用细节；`__init__.py` 通过 `_LAZY_TYPES` + `__getattr__` 实现按需导入，避免启动时加载所有 SDK。`openai_responses/` 子包提供独立于具体 provider 的 Responses API 编解码工具：`converters.py` 将 Chat Completions 消息/工具转换为 Responses 格式，`parsing.py` 解析 Responses SSE/SDK 流事件并还原为 `LLMResponse`，被 `OpenAICompatProvider` 复用以支持 OpenAI 新 Responses 端点。重试策略集中在基类的 `_call_with_retry`，内置 transient error 标记匹配、指数退避以及 Stage-2 图片回退（非 vision 模型失败时自动剥离图像重试）。
