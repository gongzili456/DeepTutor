模块以 FastAPI `APIRouter`（`router.py`）暴露 `/admin/*` 和 `/users/{user_id}/grants` 等管理端点，所有路由通过 `require_admin` 依赖保护并调用 `audit.log_admin_action` 记录审计日志。

内部按职责划分为若干子文件：
- 身份存储：`identity.py` 维护 `data/system/auth/users.json`，支持从旧布局迁移、环境变量注入 admin、头像图片原子写入；`models.py` 定义不可变数据类 `UserRecord`、`CurrentUser`、`UserScope`、`KnowledgeResource`。
- 上下文传播：`context.py` 使用 `ContextVar` 在请求内传递当前用户，缺省回退到本地 admin。
- 路径与工作区：`paths.py` 统一解析 `data/user`（admin）、`data/users/<uid>`（普通用户）、`data/partners/<id>`（伙伴）、`data/system`（部署态），并提供 `ensure_scope_workspace`、`get_owner_path_service`、`owner_secrets_dir` 等函数，确保 owner-keyed 资产（OAuth 刷新令牌等）落在沙箱不可见的 system 目录。
- 授权模型：`grants.py` 实现 grant v2 JSON schema（`empty_grant` + `normalize_grant`），持久化到 `data/system/grants/<uid>.json`，并通过 `validate_grant` 拒绝密钥/路径字段泄露。
- 资源访问控制：`model_access.py`、`knowledge_access.py`、`skill_access.py`、`tool_access.py`、`partner_access.py` 分别把 grant 与管理员目录合并成前端可见的白名单视图；`personal_models.py` 允许普通用户在自身 catalog 中注册 owner-bound 的 LLM 配置，不进入共享目录。
- 审计：`audit.py` 将用户资源访问与管理员写操作追加写入 `data/system/audit/usage.jsonl`，失败不中断请求。

依赖方向单向向外：router → access 层 → grants/identity/paths → 外部服务（ModelCatalogService、SkillService、KnowledgeBaseManager、PartnerManager），模块本身不直接持有业务状态，仅负责隔离与授权。
