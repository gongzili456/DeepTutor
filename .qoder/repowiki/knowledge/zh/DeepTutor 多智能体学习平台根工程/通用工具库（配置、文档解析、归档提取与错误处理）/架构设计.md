模块以扁平的 Python 包形式组织，按职责拆分为独立文件：`config_manager.py` 通过单例 `ConfigManager` 管理 `data/user/settings/main.yaml`，使用 `RLock` 保证并发读写并基于 mtime 缓存；`document_extractor.py` 是核心解析器，统一入口 `extract_text_from_bytes` 根据扩展名分发到 PDF（pymupdf/pypdf）、DOCX/XLSX/PPTX（python-docx/openpyxl/python-pptx 及 OOXML 回退）、纯文本路径，所有可选第三方库采用延迟 import + `_NOT_LOADED` 哨兵模式以避免启动时依赖；`archive_extractor.py` 在 `DocumentValidator.validate_upload_safety` 之上实现防 Zip Slip、zip bomb 和嵌套归档的安全解压；`document_validator.py` 集中维护允许扩展名/ MIME 白名单与文件名清洗逻辑；`json_parser.py` 提供三层 LLM 响应解析（markdown 代码块 → 直接解析 → json-repair 修复），并通过可注入的 `repair_json` 钩子便于测试替换；`error_rate_tracker.py` 用滑动窗口统计各 provider 错误率，并通过可选回调联动 `network/circuit_breaker.py` 中的全局 `CircuitBreaker` 实例形成熔断闭环；`error_utils.py` 提供异常消息格式化辅助。依赖方向单向向下：本模块仅被上层 services/handlers 引用，不反向依赖业务层。
