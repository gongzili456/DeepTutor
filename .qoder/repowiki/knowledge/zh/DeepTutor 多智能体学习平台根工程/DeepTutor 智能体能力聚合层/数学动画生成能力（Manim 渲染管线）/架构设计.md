模块以 `capability.py` 中的 `MathAnimatorCapability` 作为对外暴露的 `BaseCapability` 入口，通过 `run()` 编排 `pipeline.py` 中的 `MathAnimatorPipeline`；管线按 stages 顺序调用 `agents/` 下的五个独立 LLM Agent（ConceptAnalysisAgent、ConceptDesignAgent、CodeGeneratorAgent、SummaryAgent、VisualReviewAgent），每个 Agent 继承 `BaseAgent` 并通过 `prompts/{en,zh}/` 下的 YAML 模板加载提示词。渲染由 `renderer.py` 的 `ManimRenderService` 负责：写入临时源码后通过 `subprocess` 调用 `python -m manim`，使用线程+Queue 流式读取 stdout/stderr 并回调进度；支持 video 与 image（YON_IMAGE 锚块）两种输出模式。`retry_manager.py` 的 `CodeRetryManager` 封装 render-fix-regenerate 循环（最多 4 次重试），在渲染失败时调用 CodeGeneratorAgent.repair 修复代码，并可可选触发 VisualReviewAgent 对帧进行视觉质量审查后再决定是否继续重试。所有阶段通过 `StreamBus.stage/progress/thinking/content/error` 上报进度，并由 `_build_trace_bridge` 把 LLM trace 事件映射为 stream 事件；数据模型集中在 `models.py`，请求配置由 `request_config.py` 用 Pydantic 校验。依赖方向单向：capability → pipeline → agents + renderer/retry_manager → 外部 manim/LaTeX。
