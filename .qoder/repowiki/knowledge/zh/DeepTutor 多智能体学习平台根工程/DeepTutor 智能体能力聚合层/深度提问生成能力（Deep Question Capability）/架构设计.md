模块以 `capability.py` 中的 `DeepQuestionCapability` 为统一对外入口，依据请求上下文路由到三条路径：followup 单题追问调用 `agents/followup_agent.py`；custom/mimic 模式构造 `QuestionPipeline` 执行三阶段 agentic 循环（Explore/Plan/Quiz），并通过 `StreamBus` 向前端流式推送思考、工具调用与结果事件。

- 编排层：`pipeline.py` 定义 `QuestionPipeline`，使用 `deeptutor.core.agentic` 的 `run_agentic_loop` / `run_labeled_step` 驱动 THINK/TOOL/FINISH/PLAN 标签协议，内置 `LabelProtocol` 约束每阶段允许的动作集合，并维护 `QuizTemplate`、`QuizHistoryEntry` 等数据类。
- 适配层：`coordinator.py` 提供 `AgentCoordinator` 作为遗留 WebSocket/tool 调用的兼容门面，内部仍委托给 `QuestionPipeline`，负责把 `StreamBus` 事件转发为旧式回调。
- 解析层：`mimic_source.py` 封装 MinerU 文档解析与 `question_extractor`，将 PDF/已解析目录转换为 `QuizTemplate` 列表供 pipeline 通过 `templates_override` 跳过 explore+plan。
- 配置层：`request_config.py` 从 `main.yaml` 中安全地抽取 `capabilities.deep_question.exploring.*` 开关（迭代上限、tool_summarizer），对缺失键回退默认值。
- 历史层：`history.py` 通过 SQLite session store 读取同会话已生成的题目，按 (created_at, id) 升序排序后注入 Explore 阶段提示，避免重复与覆盖薄弱点。
- 提示词：`prompts/en` 与 `prompts/zh` 下按语言分目录存放 `deep_question.yaml`、`idea_agent.yaml`、`followup_agent.yaml`、`pipeline.yaml`，由 `services.prompt` 加载。
- 依赖方向：capability → pipeline → core.agentic + services；mimic_source 反向依赖 pipeline 的数据类型；history 仅被 capability/pipeline 消费；coordinator 是单向兼容桥接。
