- 对外入口采用延迟导入：包级 `__getattr__` 仅在首次访问符号时 import 对应子模块，避免冷启动加载 LLM 依赖。
- 所有外部 I/O（MinerU 解析、SQLite 查询、LLM 调用）均包裹在 try/except 中并记录日志后返回空结果或错误事件，保证 pipeline 在主流程中不被异常中断。
- 通过 `LabelProtocol` 显式声明每个阶段的允许动作、终止集与工具标签，而非用字符串硬编码控制流。
- 运行时配置通过 `build_question_runtime_config` 的 `_read_int` / `_read_bool` 安全读取器从任意 base_config 中提取，缺失键一律回退默认值。
- 流式进度统一经由 `StreamBus.stage` 上下文管理器 + `stream.thinking/progress/tool_call/tool_result/error/content` 方法推送，并按 stage（exploring/planning/quizzing/generation）分类。
- 提示词按语言拆分为 `prompts/en` 与 `prompts/zh` 下的同名 YAML 文件，通过 `services.prompt` 的 i18n 机制按需加载。
