- BaseAgent 的子类仅需实现 `process()` 抽象方法，其余配置、LLM 调用、提示词、Token 追踪均由基类统一处理。
- LLM 调用统一经由 `call_llm` / `stream_llm` 发起，禁止直接调用底层 `llm_complete` / `llm_stream`，以保证重试、token 限制、多模态附件与 trace 事件的一致性。
- Token 追踪优先使用外部 `token_tracker`，回退到类级共享的 `LLMStats`，且追踪失败不中断主流程。
- 跨能力共享逻辑以纯函数形式放在 `_shared/` 下（如 `emit_capability_result`、`compose_enabled_tools`），不持有实例状态，便于 chat/quiz 等多处复用。
- 工具启用策略通过 `ToolMountFlags` 数据类声明上下文门控，配合 `AUTO_MOUNTED_TOOLS` 与 `_CONDITIONAL_MOUNT_FLAGS` 映射表集中维护，避免在各管线中散落 if/else。
- 对可选的外部服务（memory、notebook）采用 try/except 失败关闭（fail-closed）模式，确保缺失时返回默认值而不抛出异常。
