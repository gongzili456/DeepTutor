模块以 `channels/` 为核心，采用插件式架构：`base.BaseChannel` 定义 `start/stop/send/send_delta` 等抽象接口；各平台实现（telegram、discord、slack、whatsapp、wecom、dingtalk、feishu、msteams、matrix、mattermost、mochat、napcat、qq、weixin、zulip、email）均继承该基类并通过 `manager.ChannelManager` 统一启停。

- 发现机制：`registry.py` 使用 `pkgutil.iter_modules` 扫描内置 channel 模块，并通过 `importlib.metadata.entry_points(group='deeptutor.partners.channels')` 加载外部插件，内置优先且同名插件会被忽略。
- 消息解耦：`bus/events.py` 用 dataclass 定义 `InboundMessage`/`OutboundMessage`，`bus/queue.MessageBus` 基于 `asyncio.Queue` 提供 inbound/outbound 双队列，channel 仅负责把平台事件推入 inbound，agent 侧消费后回写 outbound。
- 出站路由：`ChannelManager._dispatch_outbound` 是独立协程，负责去重（按 origin_message_id + 内容指纹）、流式 delta 合并（同 stream_id 的连续 `_stream_delta` 聚合）、重试退避（1s/2s/4s）以及按 `send_progress`/`send_tool_hints` 过滤工具提示。
- 配置：`config/schema.ChannelsConfig` 基于 Pydantic，启用 camelCase/snake_case 双向别名与 `extra='allow'`，每个 channel 在自身 `__init__` 中解析私有字段；`paths.py` 提供配置文件路径。
- 安全与辅助：`network.validate_url_target` 对媒体 URL 做 SSRF 防护（拒绝 RFC1918、link-local、cloud metadata 等私有段）；`helpers.py` 提供图片 MIME 检测、消息分片、Markdown 表格转换等通用工具；`transcription.GroqTranscriptionProvider` 通过 Groq Whisper API 完成音频转写，由 BaseChannel 暴露 `transcribe_audio` 供子类调用。
依赖方向：具体 channel → base → bus/events → bus/queue；manager 反向持有 channels 与 bus；config/schema 被 manager 与 channel 共同消费，无循环依赖。
