模块以 `__init__.py` 暴露统一 API（`read_snapshot`/`refresh_snapshot`/`pending_changes`/`read_changes`/`current_state`/`clear_changes`），内部按职责拆分为四个子文件：
- `entity.py`：纯数据类 `Entity`（含 `fingerprint`）与 `ChangeEntry`，不依赖任何 I/O。
- `adapters.py`：每个 surface（notebook/cowriter/book/partner/kb/chat/quiz）一个只读函数，将磁盘/SQLite 源转换为 `list[Entity]`，通过 `_READERS` 分发表由 `read_entities(surface)` 调度；所有读取均捕获异常并返回空列表以保证健壮性。
- `diff.py`：纯函数 `diff_snapshots(prev_fp, curr_fp, label_map, prev_label_map)`，基于集合差集计算 added/removed/modified 三类 `ChangeEntry`。
- `store.py`：负责 `<memory_dir>/snapshot/<surface>/state.json`（原子写入 via tmp+rename）与 `changes.jsonl`（append-only JSON Lines，逐行追加）的读写、迭代与清理。
依赖方向单向：`__init__` → `adapters` + `diff` + `store`，`store` 仅依赖 `entity`，无反向引用；外部通过 `Surface` 类型与 `paths.memory_root()` 定位存储根目录。
