- 所有持久化操作都通过 `_run(self._xxx_sync, ...)` 包装，将阻塞的 sqlite3 调用放入 `asyncio.to_thread` 并在 `asyncio.Lock` 下串行，避免事件循环阻塞。
- JSON 字段统一使用 `_json_dumps` / `_json_loads` 序列化/反序列化，并以 `default=str` 降级非可序列化对象，防止单条事件破坏整条消息的持久化。
- 新增列通过 `_initialize` 中的 `PRAGMA table_info` 检测 + `ALTER TABLE ADD COLUMN` 实现向前兼容的数据库迁移，而非要求外部脚本。
- Store 实现遵循 `SessionStoreProtocol` 的异步方法签名，调用方仅依赖协议类型，从而可在 SQLite 与 PocketBase 之间无感切换。
- 管理类采用模块级单例模式（如 `get_unified_session_manager()` 中的全局 `_instance` 延迟初始化）。
- Turn 状态机使用固定集合约束（如 `_FINAL_TURN_STATUSES = {completed, failed, cancelled, rejected}`），所有状态落库前先做白名单归一化。
