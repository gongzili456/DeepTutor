模块以 `__init__.py` 作为统一门面，通过 `importlib` 懒加载 `provider_runtime` 和 `test_runner` 以避免循环依赖；内部按职责拆分为若干子模块：
- `loader.py`：YAML 配置加载入口，解析 `data/user/settings/*.yaml`，注入运行时路径（workspace、logs、knowledge_bases_dir 等），并提供 `get_agent_params` / `get_chat_params` 从 `agents.yaml` 合并默认值。
- `runtime_settings.py`：核心 `RuntimeSettingsService`，以 JSON 文件持久化 system/auth/integrations/document_parsing/pageindex/llamaindex/graphrag/lightrag 等设置，每个 `load_*`/`save_*` 方法对应一个配置文件，并通过 `_apply_*_process_overrides` 将进程环境变量（如 `BACKEND_PORT`、`MINERU_API_TOKEN`）作为部署级覆盖层写入返回结构；`ensure_runtime_settings_files` 是启动时唯一初始化钩子。
- `model_catalog.py`：`ModelCatalogService` 维护 `model_catalog.json`，对 llm/embedding/search/tts/stt/imagegen/videogen 七类服务的 profile 进行归一化与原子保存（tempfile + os.replace）。
- `knowledge_base_config.py`：`KnowledgeBaseConfigService` 管理 `kb_config.json`，负责 KB 注册、RAG 提供者归一化、迁移标记 `needs_reindex` 以及读写全局默认检索模式。
- `provider_runtime.py`：定义 `EmbeddingProviderSpec`、`VoiceProviderSpec` 等数据类，聚合各嵌入/语音/视频/图像生成提供者的元信息，并暴露 `resolve_llm_runtime_config` / `resolve_embedding_runtime_config` / `resolve_search_runtime_config` 等解析函数供上层装配。
- `embedding_endpoint.py`、`origins.py`、`capabilities_settings.py`、`context_window_detection.py`、`launch_settings.py`、`test_runner.py`：分别处理嵌入端点别名与校验、CORS origin 归一化、能力开关、上下文窗口检测、启动参数、配置测试运行器等辅助能力。
依赖方向单向向外：本模块依赖 `deeptutor.services.path_service`、`deeptutor.runtime.home`、`deeptutor.services.provider_registry` 等底层服务，不反向被业务逻辑直接引用，仅通过包级函数暴露。
