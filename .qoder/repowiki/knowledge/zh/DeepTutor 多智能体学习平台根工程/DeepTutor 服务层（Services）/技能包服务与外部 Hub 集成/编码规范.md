- 所有对外暴露的可变状态均通过 `@dataclass(slots=True)` 数据类封装（如 `SkillInfo`、`SkillDetail`、`HubVerdict`、`Option`），并以 `to_dict()` 或 frozen 属性提供稳定序列化视图。
- 文件 I/O 统一通过 `get_path_service().get_*_file(...)` 解析路径，再结合 try/except 宽容地处理缺失或损坏的设置文件（`.tags.json`、`.hub-lock.json`、`skill_hubs.json`、`skill_hub_auth.json`）。
- 对来自外部的字符串输入（技能名、标签、hub 引用）一律先经正则归一化再校验，失败时抛出领域异常（`InvalidSkillNameError`、`InvalidTagError`、`HubError`），而非返回 None。
- 不可信来源的批量操作（`install_tree`、`_extract_skill_zip`、`preflight_skill_dir`）采用“白名单 + 上限”模式：允许的后缀集合、最大文件数、总字节数、单文件大小、压缩比阈值逐项拒绝并记录 skipped 原因。
- 可选的重型依赖（如 `deeptutor.services.sandbox`）采用函数内局部 import 的延迟加载方式，保证 skill 模块在无沙箱环境中仍可正常导入。
- 前端展示用的枚举值集中在独立模块（`taxonomy.py`），同时导出 value 的 `frozenset` 校验集与带 `label(locale)` 的选项元组，使 CLI、API、Web 共享同一份分类数据。
