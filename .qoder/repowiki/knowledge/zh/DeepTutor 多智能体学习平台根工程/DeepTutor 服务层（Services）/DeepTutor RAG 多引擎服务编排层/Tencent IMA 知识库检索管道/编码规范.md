- 对外 API 采用 async 方法并以统一字典结构返回结果，错误路径通过 `_error_result` 注入 `error_type` 字段而非抛出异常。
- 配置对象使用 `@dataclass(frozen=True)` 定义不可变类型（如 `ImaConfig`），并通过工厂函数从原始 dict 解析并校验必填字段。
- HTTP 客户端每次请求新建 `httpx.AsyncClient` 并在 `async with` 中自动关闭，通过可选 `transport` 参数注入测试替身。
- 外部服务错误通过继承自 `RuntimeError` 的专用异常类分层表达（`ImaAPIError` → `ImaAuthError` / `ImaRateLimitError`），由上层捕获并映射为用户可读信息。
- 模块通过 `__all__` 显式声明公共导出，内部辅助函数以下划线前缀命名（如 `_sources_from_items`、`_render_context`）。
