- 对外暴露的类/函数统一通过 `__all__` 显式声明导出符号，内部辅助函数保持私有命名（以下划线开头）。
- 对不可靠的外部输入（CLI 输出、JSON 行、attachment 字段）采用防御式解析：先做类型/格式检查再取值，失败时记录 warning 日志并返回默认值而非抛错。
- 长文本输出统一经过 `_truncate`/`_inline` 等裁剪函数限制字符数（如 `_MAX_FIELD_CHARS=4000`、`_TOOL_HEADER_CHARS=160`），避免前端渲染卡顿。
- 流式事件通过稳定的 `merge_id`（形如 `txt:{msg_id}:{idx}` 或 `rsn:{msg_id}:{idx}`）关联增量 delta 与最终完整块，使前端能按行原地更新。
- 可选依赖（`pty`、`pyte`、`AttachmentStore`）采用运行时 `import` 并在缺失时优雅降级，保证模块在无对应环境时仍可被导入。
