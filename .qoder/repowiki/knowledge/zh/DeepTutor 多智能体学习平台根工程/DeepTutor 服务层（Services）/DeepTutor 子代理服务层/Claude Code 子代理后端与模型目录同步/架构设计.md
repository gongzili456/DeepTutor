本模块由三个职责清晰的文件组成：
- `claude_code.py` 实现 `SubagentBackend` 接口（`kind='claude_code'`），通过 `process.probe_version`/`stream_process_lines` 启动 `claude -p --output-format stream-json --verbose`，将 stdout 上的 NDJSON 事件流解析为 `SubagentEvent`（EVENT_TEXT / EVENT_REASONING / EVENT_TOOL / EVENT_TOOL_RESULT / EVENT_ERROR / EVENT_LOG）经 `on_event` 回调实时推送；同时维护一个基于 `message.id` + content block index 的 `merge_id` 累积器，把 Anthropic `stream_event` 的 `content_block_delta` 增量合并成逐字输出的文本行。
- `claude_models.py` 在 POSIX 环境下用 `pty.fork` + `pyte` 终端模拟器驱动 `claude` 打开 `/model` 选择器，正则解析每行 picker row 得到 `{slug, display_name}`，写入 `data/user/settings/claude_models_cache.json`，提供 `sync_claude_models`（异步，走 `asyncio.to_thread`）和 `load_cached_claude_models` 两个入口。
- `images.py` 是纯工具模块，把上游传入的 attachment（inline base64 或 `/api/attachments/...` 本地 URL）落盘到临时目录，返回路径供各 backend 转发（Claude Code 通过 Read tool 读取）。
依赖方向单向向外：本模块仅依赖 `subagent.base/process/types/config`、`path_service`、`storage`，不被其他 subagent 反向引用。
