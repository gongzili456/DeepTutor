本模块由两个相互独立的子能力组成：
- `session_state.py`：通过 `get_path_service().get_session_workspace('chat', session_id)` 定位每个聊天会话工作区下的 `loaded_tools.json`，以 `{"loaded_tools": [...]}` 结构记录模型已调用的 deferred tool 名称集合，供后续对话轮次复用，避免重复加载。
- `user_config.py`：维护位于 `data/system/user-mcp/<owner>.json` 的用户级 MCP 配置（通过 `SYSTEM_ROOT` 解析），与部署级 `mcp.json` 分离，从而避开执行沙箱挂载路径，防止跨用户篡改；读取时调用 `_assert_self_service_allowed` 强制拒绝 `stdio`/命令型 server，仅允许 `sse`/`streamableHttp` 并校验 URL；通过 `MAX_SERVERS_PER_OWNER=8` 限制单账户连接数，并以 `RejectedServer` 返回被拒条目以便 UI 解释；写操作采用 read-modify-write + 临时文件 + `os.fsync` + `os.replace` 的原子写入模式。
- `__init__.py` 作为包门面，仅重新导出 `config`、`manager`、`network`、`session_state` 中的公共 API（如 `load_loaded_tools`、`record_loaded_tools`），不在此处定义业务逻辑。依赖方向单向：本模块依赖 `deeptutor.services.path_service`、`multi_user.paths`、`mcp.config`、`mcp.network`，不被同层其他模块反向引用。
