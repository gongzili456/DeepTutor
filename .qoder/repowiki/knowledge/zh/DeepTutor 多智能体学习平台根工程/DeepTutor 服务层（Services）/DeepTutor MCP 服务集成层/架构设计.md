模块以 manager.py 中的 MCPConnectionManager 为进程级单例中枢，按 (owner, server_name) 维度维护连接：SHARED_OWNER 对应管理员部署配置（含 catalog 渲染的内置条目与 pageindex_server 注入的内置端点），其他 owner 对应用户配置（由 user_config 读取并按用户隔离）。config.py 定义 MCPServerConfig 模型，catalog/loader.py 将其从 JSON 模板与凭据渲染出来；secrets.py 在连接时把 ${secret:...} 引用解析为真实值，避免落盘；network.py 对非管理员用户的 URL 做 SSRF 校验；oauth.py 在传输层注入 httpx.Auth 完成无交互令牌刷新。manager._run_server 为每个服务器启动独立 asyncio.Task，持有 AsyncExitStack 管理 mcp.ClientSession 生命周期，并通过 ToolRegistry 注册 MCPToolAdapter（仅共享 owner 进入全局注册表，用户 scope 走 scoped registry overlay 避免名称冲突）。session_state.py 持久化每会话已加载工具列表，reload/ensure_scope 通过 diff 配置实现热重载与冷作用域回收。
