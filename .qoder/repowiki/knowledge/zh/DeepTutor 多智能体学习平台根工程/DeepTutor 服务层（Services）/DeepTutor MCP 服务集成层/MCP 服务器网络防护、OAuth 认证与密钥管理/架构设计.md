模块由三个职责正交的文件组成，均通过 `deeptutor.multi_user.paths.owner_secrets_dir` 将数据落盘到每个 owner 的 secrets 树中（sandbox 不可挂载），从而保证多租户安全：
- `network.py`：定义部署态与严格态两套被禁 IP 段（link-local/cloud-metadata/0.0.0.0/8 vs 额外加入 loopback 与 RFC1918/CGNAT），在连接时通过 `socket.getaddrinfo` 实时解析并校验，提供同步与 `asyncio.to_thread` 异步两个入口。
- `oauth.py`：封装 `mcp.client.auth.OAuthClientProvider`，实现 `OwnerTokenStorage`（读写 `{owner}/private/mcp-oauth/<server>.json`，含 tokens 与 client 注册）、交互式授权流（`begin_authorization`/`complete_authorization` 通过全局 `_PENDING` 字典以 `state` 匹配回调）与非交互模式（抛出 `AuthorizationRequired`），并通过 `CALLBACK_PATH` 暴露给 API 路由。
- `secrets.py`：维护 `{owner}/private/mcp/<server>.json` 键值对，支持 `${secret:server/field}` 引用语法，提供 `resolve_references`（递归遍历 dict/list）与 `resolve_url_references`（仅替换 query 值）两个解析入口。
依赖方向单向：`oauth.py` 与 `secrets.py` 不互相引用，`network.py` 独立；三者共同被上层 MCP 连接逻辑消费。
