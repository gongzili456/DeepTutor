- 所有持久化实体使用 Pydantic BaseModel 定义，并通过 `model_config = ConfigDict(extra='allow' | 'ignore')` 控制字段扩展策略。
- ID 生成统一使用 `_new_id(prefix)` 工厂（如 `bk_`、`ch_`、`pg_`、`blk_`），时间戳统一使用 `_now()`。
- Block 生成器继承 `BlockGenerator` 并声明类属性 `block_type: BlockType`，通过 `get_block_registry()` 懒加载注册表查找实例。
- 错误分类通过 `_classify_failure` 将异常消息映射为 `json_parse`/`timeout`/`rate_limit`/`provider_error` 等类别，并写入 `block.metadata.failure`。
- 长流程分阶段通过 `BookStream.stage(STAGE_*)` 上下文管理器包裹，并在阶段内调用 `bstream.progress(...)` 和 `bstream.book_event(...)` 推送进度与事件。
- 每本书的后台编译使用独立的 `_BookRuntime`（含 `asyncio.Queue`、`queued` set、worker task 与 lock），由 `BookEngine._ensure_worker` 按需创建并在空闲时回收。
