- 能力类遵循 LoopCapability 协议，通过 `is_active` 条件激活并以 `pre_loop` 返回 PromptBlock 注入结果，不注册 answer-loop 工具。
- 提示词集中存放在 `prompts/{en,zh}/explore_context.yaml`，运行时通过 `_load_prompts` 按语言选择并按键路径（如 `loop.system`）深度解析，缺失时回退到硬编码默认值。
- 对外部重依赖（如 `explorer` 模块）采用函数内延迟 import，以避免 capability 包导入时的循环依赖。
- 所有面向用户的文案（状态、标题、强制结束指令等）统一通过 `_t(key, default=...)` 从 prompts 字典读取，禁止在代码中硬编码多语言字符串。
- LLM 调用结果通过 `StreamBus.stage` + `stream.progress/thinking` 上报 trace，使用固定 `EXPLORE_STAGE` 与 `call_kind='context_exploration'` 标记上下文探索阶段。
- 对弱模型或不支持 tool calling 的 provider 提供 single-pass 回退路径，确保即使预调查失败也不会阻断答案循环。
