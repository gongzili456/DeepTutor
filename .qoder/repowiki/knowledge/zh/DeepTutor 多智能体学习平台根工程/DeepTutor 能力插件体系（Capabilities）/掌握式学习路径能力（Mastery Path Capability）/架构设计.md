模块以 `capability.py` 中的 `MasteryPathCapability` 作为入口：在 `run` 中标记 `mastery_mode`、解析并清洗 `mastery_path_id`，然后委托给 `AgenticChatPipeline` 复用标准聊天管道。

- `loop.py` 实现 `MasteryLoopCapability`，作为聊天循环的 turn-scoped hook：当 `context.metadata['mastery_mode']` 为真时注入系统提示（从 `prompts/{en,zh}/system.md` 按语言加载），并通过 `augment_kwargs` 把 `_mastery_path_id` / `_session_id` / `_turn_id` 注入到 mastery 工具调用中。
- `tools.py` 定义五个 `BaseTool` 子类（`MasteryStatusTool`、`MasteryQuizTool`、`MasteryGradeTool`、`MasteryAssessTool`、`MasteryBuildTool`），每个工具内部懒加载 `LearningService(LearningStore())` 以避免导入循环，并依赖 `deeptutor.learning.policy` 做门限判定与间隔重复调度；所有持久化键由服务端生成（如 `<path>_m<i>_kp<j>`），模型不可控存储键。
- `choices.py` 是纯函数层，负责选择题选项的解析、格式化、答案归一化以及从历史 `ask_user` 事件恢复旧版选项体，保持工具层只做编排。
- 依赖方向单向向外：本模块 → `deeptutor.agents.chat`、`deeptutor.core.*`、`deeptutor.learning.*`，不反向被 learning 引用；工具名常量 `MASTERY_TOOL_NAMES` / `MASTERY_TOOL_TYPES` 集中声明，供 capability manifest 和 pipeline mount 策略共享同一份清单。
