本模块由两部分组成：
- `assets/`：纯静态资源目录，按用途分层组织——`README/` 存放 AR/CN/ES/FR/HI/JA/PL/PT/RU/TH 十种语言的 README；`figs/` 存放系统架构图与 Web UI 各功能模块截图（按 web-1.4.6+、webui 子目录划分），历史截图保留在 `figs-archive/`；`releases/past_releases/` 以 `verX-Y-Z.md` 命名归档每个版本的发布说明；`roster/` 提供 forkers 与 stargazers 统计 SVG。
- `.github/`：GitHub 工程化配置——`workflows/` 定义四个独立流水线：`docker-release.yml`（release 触发，基于 QEMU + Buildx 构建 linux/amd64/arm64 双架构镜像推至 GHCR）；`pypi-release.yml`（release 触发，校验 tag 与 `deeptutor/__version__.py` 一致后通过 Trusted Publishing 发布 wheel）；`tests.yml`（push/PR 触发，并行执行 lint、web node tests、import-check、Python pytest 并在 `test-summary` 汇总结果）；`sync-upstream.yml` 用于同步上游仓库。`ISSUE_TEMPLATE/` 通过 `config.yml` 禁用空白 issue 并提供 bug_report/docs/feature_request/question/eduhub 模板；`pull_request_template.md` 规定 PR 需勾选受影响模块并运行 pre-commit。
依赖方向单向：工作流仅读取仓库源码与静态资源，不反向依赖业务代码。
