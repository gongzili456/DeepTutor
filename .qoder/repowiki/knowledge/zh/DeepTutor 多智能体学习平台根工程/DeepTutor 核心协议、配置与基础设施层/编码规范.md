- 公共协议以抽象基类 + dataclass 元数据的形式定义（`BaseTool`/`BaseCapability` 搭配 `ToolDefinition`/`CapabilityManifest`），子类必须实现 `get_definition`/`execute` 或 `run` 方法。
- 流式事件统一通过 `StreamBus.emit(StreamEvent(...))` 发出，并使用 `bus.stage(name, source=...)` 上下文管理器成对包裹 STAGE_START/STAGE_END。
- 配置项采用 Pydantic `BaseModel`/`BaseSettings` 分层声明（如 `LLMRetryConfig` 嵌入 `Settings.retry`），并通过 `model_config.env_prefix` 与 `env_nested_delimiter` 从环境变量加载。
- 全局单例通过模块级 `_instance` 或 `get_*` 工厂函数暴露（`EventBus.get_event_bus`、`settings`、`_event_bus`），并在 `reset()`/`stop()` 中显式清理状态。
- 国际化文案以 `{name: {en: ..., zh: ...}}` 的嵌套字典集中管理，并提供 `localized_description(values, language)` 按 `language` 首字符选择语言。
- 日志输出统一走 `configure_logging` 安装的 handlers，并通过 `bind_log_context` 注入结构化字段，文件输出固定为 JSONL 格式的 `deeptutor.jsonl`。
