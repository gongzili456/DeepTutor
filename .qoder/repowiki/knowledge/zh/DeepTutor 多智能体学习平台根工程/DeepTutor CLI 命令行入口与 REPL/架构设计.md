模块以 `main.py` 中的 Typer 应用为根，通过 `app.add_typer(...)` 注册 partner/chat/kb/skill/memory/plugin/config/session/notebook/provider/book 等子应用，并在启动时调用各子模块的 `register(app)` 将命令挂载到对应子应用；`__main__.py` 仅做 `from .main import main; main()` 以便通过 `python -m deeptutor_cli` 或 `deeptutor` 可执行。

- 顶层命令：`run`（单次 capability 执行）、`start`（后端+前端）、`serve`（uvicorn API 服务）。
- 共享基础设施集中在 `common.py`：统一的 Rich Console、TurnRequest 构建器、`run_turn_and_render` / `regenerate_and_render` / `stream_turn_as_json` 流式渲染、`TurnStreamRenderer` 状态机（处理 stage/content/thinking/tool_call/tool_result/error/result/done/wait_for_input 等事件）、`_SigintInterceptor` 实现 Ctrl-C 中断当前 turn、工具结果环形缓冲 `_tool_result.ToolResultBuffer` 支持 `/show` 展开。
- 交互 REPL 在 `chat.py`，维护 `ChatState` dataclass，解析 `/quit /new /tool /cap /kb /history /notebook /show /config /refs /session /status /regenerate` 等内置命令，并通过 `maybe_run(asyncio.run(...))` 运行异步循环。
- 资源管理子命令各自独立文件（`kb.py`、`session_cmd.py`、`notebook.py`、`memory.py`、`plugin.py`、`provider_cmd.py`、`config_cmd.py`、`init_cmd.py`、`book.py`），统一通过 `def register(app: typer.Typer)` 模式挂载。
- Skill 子系统（`skill.py`、`skill_login.py`、`skill_prompts.py`）封装从 hub（EduHub/ClawHub）搜索、安装、登录、发布流程，安全门控包含 hub 安全 verdict → 安全解压 → frontmatter 适配 → `.hub-lock.json` 记录。
- 依赖方向单向向外：CLI 层只消费 `deeptutor.app.DeepTutorApp`、`deeptutor.knowledge.*`、`deeptutor.services.*`、`deeptutor.runtime.*` 等核心包，不反向被业务逻辑引用。
