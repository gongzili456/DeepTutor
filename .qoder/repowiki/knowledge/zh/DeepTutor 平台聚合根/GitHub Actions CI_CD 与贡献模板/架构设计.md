本模块是纯配置型 leaf，按职责拆分为四个子目录：
- `workflows/`：每个文件一个独立 GitHub Actions 工作流，彼此无依赖，通过 `on.paths` 精确触发范围。
  - 质量门禁：`tests.yml`（Python 3.11–3.14 + Node 22 + Redis 服务 + Playwright E2E + import-check + lint/import-linter）、`repository-hygiene.yml`（`scripts/check_workspace_hygiene.py`）。
  - 构建发布：`docker-release.yml`（GHCR 多平台镜像，QEMU+Buildx，SBOM）、`pypi-release.yml`（PEP 440 标签校验 + Trusted Publishing + 模块 wheel 分发）、`desktop-release.yml`（macOS ARM/Intel + Windows 三端签名/公证/安装器，产物附到 Release）。
  - 专项：`modules.yml`（模块化 wheel 生命周期）、`memory-evaluation.yml`（内存评估回归）、`sync-upstream.yml`（每日从 HKUDS/DeepTutor 合并 main）、`desktop-notarization-diagnostics.yml`（Apple notarytool 诊断）。
- `pull.yml`：第三方 action `pull` 的配置，将 `HKUDS:main`/`HKUDS:dev` 以 `hardreset` 方式拉取到 fork 的对应分支。
- `pull_request_template.md`：强制 PR 目标 `dev` 分支，列出受影响模块复选框及 pre-commit/测试/文档清单。
- `ISSUE_TEMPLATE/`：bug_report / feature_request / question / docs / eduhub / config.yml 等 GitHub 表单。

依赖方向单向向外：仅消费 `actions/*` 官方 action、`astral-sh/setup-uv@v6`、`pypa/gh-action-pypi-publish`、`docker/*` 系列以及仓库内 `scripts/` 下的 Python 脚本；不引入任何运行时代码。
