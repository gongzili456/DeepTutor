本模块是 deeptutor 的根契约层，按职责拆分为若干独立文件，彼此之间仅通过类型与抽象类耦合：
- `tool_protocol.py`：Level 1（工具）协议，定义 `BaseTool` 抽象基类、`ToolDefinition`/`ToolParameter` JSON Schema 描述、`ToolResult` 返回值以及 `ToolLookup` Protocol，供所有内置与插件工具实现。
- `capability_protocol.py`：Level 2（能力）协议，定义 `TurnCapability` 抽象基类、`CapabilityManifest` 静态元数据与 `StreamBusProtocol` 输出端口，被 deep_solve 等能力继承。
- `context.py`：运行时数据载体，以 dataclass 形式提供 `UnifiedContext`（贯穿一次 turn 的全部输入/状态）、`TurnRuntimeContext`（不可序列化的执行回调）、`WorkspaceRuntimeContext`（工作区路径）和 `Attachment`。
- `turn_request.py`：基于 Pydantic `BaseModel` 的请求值对象，集中校验用户提交（含 legacy runtime config 迁移），是应用层与运行时的统一入口契约。
- `stream.py`：统一的流式事件枚举 `StreamEventType` 与 `StreamEvent` dataclass，被 capability/tool 共同消费。
- `trace.py`：生成 UI 可渲染的 trace 元数据（call_id / phase / label / call_kind），并维护 `ANSWER_BEARING_CALL_KINDS` 白名单以同步前端行为。
- `__init__.py`：聚合导出公共 API，并通过 `__getattr__` 延迟加载 `BaseCapability` 别名以兼容旧代码。
依赖方向单向向下：上层（capabilities/tools/runtime）依赖本模块，本模块内部仅从 `response_languages` 反向引用语言校验，不引入任何业务逻辑。
