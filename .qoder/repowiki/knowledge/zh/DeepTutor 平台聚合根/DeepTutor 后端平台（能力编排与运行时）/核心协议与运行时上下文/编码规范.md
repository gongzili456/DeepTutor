- 对外暴露的运行时数据使用 dataclass（如 Attachment、UnifiedContext、StreamEvent、ToolResult），不可变或只读结构额外标注 frozen=True/slots=True。
- 请求值对象统一继承 pydantic.BaseModel 并设置 `model_config = ConfigDict(extra="forbid")`，通过 field_validator/model_validator 处理字段级与整体校验。
- 抽象接口通过 abc.ABC + @abstractmethod 声明（BaseTool、TurnCapability），同时用 typing.Protocol 表达只读视图（StreamBusProtocol、ToolLookup）。
- 向后兼容通过模块级 `__getattr__` 拦截旧名称（BaseCapability → TurnCapability）并抛出 DeprecationWarning，而非直接保留废弃符号。
- trace 元数据通过 build_trace_metadata / derive_trace_metadata / merge_trace_metadata 三件套构造与合并，避免在调用点手写字典。
- 每个模块末尾显式列出 `__all__` 控制包级导出，由 `core/__init__.py` 再聚合一次作为公共 API 门面。
