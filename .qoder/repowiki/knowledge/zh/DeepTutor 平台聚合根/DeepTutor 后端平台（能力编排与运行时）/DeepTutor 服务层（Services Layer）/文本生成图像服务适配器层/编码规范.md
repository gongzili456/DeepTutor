- 适配器实现统一继承 `BaseImagegenAdapter` 并覆写 `async generate(self, prompt, config, *, n=1)`，返回值固定为 `(bytes, content_type)` 元组列表，对外屏蔽 b64_json、data URI、远程 URL 等差异。
- HTTP 请求通过 `httpx.AsyncClient(timeout=config.request_timeout)` 上下文管理，并在异常分支中统一包装为 `GenerationProviderError` 向上抛出。
- 响应体解析失败或业务校验失败时一律抛 `GenerationProviderError`，由上层 `generation_http` 统一转换为 HTTP 错误。
- 配置字段按需拼装 payload：仅当 `config.size`/`quality`/`style`/`response_format` 非空时才写入请求体，让上游 provider 使用其默认值。
- 适配器通过 `build_auth_headers(config.auth_style, config.api_key)` 注入认证头，并通过 `**config.extra_headers` 透传额外头部，避免在每个适配器重复实现鉴权逻辑。
