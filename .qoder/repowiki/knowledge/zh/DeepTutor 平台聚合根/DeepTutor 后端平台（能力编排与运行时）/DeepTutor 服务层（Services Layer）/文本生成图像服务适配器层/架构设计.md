模块以 `base.BaseImagegenAdapter` 抽象类定义统一接口 `generate(prompt, config, *, n)` → `list[(bytes, content_type)]`，所有具体实现均继承该抽象。

- `config.py` 中的 `ImagegenConfig`（`@dataclass(slots=True)`）是配置数据载体，同时承载模型标识、认证信息（`auth_style` + `api_key`）、可选的 provider 参数（`size`/`quality`/`style`/`response_format`）以及超时与轮询参数，作为模型目录与 HTTP 适配器之间的只读契约。
- `adapters/__init__.py` 维护一个全局单例注册表 `IMAGEGEN_ADAPTERS`，键为 `adapter` 字段值；`get_imagegen_adapter(name)` 按名称解析，未知键抛出 `GenerationProviderError`，默认回退到 `openai_compat`。
- 三个适配器分别覆盖不同协议：`OpenAICompatImagegenAdapter` 调用 `POST {base}/images/generations`，兼容 OpenAI DALL·E / Volcengine Seedream 及任意 OpenAI 兼容网关；`ChatCompletionsImagegenAdapter` 走 `chat/completions` 端点并以 `modalities: ["image", "text"]` 驱动 OpenRouter Flux / Gemini image 等模型；`DashScopeImagegenAdapter` 根据 model 前缀在 legacy `text2image` 与 multimodal `image-generation/generation` 两条异步协议间切换，并自带基于 `poll_interval`/`poll_timeout` 的任务轮询循环。
- HTTP 细节（鉴权头构造、错误提升、base64 解码、路径拼接）全部委托给外部 `deeptutor.services.generation_http`，本模块不直接处理 HTTP 状态码或认证逻辑，依赖方向单向指向该共享库。
