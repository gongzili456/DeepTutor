- 对外暴露的 heavy 子模块（llm、embedding、rag、prompt、search、setup、session、config）通过 `__init__.py` 的 `__getattr__` 懒加载，避免包导入时的循环依赖与冷启动成本。
- 面向外部供应商的能力（LLM、Embedding、Image/Voice/Video 生成、Search、Parsing、Sandbox、Subagent）统一采用 base 协议 + `adapters/` 多实现 + 顶层 factory/client 装配器的适配器模式。
- Provider 选择由 `config` 中加载的 YAML/JSON 配置驱动，通过 `provider_registry` / `factory` 类根据名称动态实例化对应后端。
- 子模块间共享的全局状态（路径、缓存、密钥池、单飞锁）通过顶层 `path_service`、`singleflight_cache`、`keypool` 等单例访问，而非直接 import 子模块内部变量。
