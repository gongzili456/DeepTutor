模块以 `protocol.py` 中定义的 `SessionStoreProtocol` / `SessionRepository` / `TurnRepository` / `MessageRepository` 四个 `@runtime_checkable Protocol` 作为唯一抽象边界，`sqlite_store.py` 和 `pocketbase_store.py` 是两套等价实现；`__init__.py` 的 `get_session_store()` 根据 `is_pocketbase_enabled()` 在两者之间切换并缓存实例。

- 存储层：SQLite 通过 `sqlite3` + JSON 列实现，PocketBase 通过 HTTP 调用远端 collection；两者共享 `workspace_preferences` 升级路径、搜索归一化、事件预览压缩等工具。
- 回合运行时：`turn_runtime.py` 暴露兼容门面 `TurnRuntimeManager`，由 `turns/` 子包中的六个职责单一的服务类组合而成（`TurnRequestPreparer` → `TurnContextAssembler` → `LearningTurnAdapter` → `TurnExecutor` → `TurnLifecycle` → `SessionTitleService`），并通过 `_turn_runtime_shared.py` 共享 `_TurnExecution`、`_LiveSubscriber`、标题清洗、工作区模式解析等值层逻辑。
- 并发与多进程：`TurnLifecycle` 用 `asyncio.Lock` + `_executions` 字典维护进程内执行上下文，配合可选的 `RuntimeCoordinator` 做 lease 续租、命令分发与 cancel；`fencing_token` 用于跨 worker 的乐观锁状态转换；`migration_lock.py` 通过文件锁串行化 schema 迁移。
- 作用域隔离：`scope.py` 定义 `StoreScope`，SQLite 按用户分库、PocketBase 按 `user_id`+`workspace_id` 过滤，`pocketbase_scope()` 将 URL 与 owner 编码进 cache key 以区分多租户实例。
- 辅助能力：`artifact_attachments.py`、`quote_attachments.py`、`attachment_parsing.py` 处理附件；`native_history.py`、`model_history.py`、`legacy_migration.py`、`thread_attribution.py`、`organization.py`、`usage_statistics.py`、`usage_recovery.py`、`ask_user_trace.py`、`event_preview.py`、`search.py`、`selection_grounding.py`、`source_inventory.py`、`workspace_preferences.py` 分别承担历史回放、统计、恢复、溯源、搜索、选择还原、来源清单、偏好迁移等横切关注点。
