模块按职责拆分为六个平级子文件，由 `__init__.py` 统一暴露公共 API：
- `dataset.py`：基于 Pydantic 的 `EvalCase` / `EvalDataset` 数据模型，支持 `.jsonl`/`.ndjson`/`.json` 三种格式加载，负责字段校验、去重与错误上下文。
- `matching.py`：纯文本相关性判定层，提供 `RelevanceMatcher` + `MatchPolicy`（`min_ratio`/`min_tokens`），通过归一化包含匹配与 token overlap 两种方式把引擎返回的 chunk 映射到 gold passage 索引集。
- `metrics.py`：纯函数式指标计算层，输入为每 rank 的 gold 索引集合（`Hits`），输出 `QueryMetrics`，实现 recall/precision/ndcg/mrr/hit/average_precision 及宏平均聚合。
- `runner.py`：编排层 `RetrievalEvaluator`，驱动生产搜索路径（默认调用 `deeptutor.tools.rag_tool.rag_search`），兼容 `sources` 与 `content/context_only` 两种引擎返回形态，产出 `QueryEvaluation`。
- `report.py`：汇总层 `EvalReport`，提供 JSON 序列化、CLI summary 行以及 per-case metrics 格式化。
- `diff.py`：对比层 `diff_reports`，将两个报告（对象或 `to_dict`）对齐到 `_Normalized` 后按 query id 比较，输出 `MetricDelta`/`CaseDelta`/`EvalDiff`。
依赖方向单向：runner → matching + metrics → report；diff 仅消费 report/metrics 的输出形状，不反向依赖 runner。所有指标均为无状态纯函数，保证分数可复现、可与外部引擎无关地回归。
