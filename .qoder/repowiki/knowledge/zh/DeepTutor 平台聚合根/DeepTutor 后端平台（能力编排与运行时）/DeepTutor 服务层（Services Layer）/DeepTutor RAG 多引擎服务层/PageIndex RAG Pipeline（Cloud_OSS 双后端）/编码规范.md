- 对同步 SDK 调用统一使用 `asyncio.to_thread` 包装，避免阻塞事件循环（见 `submit_document`、`delete_document`、`build_sdk_tool_bundle`）。
- Cloud 与 OSS 两条路径通过常量 `CLOUD_PROVIDER` / `OSS_PROVIDER` 与 `provider` 参数分支处理，而非继承或子类化（manifest、client 构造、tool 前缀、supported extensions 均如此）。
- 所有 JSON 持久化使用 `atomic_write_json`，manifest/meta 读写失败时回退到空结构并记录 warning，保证幂等与容错。
- 对外暴露的类/函数在文件末尾以显式 `__all__` 列表声明导出符号，未列出的内部符号保持私有。
- 需要延迟导入的重型依赖（如 `pageindex` SDK、`KnowledgeBaseConfigService`、`shutil`）放在函数体内按需 import，避免模块级冷启动开销。
