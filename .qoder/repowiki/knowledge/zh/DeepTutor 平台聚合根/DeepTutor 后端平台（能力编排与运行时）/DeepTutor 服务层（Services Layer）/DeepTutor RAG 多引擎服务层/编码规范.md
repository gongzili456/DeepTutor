- 新增 provider 需在 factory.py 中声明字符串常量、加入 KNOWN_PROVIDERS 并在 _build_pipeline 中添加分支，同时向 list_pipelines 注册元数据。
- 每个 pipeline 子目录遵循 config/pipeline/client 三段式：config 暴露 is_*_available 与 SUPPORTED_MODES，pipeline 继承 base.RAGPipeline 实现抽象方法，client/probe 负责外部 HTTP 调用。
- 可选依赖的导入一律放在函数体内并用 try/except 捕获异常，使缺失可选包时不影响主程序启动。
- provider 名称统一小写化并通过 normalize_provider_name 归一化，version_matches_provider 通过 entry.provider 或 signature 字段区分不同 provider 的索引版本。
