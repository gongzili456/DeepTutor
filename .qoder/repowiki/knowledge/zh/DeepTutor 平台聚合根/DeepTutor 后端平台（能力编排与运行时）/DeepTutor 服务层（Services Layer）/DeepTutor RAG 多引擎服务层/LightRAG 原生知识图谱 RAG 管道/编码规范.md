- 对第三方 SDK 的导入一律延迟到函数体内（如 `from lightrag import ...`、`from deeptutor.services.config import load_lightrag_settings`），避免在包加载阶段强制安装可选依赖。
- 所有 LightRAG 返回对象在进入业务逻辑前都进行类型断言（`isinstance(result, dict)`、`isinstance(data, list)` 等），不匹配时抛出 `LightRagContractError` 而非静默降级。
- 对外暴露的错误采用专用异常类（`LightRagBatchError`、`LightRagNeedsReindexError`、`LightRagContractError`、`LightRagNotAvailableError`、`LightRagNotConfiguredError`），并在 `__all__` 中显式导出。
- 异步任务统一通过 `worker.run_in_worker_loop` + `OwnerLoopBridge` 在独立线程事件中执行，避免阻塞主事件循环，并通过 `io_bridge.raise_if_cancelled()` 支持取消传播。
- 知识库状态变更（initialize/add_documents）均包裹在 `write_ownership(kb_dir)` 上下文管理器内，确保同一 KB 的并发写入被串行化。
- LightRAG 配置通过 settings 读取并以 `*_kwargs_from_settings` 工厂函数聚合（query_kwargs/indexing_kwargs/constructor_kwargs），缺失键时回退空字典或默认值，不向上抛出。
