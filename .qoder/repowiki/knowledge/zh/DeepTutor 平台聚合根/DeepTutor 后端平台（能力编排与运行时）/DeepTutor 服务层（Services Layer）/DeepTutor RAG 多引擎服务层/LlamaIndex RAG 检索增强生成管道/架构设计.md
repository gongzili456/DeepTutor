模块以 `pipeline.py` 中的 `LlamaIndexPipeline` 为对外入口，暴露 `initialize`/`add_documents`/`search`/`delete` 四个异步方法；内部按职责拆分为：
- `embedding_adapter.py`：自定义 `CustomEmbedding(BaseEmbedling)` 适配器，桥接 DeepTutor 的 embedding provider，并通过 `ContextVar` 在同步 executor 中传递进度回调与操作级 embed_model。
- `document_loader.py` + `ingestion.py`：负责从文件到 LlamaIndex `Node` 的转换与分块。
- `vector_store.py`：FAISS / SimpleVectorStore 等后端的选择与加载。
- `retrievers.py`：组合 `QueryFusionRetriever`（向量 + BM25），支持 hybrid/vector 两种 profile，并缓存 BM25 sidecar 与 scoped index。
- `rerank.py`：可选 cross-encoder 重排序。
- `storage.py`：版本化目录管理、可恢复重建（`.embedding-checkpoint.json` + `.building.json`）、索引缓存（LRU + mtime freshness token）、嵌入校验。
- `config.py`：通过 `load_llamaindex_settings()` 读取运行时配置，提供 `RetrievalConfig`/`VectorIndexConfig` dataclass。
- `exercise_lookup.py`：针对编号习题的结构化查找旁路。
依赖方向单向向内：pipeline → storage/retrievers/embedding_adapter/config，storage → ingestion/vector_store/retrievers，无反向引用。所有耗时 I/O（嵌入、BM25 构建、FAISS 持久化）均通过 `run_in_executor` + `copy_context().run` 放入线程池，并由 `_run_with_stall_guard` 监控进度心跳防止卡死。
