- 每个后端在 `pipeline.py` 中以 `PROVIDER = "..."` 常量标识自身，并在 `search` 返回结果中附带该字段，便于上层统一分发。
- `search` 方法统一捕获异常并通过 `_error_result`/`_error` 静态方法返回含 `error_type`（`not_configured` 或 `retrieval_error`）的标准错误字典，而非向上抛出。
- 索引相关方法 `initialize` 与 `add_documents` 对外部托管后端直接抛 `RuntimeError`，明确声明索引所有权不在 DeepTutor 内。
- `delete` 仅删除 DeepTutor 侧的 KB 指针，绝不触碰用户的外部资源，因此一律返回 `True`。
- HTTP 客户端通过构造参数的 `client_factory=None` 注入，生产路径延迟 import `.client` 以避免循环导入，测试路径传入 mock 工厂。
- 配置解析集中在 `config.py` 的 `config_from_entry`，对缺失字段抛出专用的 `*NotConfiguredError(RuntimeError)`，使 pipeline 层无需关心具体字段名。
