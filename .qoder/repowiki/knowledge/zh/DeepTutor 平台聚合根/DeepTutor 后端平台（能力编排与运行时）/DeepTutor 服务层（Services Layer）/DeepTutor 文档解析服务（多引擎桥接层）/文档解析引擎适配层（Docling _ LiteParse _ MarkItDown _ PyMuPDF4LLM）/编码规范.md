- 每个引擎在 `engine.py` 中暴露一个 `XxxParser` 类，实现 `is_available`（`importlib.util.find_spec`）、`resolve_config`、`supported_formats`、`signature`、`is_ready`、`parse` 等协议方法。
- 外部第三方库仅在 `parse` 内部 `import` 引入，避免在路由/就绪探测路径触发重型依赖加载。
- `is_ready` 返回 `ReadinessReport`，未安装使用 `reason="not_configured"`，版本过旧使用 `reason="update_required"`，Docling 缺模型使用 `reason="models_missing"`。
- `parse` 中将底层异常统一包装为 `ParserError` 再抛出，保留原始消息以便 UI 展示。
- Markdown 输出统一落盘到 `workdir / f"{source_path.stem}.md"`，编码固定为 utf-8。
- 当引擎支持图片提取时，将图片写入 `workdir/images/` 并通过正则重写 Markdown 中的 `![alt](path)` 链接为相对 `images/<name>` 形式，空 images 目录会被清理。
