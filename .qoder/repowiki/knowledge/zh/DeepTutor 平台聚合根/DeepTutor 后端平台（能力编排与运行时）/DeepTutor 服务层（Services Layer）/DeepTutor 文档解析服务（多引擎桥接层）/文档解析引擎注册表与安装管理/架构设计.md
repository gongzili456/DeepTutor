模块由四个文件构成清晰的职责分层：
- `factory.py` 是对外入口，维护 `_ENGINE_LOADERS`（名称→零参加载器）和 `_ENGINE_META`（UI 元数据），通过延迟 import 每个 `.engine` 子模块避免可选依赖在启动时导入；`get_parser` 还会查询 `deeptutor.modules.catalog.manifests` 校验模块是否启用。
- `formats.py` 仅做只读聚合，把 docling/markitdown/mineru/liteparse/pymupdf4llm/tika 各子模块暴露的 format 常量取并集，供 KB 上传路由使用。
- `_install.py` 提供 `BackgroundJobManager`（单例 `_manager`），封装 pip 安装与模型下载的 subprocess 生命周期，使用线程泵 + cursor 协议向 UI 增量推送日志；`ENGINE_PIP_SPECS` 从 manifests 动态生成，`ENGINE_MODEL_DOWNLOADERS` 固定列出支持一键下载的脚本（如 docling-tools）。
- `_versions.py` 用 `importlib.metadata.version` + `lru_cache` 提供轻量版号读取，并实现不依赖 packaging 库的 `version_at_least` 比较。
依赖方向单向向外：本模块被上层 parsing 服务消费，自身仅反向依赖 `modules.catalog` 与 `services.parsing.base/types`，不引入具体 engine 实现。
