- 引擎类通过命名函数（如 `_mineru_class`）包裹延迟 import，并在 `_ENGINE_LOADERS` 字典中以配置常量键名注册，避免在 registry 顶层直接 import 第三方包。
- 对外 API 通过 `__all__` 显式声明导出符号，未列出的内部对象（如 `_normalize_name`、`_manager`）视为模块私有。
- 需要跨进程/热更新失效的缓存（`package_version`、`markitdown_supported_formats`）在安装后通过 `invalidate_caches()` 与 `cache_clear()` 主动清理。
- 对子进程的 argv 来源采用白名单模式（`ENGINE_MODEL_DOWNLOADERS`、`ENGINE_PIP_SPECS`），并使用 `# nosec B603/B404` 注释说明非用户输入的安全依据。
