- 所有 MinerU 相关错误统一抛出 `MinerUError`（继承自 `ParserError`），并附带可选的 `code`（如 `LocalParseReason` 枚举值）和截断后的 `detail` 诊断片段。
- 输入格式校验集中在 `formats.py` 的 `MINERU_SUPPORTED_FORMATS` / `MINERU_PDF_FORMATS` 常量，各后端分支均复用该集合而非硬编码后缀判断。
- 子进程输出通过 `on_output` 回调以至少 0.5s 间隔限速上报，避免 MinerU tqdm 进度条淹没 trace panel。
- 长时间任务采用「临时 attempt 目录 + atomic state.json」模式：成功时原子替换目标目录，失败时保留 `.incomplete` 状态供诊断与重试复用。
- 云后端对 PDF 超过 `max_pages_per_part` 页时自动切片，并通过 `SliceCheckpoint` 缓存每片已完成的 zip 以支持中断恢复。
- 配置读取走 `resolve_mineru_config()` 适配器，业务代码只消费不可变的 `MinerUConfig` dataclass，不直接访问 `document_parsing.json` 的原始结构。
