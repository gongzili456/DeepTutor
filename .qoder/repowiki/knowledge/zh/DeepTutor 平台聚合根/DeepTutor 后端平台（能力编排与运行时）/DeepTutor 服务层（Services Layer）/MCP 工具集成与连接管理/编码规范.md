- 对外部可选依赖（`mcp`、`httpx`、`deeptutor.runtime.registry.tool_registry.get_tool_registry`）一律在函数体内部延迟 import，避免包缺失时启动期抛错。
- 所有 JSON 配置文件写入采用 tmp 文件 + `os.fsync` + `os.replace` 原子替换模式，并在 finally 中清理 `.tmp`。
- 敏感数据（静态 secret、OAuth token/client）不进入服务器配置，而是以 `${secret:<server>/<field>}` 引用形式保存，连接时由 `secrets.resolve_references` 在内存中解析。
- 用户可配置的服务器名称统一使用正则 `^[a-zA-Z0-9][a-zA-Z0-9_-]{0,63}$` 校验，并以该名称作为文件系统文件名。
- 连接状态变更通过 `_mark_failed` / `_connect` / `_disconnect` 等私有方法集中处理，外部只暴露 `ensure_started`、`reload`、`status`、`adapters_for` 等稳定接口。
- 错误信息经 `describe_connect_failure` 展开 anyio ExceptionGroup 叶子节点并去重，避免向用户展示无意义的包装异常。
