- 每个外部 agent 通过继承 `SubagentBackend` 并以类属性声明 `kind`/`display_name`/`cli_command`，再由 `registry._BACKENDS` 集中实例化注册。
- 后端在 `detect()` 中调用 `process.probe_version([cli, "--version"])` 判断可用性，并在 `detail` 中返回人类可读的诊断信息。
- `consult()` 统一通过 `process.stream_process_lines(cmd)` 流式消费子进程输出，将每一行 JSON 映射为 `SubagentEvent(kind=..., text=..., raw=...)` 并通过 `on_event` 回调回传。
- 文本增量拼接使用稳定的 `merge_id` meta 字段（如 `text:{call_id}`、`reason:{call_id}`），使 sidebar 能在同一行上原地增长而非覆盖。
- 工具调用与其结果通过 `pending_tools` 字典按 `call_id` 缓冲，确保并行分派时先 emit TOOL_CALL 再紧跟着 emit TOOL_RESULT，保持 trace 成对可读。
- 所有对外暴露的字符串字段经 `process.truncate_field` / `process.compact_field` 截断到 `MAX_FIELD_CHARS`，避免超长事件撑满 sidebar。
