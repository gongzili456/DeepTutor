模块以 `base.BaseVideogenAdapter` 抽象类定义统一接口（`submit_task` + `generate`），所有具体实现均继承该基类。
- `config.VideogenConfig` 是数据类，承载模型名、provider/adapter 选择、认证方式、分辨率/时长/纵横比等生成参数以及 `request_timeout` / `poll_interval` / `poll_timeout` 三类轮询预算。
- `adapters/__init__.py` 维护全局 `VIDEOGEN_ADAPTERS` 注册表，由 `get_videogen_adapter(name)` 按配置中的 `adapter` 字段解析出单例适配器；默认回退到 `async_task`。
- `adapters.async_task.AsyncTaskVideogenAdapter` 实现通用的 submit → poll → download 生命周期：使用 `httpx.AsyncClient` 调用 `{base_url}/contents/generations/tasks`，在 `video_poll_budget` 异步超时上下文内循环轮询状态，成功后下载视频字节并推断 MIME。
- `adapters.dashscope.DashScopeVideogenAdapter` 完全独立实现 DashScope 的 `services/aigc/video-generation/video-synthesis` 提交路径与 `tasks/{id}` 查询路径，内置 `480p/720p/1080p` × 纵横比的像素映射表及固定 5 秒模型校验。
- `adapters.xai.XaiVideogenAdapter` 仅重写 `_submit_path` / `_status_url` / `_build_submit_payload` / `_extract_*` 四个钩子，复用父类的轮询与下载逻辑。
- 依赖方向单向向下：适配器 → base/config → `deeptutor.services.generation_http`（共享 HTTP 工具与 `GenerationProviderError`）；模块不反向依赖上层服务。
