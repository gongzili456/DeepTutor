- 每个适配器类暴露 `submit_task` 与 `generate` 两个协程方法，返回 `(bytes, content_type)` 元组，错误统一包装为 `GenerationProviderError`。
- 长任务轮询被包裹在 `video_poll_budget(poll_timeout, task_id)` 异步上下文中，超时后抛出带 task_id 的 `GenerationProviderError`。
- Provider 差异点通过静态方法钩子（`_submit_path` / `_status_url` / `_build_submit_payload` / `_extract_task_id` / `_extract_status`）覆盖，避免复制轮询主循环。
- HTTP 请求统一使用 `httpx.AsyncClient(timeout=config.request_timeout)`，并通过 `raise_for_provider(resp, action)` 将非 2xx 响应转为 `GenerationProviderError`。
- 进度回调通过可选的 `ProgressFn` 参数透传，适配器仅在轮询间隔处调用 `self._notify(progress, message)` 输出人类可读状态。
- 新 Provider 通过向 `adapters/__init__.py` 的 `VIDEOGEN_ADAPTERS` 字典注册键值对即可接入，无需修改核心调度逻辑。
