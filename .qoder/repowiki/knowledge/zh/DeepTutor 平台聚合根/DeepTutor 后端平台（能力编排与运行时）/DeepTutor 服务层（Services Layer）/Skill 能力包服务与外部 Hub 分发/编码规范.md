- 对外暴露的数据契约统一使用 `@dataclass(slots=True)` 定义（SkillInfo/SkillDetail/SkillSummaryEntry/HubSkillRef/HubVerdict/FetchedSkill 等），并通过 `to_dict()` 方法产出 JSON 兼容字典。
- 错误路径通过细粒度异常类表达（SkillNotFoundError/SkillExistsError/SkillReadOnlyError/SkillImportError/InvalidTagError/HubError 等），而非返回码或字符串消息。
- 对不可信输入（import 支持文件、zip 解压、read_skill_file 相对路径）采用白名单 + 尺寸/数量上限 + 路径穿越检查的多层防御，失败时 fail-closed。
- 可选的外部依赖（sandbox、path_service、httpx、yaml）通过函数内 late import 引入，避免在模块加载期强耦合。
- SKILL.md frontmatter 解析统一通过正则 `^---\s*\n(.*?)\n---\s*\n?` 匹配后交由 `yaml.safe_load`，缺失或非法 frontmatter 回退为空 dict。
- 持久化设置文件（`.tags.json`、`.hub-lock.json`、`skill_hubs.json`、`skill_hub_auth.json`）读取一律 try/except (OSError, JSONDecodeError) 并返回空结构，保证配置损坏不阻断运行。
