- 每个 mode 文件只实现算法流程，基础设施（prompt 加载、LLM 调用、事件发射、原子写）统一从 `modes/_runtime.py` 导入，避免在各 mode 中重复样板代码。
- 对外部 I/O（LLM、文件系统、settings）一律通过 `on_event: OnEvent | None` 回调上报阶段事件（`trace_loaded` / `progress` / `facts_extracted` / `refs_dropped` / `doc_updated` / `done`），供 workbench 追踪。
- Prompt 以 `{name}.yaml` 形式存放在 `prompts/en` 与 `prompts/zh` 下，结构固定包含 `system` 与 `user` 两个字段，缺失任一字段会抛 `RuntimeError`。
- 对磁盘写入统一采用原子模式：`meta.py` 用 `tempfile.mkstemp` + `os.replace`，`_runtime.write_doc_atomic` 用 `asyncio.to_thread(_atomic_write)`，保证崩溃后不会留下半写文件。
- L2/L3 增量通过 `*.meta.json` 侧车文件的 id-set diff 判定“自上次更新以来新增”的内容，而非依赖 mtime 或时间戳。
- mode 之间通过运行时条件 import（如 `from deeptutor.services.memory.consolidator.modes.dedup import run_dedup`）避免循环依赖，仅在真正触发 auto_after_update 时才加载下游 mode。
