模块按 `__init__.py` 注释明确划分为三层 + 横切能力：
- L1 追踪：`trace.py` 以 append-only JSONL 按 surface+日期写入，`ids.py` 生成 ULID 风格的 trace/entry id。
- L2/L3 文档模型：`document.py` 定义纯函数 `parse`/`serialize`，处理带 footnote 引用和 HTML 锚点 `<!--m_xxx-->` 的 Markdown；`ops.py` 提供 add/edit/delete 原子操作器；`paths.py` 通过 `PathService` 做 per-user 路径隔离（由 `store.py` 通过 context var 惰性注入）。
- 门面层：`store.MemoryStore` 是无状态单例（`get_memory_store()`），统一封装 emit/read/update_l2/update_l3/apply_ops_payload/write_preference/overview，所有 I/O 写路径经 `_lock_for` 按文件粒度加 `asyncio.Lock`，并通过 `asyncio.to_thread(atomic_write_text, ...)` 落盘。
- 合并器 `consolidator/`：`modes/_runtime.py` 提供共享运行时（prompt YAML 缓存、LLM 流式调用 + `<think>` 过滤、原子写 + undo checkpoint），`update.py`/`audit.py`/`dedup.py`/`merge.py` 是三种独立模式，由 `run_update/run_audit/run_dedup/run_merge` 暴露；`prompts/{en,zh}/` 按语言存放 prompt YAML 及 `_meta.yaml` 焦点/分区映射。
- 快照子系统 `snapshot/`：`adapters.py` 适配不同 workspace 源，`entity.py` 定义 Entity/EntityStamp，`diff.py` 计算指纹差异，`store.py` 持久化 `state.json` + `changes.jsonl`，对外仅暴露 read_snapshot/pending_changes/refresh_snapshot 等无副作用 API。
- 依赖方向：`store` → `consolidator` → (`document`, `trace`, `paths`)；`snapshot` 独立于 consolidator；顶层 `evaluation.py`/`evaluation_rag.py`/`recall.py` 为评测工具，不反向依赖 consolidator。
- 迁移：`store.migrate_v1_if_needed` 与 `migrate_partner_surface_if_needed` 在启动时把旧 v1 文件和 `tutorbot` surface 迁到 `backup/<ts>/` 并改写引用。
