本模块以 `store.MemoryStore` 为唯一对外入口，将三个子层按职责切分并通过共享契约协作：
- core_layer（`document.py`/`ops.py`/`trace.py`/`ids.py`/`paths.py`）定义 L1→L2→L3 的数据模型、纯函数式变更操作符与 ULID 风格 ID 生成器；`paths.py` 暴露 `Surface`/`L3Slot` 枚举及路径解析，被 consolidator 与 snapshot_store 共同消费。
- consolidator 在 L2/L3 上运行基于 chunk 的 LLM 流水线（audit/dedup/update/merge），其 prompt 由 `consolidator/prompts/{en,zh}/*.yaml` 驱动，并以 YAML `_meta.yaml` 声明模式版本。
- snapshot_store 独立于 consolidator，扫描同一 L1 trace 目录计算 surface 指纹差异并回放 `changes.jsonl`，用于外部工具对比工作区状态。
- 顶层 `settings.py`/`evaluation*.py`/`recall.py` 提供配置与评测入口，不直接耦合子层内部实现。
跨子层的关键约束是：所有持久化路径由 `paths.memory_path_service_override` 统一接管，所有 ID 由 `ids.new_trace_id/new_entry_id` 生成，确保 L1/L2/L3 文件命名与位置一致。
