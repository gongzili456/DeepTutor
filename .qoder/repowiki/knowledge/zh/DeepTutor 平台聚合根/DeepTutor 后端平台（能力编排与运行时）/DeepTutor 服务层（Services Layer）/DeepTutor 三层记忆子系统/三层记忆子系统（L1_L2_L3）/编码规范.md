- 对外入口集中在包级 `__init__.py` 的 `__all__` 中显式导出，内部实现细节（如 consolidator 的 `_filter_banned`、`_parse_ops_response`）以 `_` 前缀标记为私有但仍被 store 测试复用。
- 所有对磁盘的写操作都先通过 `MemoryStore._lock_for(path)` 获取按文件路径键控的 `asyncio.Lock`，再用 `asyncio.to_thread(atomic_write_text, path, text)` 在阻塞线程中执行，避免阻塞事件循环。
- Consolidator 各 mode（update/audit/dedup/merge）共用 `modes/_runtime.py` 提供的 `load_prompt`/`call_llm`/`write_doc_checkpoint`，mode 文件只负责算法逻辑，不直接处理 prompt 加载或 LLM 调用。
- Prompt 与 focus 元数据按语言分目录组织（`prompts/en/`、`prompts/zh/`），通过 `_lang_code(language)` 将任意 language 归一为 `en` 或 `zh`，并以 `(lang, name)` 为 key 做进程内缓存。
- 文档解析同时兼容新旧两种 Markdown 格式（新格式用 `[^label]` + `<!--m_id-->`，旧格式用 `[^m_id]`），保证已有存量文件可继续读取并在下次保存时迁移到新布局。
- 快照子系统区分 `Entity`（含内容）与 `EntityStamp`（仅 id/label/fingerprint/timestamp），diff 与 refresh 路径一律在 stamp 级别工作，避免不必要的全文 I/O。
