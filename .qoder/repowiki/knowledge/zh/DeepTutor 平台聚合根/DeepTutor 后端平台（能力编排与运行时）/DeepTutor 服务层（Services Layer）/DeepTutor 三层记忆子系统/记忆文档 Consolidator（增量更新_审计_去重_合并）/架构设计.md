模块按职责分层：
- `modes/` 暴露四个用户可见入口 `run_update` / `run_audit` / `run_dedup` / `run_merge`（由 `modes/__init__.py` 聚合），其中 `update.py` 通过 `layer` 分派到 `_run_update_l2` / `_run_update_l3`；`_shims.py` 提供兼容旧 API 的 `consolidate_l2/l3`。
- `_runtime.py` 集中所有跨 mode 的基础设施：prompt YAML 加载（`prompts/{en,zh}` 目录 + `_meta.yaml` 聚焦配置）、SSE `OnEvent` 事件发射、LLM 流式调用（失败回退到非流式）、Document 原子写入与 undo checkpoint 注册。
- 顶层纯函数工具：`chunker.py`（字符级边界感知分块）、`line_doc.py`（带行号的 Document 视图 + replace/delete/insert 编辑）、`references.py`（引用池校验 + raw-trace 标注）、`guards.py`（banned phrase 过滤）、`parse.py`（遗留 ops 解析）、`meta.py`（`*.meta.json` 侧车文件读写，L2 存 `seen_entity_refs`，L3 存 `seen_l2_entry_ids`）。依赖方向单向：modes → _runtime/chunker/references/meta/guards/parse → 上层 memory.document/ops/paths/settings，不反向依赖 modes。
- 语言与提示词通过 `load_prompt(name, language)` 从 `deeptutor/services/memory/prompts/{en,zh}/` 下同名 YAML 读取，并以 `(lang, name)` 为键做进程内缓存；`_meta.yaml` 提供 surface/slot 的 focus 与 sections 映射。
