- 公共 API 通过模块级 `__all__` 显式白名单导出，未列出的符号视为内部实现。
- 对外函数使用 `from __future__ import annotations` 配合 PEP 604 风格类型注解（如 `dict[str, Any]`、`str | None`）。
- 语言相关逻辑集中在 `language.py`，调用方通过 `normalize_language` / `is_chinese` / `language_directive` 获取行为，避免在各业务模块重复实现语言判断。
- Prompt 文件的磁盘访问采用「候选目录 × 语言回退链」的双重循环，并在解析失败时打印 Warning 而非抛异常，保证单个 prompt 缺失不影响整体启动。
