模块以 `service.py` 中的 `PersonaService` 为唯一核心类，封装 persona 文件（`data/user/workspace/personas/<name>/PERSONA.md`）的 YAML frontmatter + Markdown body 解析、CRUD 与上下文渲染；`__init__.py` 仅做 re-export。

- 数据模型：`PersonaInfo`（列表用）、`PersonaDetail`（详情用）两个 `@dataclass(slots=True)`，均带 `source: user|admin` 与 `to_dict()`。
- 文件系统约定：每个 persona 一个目录，文件名固定 `PERSONA.md`，通过 `_NAME_RE` 校验 slug（`^[a-z0-9][a-z0-9-]{0,63}$`）。
- 内置预设：`presets/<teacher|peer|research-assistant>/PERSONA.md` 随包分发，由 `seed_presets()` 非破坏性复制到目标 root，标记为只读（`source=admin`）。
- 遗留迁移：`migrate_legacy_skills()` 将 `skills/<peer|teacher|research-assistant>/SKILL.md` 迁入 personas 并丢弃 `triggers/tags`；`_adopt_workspace_personas()` 把历史按 workspace 存储的 persona 目录提升到账户级，二者在首次 `get_persona_service()` 时自动执行且幂等。
- 依赖方向：向上依赖 `deeptutor.multi_user.paths`（账户/管理员路径）、`deeptutor.services.workspace`（工作区枚举），被上层 skill / prompt 组装层消费；自身不暴露 HTTP 接口。
- 实例缓存：模块级 `_instances` dict 按 root path 缓存单例，`get_persona_service()` 是入口工厂。
