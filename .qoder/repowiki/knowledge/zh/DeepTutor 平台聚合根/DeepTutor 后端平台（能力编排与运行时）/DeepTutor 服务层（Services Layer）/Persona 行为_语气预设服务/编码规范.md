- Persona 实体以 `@dataclass(slots=True)` 定义并配套 `to_dict()` 方法输出统一字典结构，便于 API 序列化。
- 所有对 persona 名称的操作先经 `_validate_name()` 走同一正则校验，再派生目录/文件路径，避免重复校验逻辑。
- 写入前统一经 `_normalize_content()` 重写 frontmatter（name+description），保证已存文件的元数据与当前值一致。
- 错误处理使用细粒度自定义异常（`PersonaNotFoundError` / `PersonaExistsError` / `InvalidPersonaNameError`），而非泛抛 ValueError。
- 对外暴露的持久化操作（`seed_presets`、`migrate_legacy_skills`）都声明幂等语义并通过返回已处理名称列表供调用方确认。
- 模块级单例通过 `_instances` dict 按 root path 键缓存，由 `get_persona_service()` 工厂函数懒加载并在首次访问时触发迁移。
