本模块由三个并列文件组成，职责清晰分层：
- `openai_http_client.py` 是底层 HTTP 构建器，基于 `httpx.AsyncClient` 封装 SSL 校验开关（`DISABLE_SSL_VERIFY`）、OpenRouter 归属头、会话亲和性 `x-session-affinity`、重试预算与无效 CA 环境变量清理，对外暴露 `openai_sdk_client_kwargs` / `build_openai_http_client` 供上层 SDK 实例化。
- `cloud_provider.py` 通过 `aiohttp` 调用远端 `/models`，按 `binding`（openai/anthropic）选择认证头风格，并复用 `minimax_models.prioritize_model_names` 做模型排序；同时保留已弃用的 `complete`/`stream` shim 转发到 `factory`。
- `local_provider.py` 同样用 `aiohttp` 枚举本地服务，优先探测 Ollama `/api/tags`，回退到 OpenAI 兼容 `/models`，也暴露相同的弃用 shim。
依赖方向单向向下：provider 模块仅消费 `utils.build_auth_headers`/`collect_model_names` 与 `config.load_system_settings`，不反向引用 SDK 构造逻辑；SSL 禁用状态在两个 provider 中以线程安全的全局锁 + 一次性日志模式实现，避免并发重复告警。
