- 具体 provider 仅实现 `chat` / `chat_stream` / `get_default_model`，重试、指标埋点、瞬态错误判定与图片回退由基类 `LLMProvider._call_with_retry` 统一封装。
- provider 对外统一返回 `LLMResponse` 对象，错误路径通过设置 `finish_reason="error"` 而非抛出异常，使上层无需区分成功响应与可重试错误。
- 可选 SDK 依赖（如 `codebuddy_agent_sdk`、`anthropic`、`openai`）采用运行时 `import` 或模块级延迟导入，缺失时抛出明确提示错误的 `RuntimeError`。
- SSE/SDK 流式事件消费统一通过 `consume_sse` / `consume_sdk_stream` 解析，并以 `on_content_delta` / `on_reasoning_delta` / `on_tool_args_delta` 回调向上传递增量文本与工具参数。
- 工具调用参数解析遵循「严格 JSON → json_repair 修复 → 截断告警」三级回退策略，无法修复时以 `{"raw": ...}` 兜底。
- 模块顶层通过 `_LAZY_TYPES` 映射与 `__getattr__` 实现类名的延迟加载，避免启动期导入所有 provider 实现。
