- 对外 API 函数在入口处从 `kwargs` 中显式 pop 出框架字段（如 `extra_headers`、`reasoning_effort`、`image_data`、`image_mime_type`、`image_filename`），再交给内部 `_sanitize_call_kwargs` 剔除保留字段后透传到底层 provider。
- 需要运行时 provider 实例的路径使用延迟 import（`from . import factory`、`from . import cloud_provider`、`from . import local_provider`）以避免循环导入和冷启动开销。
- 可配置常量集中定义在模块顶层（`DEFAULT_MAX_RETRIES`、`DEFAULT_RETRY_DELAY`、`DEFAULT_EXPONENTIAL_BACKOFF`、`STREAM_CONTROL_TOKENS`、`DEFAULT_STREAM_COALESCE_*`），供 `complete`、`stream` 及测试共享。
- 对可能缺失的属性一律使用 `getattr(self.config, ..., None)` 或 `getattr(current, ...)` 读取，保证旧版 `LLMConfig` 与新扩展字段共存。
- 进程级可变状态（`_client` 单例、`_provider_registry`）通过模块级变量 + 显式 `reset_*` 函数（`reset_llm_client`、`reset_runtime_provider_pool`）进行清理，便于设置重载与测试隔离。
