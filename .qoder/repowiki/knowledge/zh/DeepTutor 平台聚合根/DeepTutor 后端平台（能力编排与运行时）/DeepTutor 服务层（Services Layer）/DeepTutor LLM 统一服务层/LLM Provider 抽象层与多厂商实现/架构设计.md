模块以 `base.py` 中的 `LLMProvider` ABC 为唯一契约，统一暴露 `chat` / `chat_stream` / `get_default_model` / `aclose` 以及带重试与图片回退的 `chat_with_retry` / `chat_stream_with_retry`；所有具体提供商均继承该基类。

- 公共数据模型：`ToolCallRequest`、`LLMResponse`、`GenerationSettings` 在 `base.py` 中定义，作为 provider 间交换的统一格式。
- 重试与容错集中在基类：通过 `_RETRYABLE_HTTP_STATUS_CODES`、`_TRANSIENT_ERROR_MARKERS`、三个 HTTP 状态码正则模式判断可重试错误，并在失败时执行最多三次指数退避（1/2/4s），同时支持 Stage-2 视觉降级（非瞬态错误 + 含图片消息 → 自动去掉图片重发）。
- 子包 `openai_responses/` 提供 Responses API 的 SSE/SDK 流解析器（`parsing.py`）、工具/消息转换器（`converters.py`），被 `openai_codex_provider.py` 和 `azure_openai_provider.py` 复用。
- SDK 适配桥 `sdk_bridge.py` 将 CodeBuddy Agent SDK 的消息流、中断语义、MCP tool 前缀 (`mcp__deeptutor__`) 转换为 DeepTutor 的 `ToolCallRequest`，供 `codebuddy_provider.py` 与 `claude_code_provider.py` 共享。
- 每个厂商一个文件（`anthropic_provider.py`、`azure_openai_provider.py`、`openai_codex_provider.py`、`openai_compat_provider.py`、`github_copilot_provider.py`、`claude_code_provider.py`、`typescript_provider.py`、`codebuddy_http_provider.py`、`codebuddy_provider.py`），按自身传输方式（httpx SSE、SDK stream、HTTP JSON）实现 `chat` / `chat_stream`。
- 模块入口 `__init__.py` 使用 `importlib.import_module` + `__getattr__` 实现延迟加载，避免启动时导入全部可选 SDK（Anthropic、OpenAI、CodeBuddy 等）。
