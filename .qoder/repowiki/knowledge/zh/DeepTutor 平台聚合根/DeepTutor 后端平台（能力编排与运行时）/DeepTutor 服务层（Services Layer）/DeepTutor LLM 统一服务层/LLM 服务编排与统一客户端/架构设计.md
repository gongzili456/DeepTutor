模块由三层组成：
- 门面层 `client.py`：暴露 `LLMClient` 类与 `get_llm_client()` 进程级单例，同时通过 `build_model_func_for_config` 生成适配通用 `llm_model_func` / `vision_model_func` hook 的异步 callable；初始化时可选地把 `OPENAI_API_KEY` / `OPENAI_BASE_URL` 写入环境变量以兼容下游 OpenAI SDK。
- 编排层 `factory.py`：核心入口 `complete` / `stream` / `complete_with_config` / `fetch_models`，承担参数到 `LLMConfig` 的合并（`_resolve_call_config`）、提供商选择（`_resolve_provider_spec`，优先级：显式 binding → gateway → model 匹配 → 本地服务器推断 → fallback），并通过 `provider_factory.get_runtime_provider` / `build_isolated_provider` 获取底层 provider 执行；`stream` 内部用 `asyncio.Queue` + `_on_reasoning_delta` / `_on_content_delta` 回调实现 `<think>` 包裹与按字符/时间 coalesce 的增量输出；错误经 `error_mapping.map_error` 统一映射。
- 注册表层 `registry.py`：基于全局 `_provider_registry` 字典的轻量装饰器 `@register_provider`，用于动态发现 provider 类。
依赖方向单向：client → factory → provider_core/provider_factory/provider_registry，不反向引用。
