- 对外暴露的选择对象（如 `LLMSelection`）仅携带 ID 字段，敏感凭据留在服务端 catalog 中，仅在运行时解析。
- 对 catalog 的读取一律通过 `_service(catalog)` 辅助函数安全取嵌套 dict，缺失键返回空 dict 而非抛错，使 UI 列表与后台任务在配置不完整时仍可降级。
- 需要临时改变模型的作用域通过 contextmanager（`task_llm_scope`）或 activate/reset 配对（`activate_llm_selection` + `reset_llm_selection`）管理，并在 finally 中恢复 token。
- 所有异常路径都记录 debug 日志并静默回退到默认行为（继承主模型），因为标题/提示词等后台调用不应因配置错误而阻塞主流程。
- 新增后台调用需同时声明 `TaskKind` 成员与 `TASK_KINDS` 元组条目，以便 settings 页面自动列出该 kind。
