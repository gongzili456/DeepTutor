- 新增供应商通过实现 `BaseTTSAdapter` / `BaseSTTAdapter` 子类并在 `adapters/__init__.py` 的全局注册表中登记键值对完成接入。
- 所有面向用户的错误统一继承 `VoiceProviderError`，并通过 `public_message` 字段区分应用文案与上游原始响应体。
- 配置对象使用 `dataclass(slots=True)` 定义，避免可变状态，仅承载从 model catalog 解析出的只读参数。
- HTTP 超时统一通过 `asyncio.timeout(config.request_timeout)` 包裹适配器调用，并由 `synthesize_with_timeout` 转换为 `VoiceProviderTimeout`。
- 认证头构造走 `build_auth_headers(auth_style, api_key)`，根据 `auth_style` 常量（bearer / api_key_header / token）选择 Authorization 或自定义 `api-key` 头。
- 语音 ID 不在代码中硬编码，而是由 `discovery.discover_voices` 在运行时向供应商控制面查询，UI 选项仅包含模型能力元数据。
