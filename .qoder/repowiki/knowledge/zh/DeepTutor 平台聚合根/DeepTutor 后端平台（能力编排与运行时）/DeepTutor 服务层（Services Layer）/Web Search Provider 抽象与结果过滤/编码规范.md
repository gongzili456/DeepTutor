- Provider 类通过 `@register_provider(name)` 装饰器声明自身，并在类上暴露 `name`/`display_name`/`requires_api_key`/`supports_answer`/`BASE_URL`/`API_KEY_ENV_VARS` 等元数据供 registry 读取。
- 所有 provider 返回标准化的 `WebSearchResponse`（含 `query`/`answer`/`provider`/`citations`/`search_results`/`metadata`），由 `consolidation.AnswerConsolidator` 或上游消费方统一格式化。
- 敏感凭据一律通过 `search_provider_credentials(self.name)` 从 Settings > Search 的配置文件中按 provider name 拉取，而不是直接从环境变量读取。
- 对外部 API 调用（OpenAI Moderation、Google Web Risk）采用可注入的 `request_*` 参数以便测试替换，并在网络/JSON 异常时 fail-open 记录警告而不抛出。
- 源过滤采用分阶段拒绝理由字符串（如 `blocked_domain`、`unsafe_content`、`moderation_flagged`、`web_risk_threat`）累积到 `response.metadata['source_filter']`，便于调用方审计。
