- `main.py` 创建 FastAPI 实例并定义 `lifespan`：在启动阶段初始化 ApplicationContainer、EventBus、LLM 客户端、Cron/BackgroundLeaderSupervisor、MCP 连接池等跨模块共享资源，并在关闭时按相反顺序释放。
- `router_loader.RouterLoader` 是路由装配核心：支持“延迟加载”模式（`DEEPTUTOR_CHAT_ENGINE=typescript-native`），通过 `router_index.json` 指纹匹配在首次请求时才 import 对应路由模块，避免无关 schema 膨胀；OpenAPI 生成前会调用 `expand()` 展开所有 DeferredRouter。
- `module_routes.mount_module_routes` 从 `deeptutor.modules.catalog.manifests()` 读取已启用模块的 route 元数据，按 `auth` 字段映射为 `public/authenticated/learning/admin` 四种依赖注入策略，并把未启用模块的 HTTP 路径加入 `exclude_paths` 以返回 409。
- 全局中间件链：security_guard → json_error_boundary → WorkspaceActivityMiddleware → CORS → selective_access_log，保证错误响应始终为 JSON 且非 200 请求进入独立 access logger。
- 各子模块（chat_and_sessions、content_learning、notebook_and_outputs、co_writer_and_subagents、partners_integrations、settings_and_config、dashboard_and_voice）仅暴露 FastAPI APIRouter，不直接持有容器或生命周期逻辑，全部由本层装配与调度。
