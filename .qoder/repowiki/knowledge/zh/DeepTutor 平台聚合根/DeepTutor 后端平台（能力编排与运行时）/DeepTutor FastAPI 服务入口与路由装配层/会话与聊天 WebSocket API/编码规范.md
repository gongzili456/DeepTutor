- HTTP 异常统一通过 FastAPI 的 `HTTPException(status_code, detail=...)` 抛出，404 表示资源不存在，409 表示并发/状态冲突，501 表示后端能力未实现。
- 对可选功能模块（如 reading、mastery）采用运行时 `module_enabled("...")` 判断后动态 `from ... import`，避免在未启用时引入额外依赖。
- 需要阻塞 I/O 的辅助清理（学习路径解绑、附件删除、阅读目录遗忘、任务板移除）统一通过 `asyncio.to_thread` 放入线程池执行，防止阻塞异步事件循环。
- WebSocket 客户端命令先经 `TypeAdapter(ClientCommand).validate_python` 校验，再按 `msg_type` 分派到对应分支，未知类型返回 `unknown_message_type` 协议错误。
- WS 订阅生命周期用 `subscription_tasks: dict[str, asyncio.Task]` 跟踪，每个新订阅前调用 `stop_subscription(key)` 取消旧任务，并在 `finally` 中统一清理。
- Pydantic 请求体模型集中定义在路由文件顶部（如 `SessionOrganizationRequest`、`BranchSelectionRequest`、`QuizResultsRequest`），字段校验与默认值内聚于模型而非 handler 参数。
