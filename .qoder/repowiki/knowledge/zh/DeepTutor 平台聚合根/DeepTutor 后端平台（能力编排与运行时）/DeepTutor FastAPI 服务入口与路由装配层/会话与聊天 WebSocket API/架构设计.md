本模块由两个 FastAPI `APIRouter` 组成：
- `sessions.py`：REST 层，暴露 `/capabilities`、`/submission-replacement`、`/{session_id}` 及其子路径（`organization`、`threads`、`messages/{message_id}/events`、`quiz-results`、`branch-selection`、`migrate-watching`、`recycle-bin`、`restore`、`purge` 等），所有持久化通过 `deeptutor.services.session` 提供的 store 抽象（`get_session_store` / `get_sqlite_session_store`）访问，业务编排委托给 `TurnApplicationService`（通过 `_turn_application_service` 延迟从容器解析）。
- `unified_ws.py`：WebSocket 层，单一 `/ws` 入口，使用 `TypeAdapter(ClientCommand)` 校验客户端协议，将 `start_turn` / `cancel_turn` / `submit_user_reply` / `regenerate` / `user_input` 等命令转发到 `container.turns`，并通过 `subscribe_turn` / `subscribe_session` 建立可恢复的事件订阅任务。
依赖方向单向向外：router → services/session + services/workspace + app.container；不直接持有状态，store 与 turns 均通过工厂或容器注入。WS 认证复用 `auth.ws_require_auth`，工作区上下文在连接建立时通过 `reset_current_user` 绑定到当前 socket。
