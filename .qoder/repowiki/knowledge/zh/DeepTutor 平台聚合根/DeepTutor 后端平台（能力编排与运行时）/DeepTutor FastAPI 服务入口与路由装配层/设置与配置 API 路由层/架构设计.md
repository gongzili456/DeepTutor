本模块由四个并列的 FastAPI `APIRouter` 组成，职责按配置域切分：
- `settings.py` 是核心大文件，定义 `router`（管理员+用户）和 `public_router`（公开 UI 语言/主题），集中处理界面设置、模型目录（catalog）、提供者连接、Codex OAuth、运行时网络设置、文档解析引擎、语音预览等；通过 `_runtime_catalog_write()` 上下文管理器在写入 catalog 后原子重置 LLM/embedding 全局客户端，避免并发覆盖。
- `capabilities_settings.py` 仅做薄透传，GET/PUT `/settings` 委托给 `deeptutor.services.config.capabilities_settings`，遵循“API 只做传输、校验在 service 层”的模式。
- `mcp_settings.py` 使用 `Depends(require_admin)` 依赖注入实现管理员门禁，CRUD MCP 服务器并调用 `manager.reload()` 热重载。
- `agent_config.py` 提供只读的 `AGENT_REGISTRY` 静态字典，供前端渲染 Agent 图标/颜色/标签。

依赖方向单向向下：路由层 → `deeptutor.services.*`（config、mcp、model_selection、interface_settings、session 等），不反向被业务逻辑引用；权限控制通过 `get_current_user().is_admin` 或 `require_admin` 依赖完成。
