- 路由文件以模块级 `router = APIRouter()` 暴露，并在内部按需创建 `public_router` 用于无需鉴权的公开端点。
- 管理员敏感端点通过 `Depends(require_admin)` 依赖注入或手动检查 `get_current_user().is_admin` 进行授权，非管理员返回 403。
- 请求体使用 Pydantic `BaseModel` 声明，字段约束通过 `Field(ge=..., le=...)`、`Literal[...]` 与 `field_validator` 表达，而非手写校验逻辑。
- 对可写配置（catalog、MCP、capabilities）采用 GET 读状态 + PUT/PATCH 合并更新的 REST 风格，修改后调用对应 service 的 reload/reset 方法使新配置生效。
- 敏感数据（catalog secrets、tokens）在返回前经 `redact_catalog_secrets` 等函数脱敏，输入侧则用 tri-state（None 保持原值、"" 清空、字符串替换）区分未编辑与显式清除。
