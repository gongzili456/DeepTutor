模块由三个 FastAPI `APIRouter` 组成，职责清晰分层：
- `partners.py` 是核心路由，定义 `/api/partners/*` 下的 CRUD、生命周期、Soul 模板、渠道 onboarding（WeChat QR）、工具选项、导航与实时聊天（HTTP / SSE / WebSocket）；通过 `_MANAGEABLE` / `_USABLE` 路径依赖实现“可管理”和“可使用”两级权限，并在多 worker 模式下经 `BackgroundCommandKind` + `coordinator.leader_id()` 把 start/stop/reload 委派给 leader 进程。
- `_partners_channel_schema.py` 是与 HTTP 层绑定的辅助包：按 `XxxChannel` ↔ `XxxConfig` 命名约定反射 Pydantic 模型，生成 JSON Schema、内联 `$ref`、收集 secret 字段，供 `GET /channels/schema` 驱动前端动态表单。
- `imports.py` 提供独立的 `/api/chat-history` 路由，接收浏览器侧已归一化的 ChatGPT / Claude Code / Codex 会话并持久化到共享 session store，使用 `imported_` 前缀隔离来源。

依赖方向单向向外：本模块仅消费 `deeptutor.services.partners.*`、`deeptutor.multi_user.*`、`deeptutor.partners.channels.registry` 等上层服务，不反向被它们引用；`plugins_api.py` 在当前仓库中不存在，不在本模块范围内。
