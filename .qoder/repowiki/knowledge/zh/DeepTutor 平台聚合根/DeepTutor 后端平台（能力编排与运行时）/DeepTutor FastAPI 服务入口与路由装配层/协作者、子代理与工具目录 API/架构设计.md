三个并列的 FastAPI `APIRouter` 模块，各自挂载到上层应用：
- `co_writer.py`：基于 `EditAgent` 单例（按语言懒加载并 `refresh_config`）实现 Markdown 编辑（rewrite/shorten/expand）、React 式选中文本编辑、自动标注、文档 CRUD、Docx/TXT/Anki 导入导出、附件上传、历史与 tool-calls 查询；通过 `_selected_edit_agent` 上下文管理器在请求内切换 LLM profile，并通过 `StreamBus` + SSE (`text/event-stream`) 推送编辑过程事件。
- `subagents.py`：面向「我的 Agent → 已连接 Agent」功能，封装 `detect_all` / `get_backend` / `sessions` 等 `deeptutor.services.subagent` 能力，将子代理注册为 `type: subagent` 的 KB 指针（经 `account_kb_manager`），并提供 NDJSON 流式消息接口以复用同一 live session。
- `tools.py`：纯只读清单端点，枚举 `BUILTIN_TOOL_TYPES` 与 `COMING_SOON_TOOL_TYPES`，序列化 `ToolDefinition`/`ToolPromptHints`，结合 `tool_description_i18n`、`USER_TOGGLEABLE_TOOL_NAMES`、`capability_tool_owners` 和 web_search 运行时可用性检查生成 Settings UI 所需的双语元数据。
依赖方向单向向外：仅消费 `deeptutor.co_writer`、`deeptutor.services.*`、`deeptutor.multi_user.*`、`deeptutor.knowledge.*`、`deeptutor.tools.builtin` 等下层包，不反向被它们引用。
