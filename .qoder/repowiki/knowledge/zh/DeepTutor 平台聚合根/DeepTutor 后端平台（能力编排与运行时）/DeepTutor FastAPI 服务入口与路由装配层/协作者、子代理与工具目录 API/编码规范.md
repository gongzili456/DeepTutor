- 路由文件统一以 `router = APIRouter()` 开头，并在模块末尾显式 `__all__ = ["router"]`（如 subagents.py）。
- 对重型依赖（`EditAgent`、`append_history`、`load_history`、`tool_calls_dir` 等）采用函数体内 `from ... import ...` 的延迟导入，避免冷启动开销。
- HTTP 异常处理采用 try/except 包裹业务逻辑，捕获通用 `Exception` 后打印 traceback 并以 500 返回，同时让 `HTTPException` 透传原状态码。
- 对外暴露的请求/响应体使用 Pydantic `BaseModel` 定义，并通过 `Field(max_length=...)`、`Literal[...]`、`ge=0` 等约束进行输入校验。
- 需要用户权限或模块开关的路由在入口处调用 `require_module("knowledge")` 或 `require_admin` 装饰器进行能力门控。
- 流式端点通过 `asyncio.create_task` 异步执行后端任务，并用 `finally` 中 `task.cancel()` 保证客户端断开时清理后台任务。
