四个独立的 FastAPI `APIRouter`，按领域拆分：
- `notebook.py`：通过 `deeptutor.services.notebook.notebook_manager` 暴露 notebook 与 record 的 CRUD、复制/移动、Markdown 导出，以及基于 `StreamingResponse` + SSE (`text/event-stream`) 的摘要流式写入；损坏文件统一经 `_unreadable` 转为 409 `notebook_unreadable`。
- `outputs.py`：受 `require_auth` 保护的静态产物下载，先走当前用户 workspace，再回退到 partner scope（`visible_partners`），对 `.html` 且含 `video_lesson` 的路径注入沙箱 CSP。
- `attachments.py`：仅支持 `LocalDiskAttachmentStore` 的聊天附件预览，以 session_id 作为 ACL 边界，返回 `Content-Disposition: inline`。
- `memory.py`：记忆 v3 workbench，分三层——overview/doc CRUD、consolidator run 生命周期（start/cancel/undo/events SSE）、trace/snapshot 浏览器；长任务由 `services.memory.consolidator.runs.RunManager` 持有，客户端通过 `/runs/{id}/events?since=N` 重连。
依赖方向单向向下：router → `deeptutor.services.*`（notebook/memory/storage/path_service），不反向引用业务逻辑；认证与路径解析通过 `Depends(require_auth)` / `get_current_path_service()` 注入。
