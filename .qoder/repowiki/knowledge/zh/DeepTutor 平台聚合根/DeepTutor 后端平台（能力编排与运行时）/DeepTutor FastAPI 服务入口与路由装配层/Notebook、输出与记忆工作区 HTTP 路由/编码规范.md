- 每个模块在文件顶部声明 `router = APIRouter()` 并以装饰器直接挂载端点，保持 router 为模块级单例。
- 需要认证的端点通过 `Depends(require_auth)` 注入 `TokenPayload`，并在内部用 `get_current_user_or_none()` 做 fail-closed 检查。
- 长耗时操作统一采用 SSE 流式响应：`StreamingResponse` + `media_type="text/event-stream"`，事件体格式为 `data: <json>\n\n`，并设置 `Cache-Control: no-cache`。
- 可恢复的业务异常（如 `NotebookCorruptedError`）被单独捕获后转换为带结构化 `code` 字段的 HTTPException，而非泛化 500。
- Pydantic request model 使用可选字段配合 `model_dump(exclude_unset=True)` 传递部分更新，避免未发送字段覆盖后端默认值。
