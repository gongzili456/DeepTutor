模块由两部分组成：
- 应用入口层：`main.py` 通过 `@asynccontextmanager lifespan` 管理 FastAPI 生命周期（初始化容器、校验 capability/tool 一致性、启动 EventBus/BackgroundLeaderSupervisor/MCP/LLM provider pool、执行 v1→v2 迁移），并注册全局中间件链（`WorkspaceActivityMiddleware` → `json_error_boundary` → security guard → access log → CORS）；`run_server.py` 作为 uvicorn 进程入口，设置事件循环策略、工作目录、reload_excludes、WS 大小与 keep-alive 超时后调用 `uvicorn.run("deeptutor.api.main:app", ...)`。
- 运行时工具层 `utils/`：每个文件是一个独立单例服务，通过类级 `_instance` + `get_instance()` 暴露，互不依赖，被上层 router 按需导入——`progress_broadcaster.ProgressBroadcaster` 按 knowledge base 名维护 WebSocket 订阅集合；`task_log_stream.KnowledgeTaskStreamManager` 用 `deque` + `asyncio.Queue` 实现带心跳的 SSE 任务日志流，并通过 `_capture_non_propagating_task_logs` 把 `lightrag`/`graphrag` 等非传播 logger 重定向到当前 task_id；`task_id_manager.TaskIDManager` 以 `{task_type}_{timestamp}_{uuid}` 格式生成可清理的任务 ID；`tool_options.build_tool_options` 聚合可选工具、内置工具和 MCP 工具的国际化描述供 partners/admin API 使用；`http_headers.content_disposition` 统一处理 RFC 6266/5987 的非 ASCII 文件名编码。
依赖方向单向向外：本模块仅依赖 `deeptutor.*` 内部包，不被同层其他模块反向引用。
