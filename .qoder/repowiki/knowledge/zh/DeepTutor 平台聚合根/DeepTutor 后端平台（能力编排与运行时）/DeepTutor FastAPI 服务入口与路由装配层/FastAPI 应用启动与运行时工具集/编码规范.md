- 进程级共享状态通过类属性 `_instance` + `get_instance()` 单例模式暴露，并在多线程场景下用 `threading.Lock` 保护实例化与字典访问。
- 异步方法内的可变共享状态使用 `asyncio.Lock` 保护，同步路径则使用 `threading.Lock`，避免混用导致死锁。
- 对可能缺失的外部子系统（如 MCP manager、LMM client、knowledge/mastery/memory/calendar 模块）采用延迟 import + try/except 包裹，失败时降级为 warning/debug 日志而非中断启动。
- 对外暴露的工具/选项数据统一通过 `localized_description` + `tool_description_i18n` 进行多语言描述渲染，返回结构包含 `description` 与 `description_i18n` 双字段。
