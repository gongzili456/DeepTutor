本模块由三个并列的 FastAPI `APIRouter` 组成，各自挂载到应用根路径：
- `dashboard.py`：暴露 `/recent`、`/suggestions`、`/learning-index`、`/source-library/{kind}`、`/learning-library/{kind}`、`/{entry_id}` 等只读端点，统一通过 `_workspace_rows` 把当前 workspace 的 `content_workspace_id` / `content_workspace_name` 注入到返回行中；对 books/mastery/reading/watching/practice 等子能力采用「在 handler 内延迟 import 对应 router 函数」的方式避免循环依赖，并通过 `module_enabled` + `learning_surface_allowed` 做功能开关与多租户可见性过滤。
- `voice.py`：薄 HTTP 层，直接调用 `deeptutor.services.voice` 的 `synthesize_speech` / `transcribe_audio`，负责 TTS 请求体校验、PCM→WAV 转换、25 MB 上传上限与 provider 异常到 HTTP 状态码（400/413/502/504）的映射。
- `quiz_judge.py`：独立的 WebSocket 端点 `/questions/judge`，因 WS 升级无法使用 FastAPI 依赖注入，故在 handler 内调用 `ws_require_auth` 完成鉴权；内置多语言 judge system prompt（zh/en/de/uk/pt/vi/fr/tr），按 `SUPPORTED_JUDGE_LANGUAGES` 派生支持集，并兼容旧版单图 `user_answer_image` 与新数组 `user_answer_images` 两种入参格式，必要时通过 `AttachmentStore.resolve_path` 将本地附件 URL 转为 base64 以适配不支持外部 URL 的 LLM provider。

依赖方向单向向外：仅消费 `services.*`、`multi_user.*`、`modules.catalog` 与同包其他 router 中的纯列表函数，不反向被这些服务引用。
