- 对可能引入循环依赖的子模块（如 book、mastery_path、reading、co_writer、auth、llm.capabilities）采用在 handler 函数体内 `from ... import` 的延迟导入方式。
- WebSocket 端点不使用 FastAPI 依赖注入进行鉴权，而是在 handler 开头显式调用 `ws_require_auth(websocket)`，失败时直接 return，成功后再 `websocket.accept()`。
- 对外部 provider 调用统一用 try/except 捕获具体异常类型（如 `ValueError`、`VoiceProviderTimeout`、`VoiceProviderError`）并映射为明确的 HTTP 状态码（400/413/502/504）。
- 多语言系统提示集中放在模块级字典（如 `_JUDGE_SYSTEM_PROMPTS`），并通过 `frozenset(_JUDGE_SYSTEM_PROMPTS)` 派生白名单，新增语言只需编辑一处。
- 工作区相关数据读取统一经过 `_workspace_rows` 包装，向每行追加 `content_workspace_id` 与 `content_workspace_name`，确保后续链接始终锚定来源 store。
