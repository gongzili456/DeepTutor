- 每个路由文件导出 `router = APIRouter()`，部分文件还额外导出 `ws_router = APIRouter()` 以分离 HTTP 与 WebSocket 端点。
- 对 Book/Knowledge/Mastery Path 等重量级或外部依赖对象使用模块级 getter 函数并在函数体内 `import`，避免模块导入时触发昂贵初始化。
- 请求体统一用 Pydantic `BaseModel` + `Field(...)` 声明，响应体通过 `model_dump(mode="json")` 序列化后返回 dict。
- HTTP 错误统一通过 `fastapi.HTTPException(status_code=..., detail=...)` 抛出，业务异常被捕获后映射为 400/403/404/409/500/502 等语义状态码。
- 阻塞型 I/O（文件系统、同步 DB、zip 解压、hub catalog）通过 `asyncio.to_thread` 包装，避免阻塞异步事件循环。
- 涉及并发写的路径（book 的 `_claim_content_mutation`、mastery path 的 `_exclusive_path_mutation`）先取消活跃 turn 再获取 lease，冲突时返回 409 并附带会话信息。
