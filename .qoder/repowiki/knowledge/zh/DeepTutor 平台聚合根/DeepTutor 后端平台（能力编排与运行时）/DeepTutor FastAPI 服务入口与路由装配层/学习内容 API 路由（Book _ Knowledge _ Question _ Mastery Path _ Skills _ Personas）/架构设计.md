模块由七个并列的 FastAPI `APIRouter` 组成，每个文件对应一个业务域：
- `book.py`：BookEngine 的完整生命周期（create → confirm-proposal → confirm-spine → compile/regenerate/insert/move/block），通过 `_resolve_book_or_404` + `_claim_content_mutation` 实现共享编辑的乐观锁 revision 控制，并提供 `/books/{id}` 的 WebSocket 事件流。
- `knowledge.py`：KnowledgeBaseManager 的 CRUD、文件上传（含 zip 解压、PocketBase 镜像）、多 RAG 后端（LightRAG/PageIndex/GraphRAG/LlamaIndex）预检与索引策略冻结；通过 `assert_writable`/`resolve_kb` 做多用户权限。
- `question.py`：两个 WebSocket 端点（`/mimic`、`/generate`），拦截 stdout 并通过 `bind_log_context`/`capture_process_logs` 把生成日志推回前端。
- `question_notebook.py`：基于 SQLite session store 的题目笔记本 CRUD、分类、附件存储（AttachmentStore）与统计。
- `mastery_path.py`：LearningService + LearningStore 上的学习路径建模、复习队列、主题地图与 `PathLeaseConflictError` 独占写入。
- `skills.py`：SKILL.md 包的 CRUD 与 EduHub 安装，按 `library_workspace` 在账户级与 workspace 级之间切换服务实例。
- `personas.py`：PERSONA.md 行为预设，合并 admin 只读 preset 与用户可写 persona。
依赖方向单向向下：router → multi_user access layer → services/* → storage/LLM/RAG 等基础设施；重型对象（BookEngine、KnowledgeBaseManager、TopicGeneration）采用函数内 import 延迟加载以避免启动开销。
