- 对外暴露的 Prompt 文案全部走 `_t(key, default=...)` 查表，默认值提供英文兜底，中文变体来自 `prompts/{en,zh}/explore_context.yaml`，避免硬编码字符串。
- 所有 LLM 输出先经 `clean_thinking_tags(binding, model)` 清理后再计入最终 investigation，thinking-only 模型的回退路径也遵循同一清洗流程。
- Trace 事件统一通过 `stream.stage(EXPLORE_STAGE, source=EXPLORE_SOURCE, metadata=stage_meta)` 包裹，并在 running/complete 两端发送 `call_state` 进度，使前端能识别“上下文调查”阶段。
- 对可能失败的 LLM/tool 调用采用 try/except + logger.warning 后降级到单遍模式，保证 pre-pass 永不阻塞主回答循环。
- 敏感运行时对象（如 `LLMClientConfig`、`StreamBus`、`UnifiedContext`）通过方法参数显式传入，不在类属性上持有，避免跨线程共享。
