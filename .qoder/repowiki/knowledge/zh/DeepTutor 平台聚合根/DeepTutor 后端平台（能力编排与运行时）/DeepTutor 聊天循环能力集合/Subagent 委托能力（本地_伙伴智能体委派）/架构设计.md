模块按 capability / binding / tools 三层组织：
- `capability.py` 实现 `KnowledgeCapability` 子类 `SubagentCapability`，负责判定是否激活、注入系统提示、为工具调用注入服务端上下文（`augment_kwargs`），并在 partner_group/partner 场景下强制首轮必须咨询。
- `binding.py` 提供纯读取的 `connection_for_turn`，从 `context.knowledge_bases` 解析出第一个 `type == subagent` 的 KB，或优先走 `partner_discussion_group_id` / `consult_partner_id`，结果缓存在 `context.extension('subagent')` 中供同轮复用；同时暴露 `subagent_refs` 把子 agent KB 从 RAG 索引中排除。
- `tools.py` 定义唯一的 `ConsultSubagentTool`，根据 `_subagent` 注入字段选择后端（`PartnerGroupBackend` / `PartnerBackend` / 通用 `get_backend(kind)`），通过 `event_sink` 以统一 trace_kind `subagent_event` 流式转发所有原生事件到侧边栏，并维护 per-turn 预算与跨轮 session_id。
依赖方向单向：capability → binding + tools → `deeptutor.services.subagent`（延迟 import 避免循环）。
