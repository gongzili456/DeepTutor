- 对 `LearningStore`/`LearningService` 的访问一律通过 `asyncio.to_thread` 包装同步 IO，避免阻塞事件循环。
- 工具函数通过 `_resolve_path_id` / `_resolve_session_id` / `_resolve_turn_id` 从 kwargs 中读取 pipeline 注入的私有字段，而不是让模型直接传入。
- 需要跨层传递 turn/session/path 上下文时，通过 `augment_kwargs` 注入 `_bind_active_path` / `_bind_active_mode` / `_teaching_delivery` 等回调，使工具无需感知 `UnifiedContext`。
- 可能改变 turn 目标的工具（`mastery_switch`、`mastery_leave`、`mastery_mode`）声明在 `rebinding_tools` 中，确保同轮内的后续 tool call 绑定到新目标。
- 持久化失败采用 best-effort 策略：捕获异常后记录 warning 日志但不中断主流程，保证 handoff 本身已经生效。
- 工具返回统一通过 `_json_result` / `_no_path_result` / `_wrong_mode_result` 等工厂构造 `ToolResult`，保持 success/content/meta 结构一致。
