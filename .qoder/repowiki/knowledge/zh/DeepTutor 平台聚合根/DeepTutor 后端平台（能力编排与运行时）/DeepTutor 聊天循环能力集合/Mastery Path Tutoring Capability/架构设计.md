模块以 `capability.py` 中的 `MasteryPathCapability`（实现 `TurnCapability`）作为入口：解析 `mastery_path_id`、持有 path lease、标记 `mastery_mode`，然后委托给 `pipeline.MasteryLoopPipeline`。

内部分层清晰：
- `capability.py` — 会话级能力注册与 path lease 生命周期管理；
- `pipeline.py` — 继承 `AgenticLoopPipeline`，用 `MasteryPromptAssembler` 替换系统提示的基础块，注入当前知识点的 lesson evidence 与视觉图片，并处理 deferred outline tools；
- `loop.py` — `MasteryLoopCapability` 钩子集（`system_block`/`augment_kwargs`/`pre_loop`/`finish_instruction`/`final_text_override`），把 mastery 工具挂载到 chat 的工具表面之上，并通过 `_bind_active_path` / `_bind_active_mode` 回调在单轮内重定向上下文；
- `tools.py` — 所有 `mastery_*` 工具的实现，通过 `_new_service()` 每次构造新的 `LearningService(LearningStore())` 避免并发共享状态，并把纯引擎逻辑（门控、间隔重复、进度）留在 `deeptutor.learning`；
- `binding.py` — 唯一允许变更 path 绑定的模块，原子化完成 release→acquire→persist 三步，保证租约、会话偏好与活 turn 三者一致；
- `mode.py` / `choices.py` / `history.py` / `memory.py` — 模式门控、选项解析、历史分享与记忆提示等横切辅助。

依赖方向单向向外：本模块调用 `deeptutor.capabilities.protocol`、`deeptutor.core.*`、`deeptutor.agents.loop.pipeline` 以及 `deeptutor.learning.*`，但被反向通过 `builtin_capability_manifest("mastery_path")` 注册进运行时。prompt 模板集中在 `prompts/en|zh/mastery_loop.yaml`，由 `get_prompt_manager().load_prompts(module_name="mastery", agent_name="mastery_loop", language)` 加载。
