模块以 `__init__.py` 暴露 `NotebookAnalysisAgent` 与 `NotebookSummarizeAgent` 两个对外类；内部按职责拆分为：
- `analysis_agent.py`：实现三阶段推理循环（`_stage_thinking` → `_stage_acting` → `_stage_observing`），调用 LLM 流式接口后解析 JSON 选出最多 5 条相关记录，并通过 `StreamEvent` + `EventSink` 回调上报 THINKING / TOOL_CALL / OBSERVATION / RESULT 等事件。
- `summarize_agent.py`：对单条 notebook 输出做摘要，提供同步 `summarize` 与流式 `stream_summary` 两种 API。
- `_text.py`：共享的 `clip_text` 截断工具，避免提示词过长。
- `prompts/{en,zh}/`：按语言分目录存放 YAML 提示模板，由 `get_prompt_manager().load_prompts("notebook", <agent>, language)` 在构造时加载，使 agent 代码不硬编码任何自然语言文本。
依赖方向单向向外：本模块依赖 `deeptutor.services.llm`、`deeptutor.core.stream`、`deeptutor.core.trace`、`deeptutor.services.prompt.manager`，不被同层其他 agents 引用。
