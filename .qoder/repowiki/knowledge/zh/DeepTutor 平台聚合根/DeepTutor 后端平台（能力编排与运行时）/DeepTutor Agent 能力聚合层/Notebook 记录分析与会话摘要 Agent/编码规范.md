- Agent 构造函数根据 `language` 参数自动映射到 `zh` 或 `en`，再通过 `get_prompt_manager().load_prompts("notebook", <agent_name>, self.language)` 从对应语言目录加载 YAML 提示。
- LLM 调用统一走 `llm_stream` 异步迭代，配合 `clean_thinking_tags` 清理模型思维标签后再返回结果。
- 长文本输入（user_query / output / metadata / record content）一律经 `_clip_text` 截断并附带截断标记，防止超出 token 限制。
- 分析 Agent 的每个阶段方法都通过 `build_trace_metadata` + `_emit_stage_start/end` 包裹，并以 `StreamEvent` 向外部 emit THINKING/OBSERVATION/TOOL_CALL/RESULT 等事件。
- 提示模板通过 `_stage_text(stage, field)` 访问 YAML 中的 `system` / `user_template` 字段，再 `.format(...)` 注入变量，避免在 Python 中拼接自然语言。
