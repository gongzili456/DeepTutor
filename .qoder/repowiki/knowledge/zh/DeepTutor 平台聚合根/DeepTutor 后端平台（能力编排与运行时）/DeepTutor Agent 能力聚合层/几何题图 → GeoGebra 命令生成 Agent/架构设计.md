模块以 `VisionSolverAgent`（继承自 `BaseAgent`）为唯一入口，对外暴露 `process` 与 `format_ggb_block` 两个方法，保持与旧四阶段管线（BBox→Analysis→GGBScript→Reflection）兼容的契约，供 `geogebra_analysis` 工具在 chat/solve 中调用。

- 提示词：`prompts/geogebra.md` 是纯文本模板，使用 `{{ question_text }}` 占位符注入题干；首次分析失败时会在末尾追加一段中文修复指令。
- 推理流程：`_analyze` 组装 prompt + base64 图片消息，经 `_call_vision_llm` 通过 `stream_llm` 流式调用视觉模型（默认走 `vision_model`，回退到 `model`），返回原始文本后由 `_extract_json` 用正则剥离 `<think>`、```json 围栏、注释与尾随逗号再解析。
- 数据规整：`_coerce_commands` 将模型输出的 `commands` 标准化为 `[{command, description}]` 列表，兼容字符串数组降级；`_format_commands` 将其拼接为前端可渲染的 ```ggbscript 代码块。
- 依赖方向：仅向上依赖 `deeptutor.agents.base_agent.BaseAgent`，不引入其他业务模块；LLM 调用、日志、配置全部委托给基类。
