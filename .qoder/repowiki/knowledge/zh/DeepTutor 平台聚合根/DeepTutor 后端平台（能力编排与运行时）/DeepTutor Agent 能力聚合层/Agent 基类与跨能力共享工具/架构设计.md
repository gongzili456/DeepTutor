本模块由两部分组成：
- `base_agent.py` 定义 `BaseAgent`（`ABC`），是所有 solve/research/co_writer/question 等模块 Agent 的统一父类，集中处理 LLM 配置加载（`get_llm_config` + `agents.yaml`）、统一调用接口 `call_llm` / `stream_llm`（封装 `deeptutor.services.llm` 的 complete/stream，支持 multimodal attachments、response_format、reasoning_effort、trace callback）、token 统计（类级 `_shared_stats: dict[module_name, LLMStats]`）、PromptManager 加载与 `get_prompt` 双模式查询。
- `_shared/` 子包承载跨能力管线的纯策略与运行时绑定，不依赖具体 pipeline：`tool_composition.py` 通过 `ToolMountFlags` + `compose_enabled_tools` 实现“用户开关 → 条件自动挂载 → 能力自有工具 → 常驻内置工具”的固定顺序；`tool_runtime.py` 负责把 `UnifiedContext` 中的 workspace/sandbox 路径注入到 tool 调用参数；`capability_result.py` 提供 `emit_capability_result` 作为各能力 `run()` 的统一终点；`json_output.py` 提供从含 `<think>` 推理前缀的模型输出中提取 JSON 对象的健壮解析器；`workspace_prompt.py` 生成面向模型的 workspace 使用约束提示。
依赖方向单向向外：本模块仅依赖 `deeptutor.services.*`、`deeptutor.core.context`、`deeptutor.modules.catalog` 等基础设施，不被同层其他 agents 反向引用。`__init__.py` 通过 `importlib.import_module` 延迟导入 `BaseAgent`，避免启动时加载整个 base_agent 文件。
