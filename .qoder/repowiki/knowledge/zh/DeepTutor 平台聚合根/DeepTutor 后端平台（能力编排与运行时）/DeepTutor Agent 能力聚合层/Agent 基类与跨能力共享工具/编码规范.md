- 对外暴露的公共 API 通过模块末尾的 `__all__` 显式声明，未列出的符号视为内部实现。
- 对可能失败的外部服务访问（memory/notebook/mastery/partners 探测、model catalog 读取、prompt 加载）采用 try/except 包裹并返回保守默认值（False / None / 空列表），保证主流程不因探测失败而中断。
- LLM 调用的 trace 事件统一通过 `_emit_trace_event` 发出，携带 `event=llm_call`、`state`（running/streaming/complete/error）、`agent_name`、`stage`、`model` 等字段，供外部回调消费。
- 工具启用策略以纯函数形式表达（`compose_enabled_tools`、`default_optional_tools`、`user_has_*` 探针），将上下文判断与最终排序解耦，便于 chat 与 quiz 复用同一份规则。
- 工作区相关的路径注入集中在 `bind_workspace_tool_runtime`，按 tool 名前缀（`workspace_`、`exec`、`GENERATION_TOOL_SERVICES`）分支注入 `_sandbox_*` / `_workspace_*` 键，避免在各 tool 中重复构造 mount。
