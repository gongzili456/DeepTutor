- 对外 API 使用 `async def run(..., stream: StreamBus)` 并通过 `stream.stage` / `stream.progress` / `emit_capability_result` 暴露可观测性，而非直接返回中间状态。
- 提示词集中放在 `prompts/{en,zh}/agent_name.yaml`，运行时通过 `self._t(key)` 或 `get_prompt_manager().load_prompts(module_name="question", agent_name=...)` 加载，并按语言追加 `append_language_directive`。
