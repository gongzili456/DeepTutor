模块以 `capability.py` 中的 `MathAnimatorCapability`（实现 `TurnCapability`）作为运行时入口，通过 `importlib.util.find_spec("manim")` 懒加载可选依赖，再实例化 `pipeline.MathAnimatorPipeline` 驱动五阶段流程：concept_analysis → concept_design → code_generation → code_retry(render) → summary。

内部分层清晰：
- `agents/` 子包封装各阶段的 LLM 调用代理（ConceptAnalysisAgent / ConceptDesignAgent / CodeGeneratorAgent / SummaryAgent / VisualReviewAgent），每个代理对应 `prompts/en|zh/*.yaml` 双语提示词；
- `pipeline.py` 是编排层，持有各 Agent 实例并通过 `set_trace_callback` 统一注入 trace 回调；
- `retry_manager.CodeRetryManager` 负责 render-fix-regenerate 循环（最多 4 次重试 + 180s 修复超时），并支持两条修复路径：启用视觉审查时走 `VisualReviewService` + `VisualReviewAgent`，否则回退到 `layout_probe.geometry_review` 做无模型几何检查（`MAX_LAYOUT_ROUNDS=3`）；
- `renderer.ManimRenderService` 封装 Manim 渲染，`models.py` 用 Pydantic 定义跨阶段共享数据契约（`ConceptAnalysis`/`SceneDesign`/`GeneratedCode`/`RenderResult` 等）；
- `request_config.py` 提供带 `extra="forbid"` 的 `MathAnimatorRequestConfig` 校验入口；
- `__init__.py` 使用 `__getattr__` 延迟导入 `MathAnimatorPipeline`，避免启动期加载 Manim。

依赖方向单向：capability → pipeline → agents/renderer/retry_manager/models/request_config，不反向引用上层框架。
