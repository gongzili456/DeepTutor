- LLM 相关类（各 Agent、Pipeline、Capability）通过构造函数接收 `api_key/base_url/api_version/language` 参数，而非从全局读取，便于测试替换。
- 跨阶段数据契约统一在 `models.py` 中以 Pydantic `BaseModel` 声明，并在子类上设置 `model_config = ConfigDict(extra="ignore")` 以容忍上游 LLM 返回多余字段。
- 对外暴露的公共 API（`MathAnimatorPipeline`、`validate_math_animator_request_config`）集中在 `__init__.py` 的 `__all__` 中，并通过 `__getattr__` 延迟 import 以避免启动期加载重依赖。
- 异步阶段执行统一包裹在 `async with stream.stage(name, source=self.name)` 上下文管理器中，配合 `time.perf_counter()` 累计 `timings` 字典用于性能追踪。
- 提示词按语言分目录存放于 `prompts/en/` 与 `prompts/zh/`，文件名与对应 Agent 类名一一对应，便于 i18n 切换。
