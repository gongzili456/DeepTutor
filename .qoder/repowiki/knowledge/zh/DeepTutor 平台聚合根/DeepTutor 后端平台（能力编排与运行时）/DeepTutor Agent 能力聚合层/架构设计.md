本包是 Deeptutor 所有 Agent 能力的统一入口：
- `base_agent.BaseAgent` 是所有子模块 Agent 的抽象基类，集中封装 LLM 配置（从 `deeptutor.services.llm.get_llm_config` 与 `agents.yaml` 合并）、提示词加载（`PromptManager` 按 `module_name/agent_name/language` 解析 `prompts/{en,zh}` 目录）、`call_llm`/`stream_llm` 统一接口、token 统计（类级 `_shared_stats`）与 trace 回调。
- `_shared/` 提供跨能力复用的工具装配（`tool_composition`、`tool_runtime`）、结构化输出（`json_output`）、工作区提示（`workspace_prompt`）与结果模型（`capability_result`），被多个子模块直接复用。
- 每个业务能力子目录（chat、research、question、math_animator、notebook、visualize、video_lesson、vision_solver）遵循同一约定：定义 `capability.py` 暴露给上层 Capability 注册表，内部再拆 `pipeline.py` + 若干 `agents/*.py` + `prompts/{en,zh}/*.yaml`；部分子模块还自带 `request_config.py` 描述该能力的请求结构。
- `loop/` 是通用单循环引擎（`AgentLoop`、`AgenticLoopPipeline`、`native_tools`、`python_scheduler`、`reasoning_recovery` 等），被 `chat/agentic_pipeline.py` 作为宿主复用，而非每个能力各自实现循环。
- 顶层 `__init__.py` 仅懒导出 `BaseAgent`，避免在导入时触发各子模块的依赖初始化。
