- 每个 Agent 继承 `BaseAgent`，在 `__init__` 中通过 `module_name="visualize"` + `agent_name` 注册，并使用 `self.get_prompt(...)` 从 `prompts/{lang}/` 目录加载 YAML 提示词。
- LLM 输出经 `extract_json_object` 后交给 Pydantic `model_validate` 进行结构化校验，枚举字段通过 `model_validator(mode="before")` 将未知值降级为默认值而非抛错。
- 对外部不可信输入先做本地确定性校验（`validate_visualization` 针对 svg/chartjs/mermaid/mindmap/html），仅在失败时再触发一次 LLM repair，避免无谓的模型调用。
- 长耗时阶段统一通过 `stream.stage(...)` 上下文管理器包裹，并在进入/退出时向 `StreamBus` 发送 `progress`/`content`/`thinking` 事件，附带 `source=self.name` 和 `stage` 标签。
- Manim 等可选重型依赖采用运行时 `import`（`importlib.util.find_spec` 探测 + `require_module` 检查），保证基础 visualize 功能在无 Manim 环境下仍可运行。
