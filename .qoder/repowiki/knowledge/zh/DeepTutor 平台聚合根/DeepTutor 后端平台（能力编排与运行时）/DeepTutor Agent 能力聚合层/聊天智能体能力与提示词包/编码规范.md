- 能力通过继承 `TurnCapability` 并在类上声明 `manifest = builtin_capability_manifest("...")` 来注册，运行时由 bootstrap 自动发现。
- Pipeline 类通常只继承基类而不重写逻辑，仅通过模块级常量（如 `CHAT_OPTIONAL_TOOLS`）暴露配置别名，具体模式在外部覆盖预算与流命名空间。
- 提示词模板按语言拆分为 `prompts/<locale>/<agent>.yaml` 子目录，每个文件包含 system / context_template / user_template / history_format 四个字段。
