模块以三层组织：
- `capability.py` 中的 `ChatCapability` 实现 `TurnCapability` 协议，作为运行时可发现的能力入口，仅负责根据 `context.language` 构造 `AgenticChatPipeline` 并调用其 `run`。
- `agentic_pipeline.py` 中的 `AgenticChatPipeline` 是空子类，直接复用 `deeptutor.agents.loop.pipeline.AgenticLoopPipeline` 的全部协议、工具表面与默认行为；模块级常量 `CHAT_OPTIONAL_TOOLS` / `CHAT_EXCLUDED_TOOLS` 只是对父类常量的别名，供上层模式（solve、ask_questions 等）覆盖预算和流命名空间时使用。
- `prompts/en` 与 `prompts/zh` 两套 YAML 提示词包（`chat_agent.yaml`、`agentic_chat.yaml`、`context_summary_agent.yaml`），按语言目录分发 system/context_template/user_template/history_format 模板。
依赖方向单向向外：本模块依赖 `agents.loop`、`core.capability_protocol`、`runtime.bootstrap.builtin_capabilities`，不被同层其他 agents 反向引用。
