- 新 Agent 继承 `BaseAgent` 并实现 `async process()`，通过 `get_prompt()` 读取 PromptManager 加载的 YAML 提示词。
- LLM 调用统一走 `BaseAgent.call_llm` / `stream_llm`，不直接调用底层 `llm_complete` / `llm_stream`。
- 提示词按 `prompts/en` 与 `prompts/zh` 双语目录组织，文件名与 agent 名一一对应。
- 每个业务能力在自身目录下提供 `capability.py` 作为对外注册点，内部管线放在 `pipeline.py`，具体 Agent 放在 `agents/` 子目录。
- 需要结构化输出的能力使用 `_shared/json_output.py` 或 Pydantic models 进行响应解析。
