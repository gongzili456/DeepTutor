- 路径构造函数统一返回 `Path` 并通过 `ensure_dir` 保证目录存在，调用方无需自行创建。
- 配置模型继承自 `Base`，利用 `alias_generator=to_camel` 与 `populate_by_name=True` 同时兼容 camelCase 与 snake_case JSON 键。
- 可选能力通过独立的 Pydantic 类（如 `DeliveryOverrides`、`StreamingSupport`）组合到 `ChannelsConfig`，而非在单一模型中堆叠布尔开关。
- 对外 API 集中在包级 `__init__.py` 中 re-export，子模块内部实现不直接暴露给上层 callers。
