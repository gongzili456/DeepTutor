- 事件类型统一使用 `@dataclass` 定义，并配合 `field(default_factory=...)` 为可变默认值（如 `metadata`、`media`、`timestamp`）提供安全的工厂函数。
- 对可选的复杂默认字段（`metadata: dict[str, Any]`、`media: list[str]`）一律采用 `default_factory=dict/list` 而非直接传实例，避免共享可变状态。
- `MessageBus` 的公开 API 成对出现：每个队列都有对应的 `publish_*` 与 `consume_*` 方法，并提供非阻塞的 `try_consume_outbound` 供路由层做前瞻合并。
- 出站消息在入队前统一通过 `metadata.setdefault("_enqueued_at", time.monotonic())` 注入排队时间戳，以便下游计算投递延迟。
