模块由三个文件组成清晰的三层结构：
- `events.py` 定义数据契约：`InboundMessage`（渠道→Agent 的入站消息，含 channel/sender_id/chat_id/content/media/metadata/session_key_override/actor 等字段，并通过 `session_key` 属性派生会话键）和 `OutboundMessage`（Agent→渠道的出站消息，含 reply_to、media、metadata）。
- `queue.py` 提供 `MessageBus` 类，内部封装两个 `asyncio.Queue`（`inbound` / `outbound`），暴露 `publish_*` / `consume_*` / `try_consume_outbound` 以及 `inbound_size` / `outbound_size` 监控属性；出站写入时自动注入 `_enqueued_at` 时间戳用于测量投递延迟。
- `__init__.py` 仅做白名单式 re-export（`MessageBus`, `InboundMessage`, `OutboundMessage`），对外只暴露这三个符号。
依赖方向单向：`queue.py → events.py`，`__init__.py` 聚合二者；`events.InboundMessage` 通过 `CurrentUser` 引入 multi_user 模型以支持认证用户上下文，但 bus 本身不感知具体渠道实现。
