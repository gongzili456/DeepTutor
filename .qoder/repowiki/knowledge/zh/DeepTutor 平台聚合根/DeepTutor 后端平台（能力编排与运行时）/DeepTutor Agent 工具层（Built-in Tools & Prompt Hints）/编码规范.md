- 工具类继承 `_PromptHintsMixin` 并在 `get_prompt_hints` 中委托给 `load_prompt_hints(self.name, language)`，使提示词随工具名自动匹配 YAML 文件。
- 工具实现将参数契约集中在 `get_definition` 的 `ToolDefinition` 中描述，而 `execute` 仅做参数提取与结果组装，业务逻辑下沉到同名模块的异步函数。
- 对重型服务（sandbox、llm、workspace、knowledge_access）采用方法内局部 import，避免 `tools → services → runtime → registry → tools` 循环导入。
- 外部副作用调用（网络搜索、arXiv/Zotero API、KB 清单扫描）通过 `asyncio.to_thread` 包裹同步阻塞函数，保持 `execute` 的异步语义。
- 面向用户的错误信息统一通过 `deeptutor.services.i18n.t(...)` 进行 i18n 翻译，而非硬编码英文字符串。
- YAML 提示词按 `tool_name.yaml` 命名并分 `en/`、`zh/` 两套，加载时优先本地语言再回退到 en，缺失文件时返回空 `ToolPromptHints`。
