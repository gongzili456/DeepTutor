模块以 `BaseTool`（来自 `deeptutor.core.tool_protocol`）为统一抽象，按职责拆分为三层：
- 注册与发现层：`builtin_specs.py` 通过 `BuiltinToolSpec` + `LazyBuiltinToolTypes` 从 `deeptutor.modules.catalog.manifests()` 读取 class_path 并惰性加载实现类，避免启动时导入整个能力图；`__init__.py` 用 `_LAZY_EXPORTS` + `__getattr__` 对外暴露顶层 API。
- 工具实现层：`builtin/__init__.py` 集中定义所有 `BaseTool` 子类（Brainstorm/RAG/Reason/WebSearch/PaperSearch/Zotero/GeoGebra/KbFiles/KnowledgeFrontier 等），每个类的 `get_definition` 返回 `ToolDefinition`，`execute` 调用同目录下的纯函数实现（如 `brainstorm.py`、`rag_tool.py`、`web_search.py` 等），从而把参数契约与业务逻辑解耦。
- 沙箱执行层：`exec_tool.py` 是唯一的代码执行入口，通过 `deeptutor.services.sandbox` 在隔离环境中运行 Python/C/C++/shell，并对 shell 命令使用 `_DENY_PATTERNS` 正则黑名单拦截危险操作。
- 提示词层：`prompting/` 下按 `en/zh/` 子目录组织每个工具的 YAML 提示词，由 `load_prompt_hints` 带 mtime/size 缓存加载，`ToolPromptComposer` 提供 list/table/phased/aliases 多种渲染格式。
- 辅助子包：`vision/`（图像块解析、坐标变换、GeoGebra 校验）、`question/`（题目抽取与考试模拟）、`tools/question_bank.py` 等共享能力。
依赖方向单向向外：本模块依赖 `core.tool_protocol`、`services.*`、`knowledge.*`、`modules.catalog`，不被上层反向引用。
