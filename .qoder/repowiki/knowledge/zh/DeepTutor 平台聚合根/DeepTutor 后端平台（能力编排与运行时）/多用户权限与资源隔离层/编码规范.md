- 领域实体统一用 `@dataclass(frozen=True, slots=True)` 定义，并提供 `public_dict()` 方法输出给 API 的白名单字段。
- 权限降级采用 least-privilege 语义：未知角色经 `normalize_role` 回退为 `user`，未知 grant 字段丢弃而非报错。
- 资源访问判定器按资源域拆分为独立文件（book/knowledge/learning/skill/tool/model/partner），统一通过 `permission_for_user(user).level_for(...)` 或 `can_*` 函数暴露。
- 文件系统路径通过 `paths.py` 的 `get_current_path_service()` / `get_owner_path_service()` 获取，避免直接拼接 `data/users/<uid>`。
- grant 读写统一走 `_grant_write_lock` 加 `.xxx.lock` 文件锁，并以 `GrantWriteReceipt` 支持条件恢复（compare-and-swap）。
- 敏感值（配对码、ticket）在持久层仅存 SHA-256 哈希，传输体用 JWE 加密，错误一律抛出细粒度异常类（`HandoffRejected`/`HandoffRateLimited`）。
