模块由两个互补子模块组成，通过 `__init__.py` 统一对外暴露：
- `metadata_i18n.py`：维护 `_CAPABILITY_DESCRIPTIONS`、`_TOOL_DESCRIPTIONS` 两个静态字典（键为 capability/tool 名，值为 `{en, zh}` 映射），并提供 `capability_description_i18n`、`tool_description_i18n`、`localized_description` 三个纯函数，用于 settings UI / API 展示。
- `status_i18n.py`：定义 `StatusI18n` 类，在构造时惰性导入 `deeptutor.services.prompt.get_prompt_manager` 以避免启动循环依赖，调用 `load_prompts(module_name=module, agent_name=name, language=language)` 从 `deeptutor/agents/<module>/prompts/{en,zh}/<name>.yaml` 下读取 `status:` 映射，并通过 `t(key, default, **kwargs)` 支持 `{name}` 占位符格式化。
依赖方向单向向外：本模块仅被上层 capability/prompt 消费，不反向依赖业务逻辑；`StatusI18n` 的 prompt 服务导入延迟到首次实例化时执行以规避循环。
