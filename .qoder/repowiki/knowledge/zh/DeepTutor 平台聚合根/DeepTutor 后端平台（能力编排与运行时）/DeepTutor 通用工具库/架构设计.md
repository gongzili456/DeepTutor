本模块是纯工具包，无入口脚本，被 `deeptutor/services`、`deeptutor/runtime`、`deeptutor/api` 等上层按需 import。

- 文档处理子域：`document_extractor.py` 作为字节到文本的统一入口（`extract_text_from_bytes`），按扩展名分发到 PDF(pymupdf/pypdf)、DOCX/XLSX/PPTX(openpyxl/python-pptx + raw OOXML fallback)、EPUB(标准库 zipfile+xml) 以及 text-like 解码；`document_images.py` 负责从 Office/EPUB 中抽取图片并生成 `[图片 N: name]` 标记；`archive_extractor.py`、`bibtex_converter.py`、`document_validator.py`、`filenames.py`、`json_parser.py`、`text_display.py` 各自承担单一格式或显示职责。
- 文件类型路由：`file_types.FileTypeRouter` 集中维护 `PARSER_EXTENSIONS / TEXT_EXTENSIONS / IMAGE_EXTENSIONS` 三套扩展集，并通过 `get_parser_extensions()` 动态合并 `services.parsing.engines.formats.known_parser_formats()`，使 chat 与 KB 共享同一份格式清单。
- 配置管理：`config_manager.ConfigManager` 以单例模式读写 `data/user/settings/main.yaml`，通过 mtime 缓存 + `RLock` 保证线程安全，并在 `_runtime_key_values` 中组合 `ModelCatalogService` 与 `RuntimeSettingsService` 暴露 LLM 相关环境变量。
- 网络可靠性：`network/circuit_breaker.py` 实现 per-provider 的 closed/open/half-open 状态机，并提供全局 `circuit_breaker` 实例及 `is_call_allowed`/`record_call_success`/`record_call_failure` 便捷函数供 provider 调用方使用。
- 系统级辅助：`console_encoding.relax_console_encoding` 修复 Windows 窄控制台下的 UnicodeEncodeError；`error_utils.format_exception_message` 从 API JSON 错误体中提取可读信息；`secret_files` 用于读取受保护配置文件。

依赖方向单向向外：utils 不反向依赖业务服务（除 `ConfigManager` 在 `_runtime_key_values` 中延迟导入 services 以避免循环），仅由上层消费。
