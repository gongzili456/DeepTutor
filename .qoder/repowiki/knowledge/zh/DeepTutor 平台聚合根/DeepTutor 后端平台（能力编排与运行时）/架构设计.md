本层是 Deeptutor 后端的统一装配面，通过三层协作把各子模块串联起来：
- 模块声明层 `modules/manifests/*.json` 声明每个 feature 的 `requires` 依赖、贡献的 `capabilities/tools/loops/routes/paths`，由 `catalog.py` 在启动时校验环依赖并计算拓扑顺序；`require_module(name)` 是运行时按需启用的唯一入口。
- 运行时编排层 `runtime/` 提供 `ChatOrchestrator`：接收 `UnifiedContext`，按 `active_capability` 或默认 `chat` 从 `capability_registry` 查找并调用 `TurnCapability.run(context, bus)`，同时管理 `StreamBus`、LLM 用量统计与错误收敛；`turn_engine.py`、`isolated_worker.py`、`background_leader.py` 负责单进程/多进程调度。
- API 接入层 `api/` 通过 `RouterLoader` + `router_index.json` 对 FastAPI 路由做延迟加载，仅在 OpenAPI 生成或首次命中时才 import 对应 router 模块，避免无关模块污染启动路径。
- 共享契约层 `core/`（`TurnCapability`、`ToolProtocol`、`UnifiedContext`、`StreamEvent`）是所有业务子模块（agents/capabilities/services/runtime/api）共同遵守的数据协议，跨进程事件经 `events/event_bus.py` 广播。
- 可选扩展通过 `multi_user`（身份/权限）、`partners`（IM 渠道）、`plugins`（外部插件）挂载到同一运行时，不改变核心编排流程。
