模块按职责分层组织：
- 数据层 `models.py` 定义所有 Pydantic 聚合根（`LearningProgress`、`KnowledgePoint`、`QuizAttempt`、`ErrorRecord`、`LearningEvidence` 等），并通过枚举 `_missing_` 钩子兼容旧版中文/阶段值。
- 持久层 `storage.py` 以 SQLite 为权威存储，通过 `LearningStore` + `LearningTransaction` 提供事务化聚合读写、乐观锁（revision 冲突抛出 `LearningConflictError`）、路径租约（`PathLeaseConflictError`）以及从旧 JSON 文件的惰性迁移归档。
- 业务编排层 `service.py` 是核心入口，组合 grading/mastery/scheduler/policy 等子模块完成一次交互的完整状态机推进。
- 算法策略层拆分为可替换文件：`mastery.py`（近期加权准确率掌握度评分）、`grading.py`（确定性答案判分）、`scheduler.py`（间隔重复调度）、`review_strategy.py`（复习策略模板）。
- 事件通道 `event_hub.py` 提供线程安全的 `MasteryTopicEventHub`，在同步 SQLite 写入后通过 `call_soon_threadsafe` 唤醒异步 WebSocket 订阅者。
- LLM 辅助侧由 `prompts.py` + `prompts/en.yaml|zh.yaml` 管理多语言提示词，`topic_generation.py` / `topic_materials.py` / `topic_naming.py` / `visual_practice.py` / `question_card.py` / `lesson_evidence.py` / `semantic_assessment.py` 负责主题生成、材料抽取、视觉练习与语义评估。
- 依赖方向单向：service → (storage, mastery, grading, scheduler, policy) → models；event_hub 仅被 storage/service 用于发布信号。
