- 枚举类通过重写 `_missing_` 把旧版中文或废弃字符串映射到当前值，使历史数据反序列化时自动降级。
- 所有 Pydantic 模型统一设置 `model_config = ConfigDict(extra="ignore")`，允许上游传入额外字段而不报错。
- 持久化异常采用继承自 `LearningStoreError` 的专用子类（如 `LearningConflictError`、`PathLeaseConflictError`），调用方按领域语义捕获而非通用 `RuntimeError`。
- 对外暴露的公共 API 集中在包级 `__init__.py` 中重新导出 Pydantic 模型，其他模块只引用 `deeptutor.learning.models`。
- LLM 相关能力以独立小模块拆分（topic_generation/topic_materials/topic_naming/visual_practice/question_card/semantic_assessment/lesson_evidence），每个文件聚焦单一生成任务并由 service 组合调用。
