- LLM 提示词以 YAML 文件存放在 prompts/en 与 prompts/zh 下，文件名与 agent/block 类名一一对应，由 language.py 按当前 locale 自动加载。
- 所有对外暴露的数据结构使用 Pydantic v2 模型定义，并在 models.py 中集中声明以便跨子模块复用。
- 长耗时任务通过 event_hub 发布结构化事件，调用方通过 streaming.py 的 SSE 通道消费，避免阻塞主线程。
- 持久化采用原子 JSON 文件（book.json / outline.json / pages/*.json），写入前先落盘临时文件再 rename，配合 progress.py 实现断点续跑。
