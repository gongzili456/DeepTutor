模块以 `base.py` 中的抽象基类 `BlockGenerator`（定义 `block_type` 类属性与 `async _generate(ctx)` 契约）为核心，所有具体块类型（text/callout/quiz/code/figure/interactive/animation/deep_dive/timeline/flash_cards/concept_graph/section/user_note）均继承它并实现 `_generate`。

- 注册机制：`BlockGeneratorRegistry` + 模块级 `_REGISTRY` 单例通过 `get_block_registry()` 懒加载，在 `_build_default_registry` 中集中 import 并实例化全部 Generator，避免循环依赖。
- 共享基础设施：`_llm_writer.py` 暴露 `llm_text` / `llm_json`，封装 `deeptutor.services.llm.complete/stream`、语言指令注入、thinking preamble 剥离与结构化 JSON 重试；`_rag_helpers.py` 提供 `optional_rag_lookup`，优先使用 `ctx.exploration.relevant_chunks`（BookEngine v2 缓存），再回退到 `rag_search`，失败静默吞掉。
- 提示词管理：`_prompts.py` + `_language.py` 按语言目录加载 YAML 提示模板，由每个 generator 通过 `load_book_prompts(name, language)` 取用。
- 错误分类：`GenerationFailure` 异常被 `BlockGenerator.generate` 统一捕获，经 `_classify_failure` 归入 provider_error/json_parse/empty_response/timeout/rate_limit/prompt_leak/generator_error 等 bucket，写入 block.metadata.failure。
- 依赖方向：generator → base/_llm_writer/_rag_helpers/_prompts → deeptutor.services.* / deeptutor.tools.rag_tool / deeptutor.models；generator 之间不互相引用。
