- 每个 Agent 在 `__init__` 中固定传入 `module_name="book"` 和各自的 `agent_name`，并通过 `super().__init__` 复用 BaseAgent 的 API key/base_url/language/binding 参数。
- 系统提示词优先通过 `self.get_prompt("system"|"user_template"|...)` 加载 YAML，未命中时回落到模块级 `_FALLBACK_SYSTEM` / `_FALLBACK_USER` 常量。
- LLM 调用统一用 `stream_llm` 收集 chunk，配合 `StreamOutcome()` 检测 truncated，再通过 `json_with_reasoning_retry` 或 `parse_json_response` 解析 JSON，失败时返回最小兜底结果而非抛出异常。
- 对外部输入的字符串一律经 `_clip(text, limit)` 截断，数值经 try/except 转 int/float 并设置默认值，确保 LLM 产出不稳定时不会破坏下游 Pydantic 模型。
- Agent 的 `process` 方法作为 `BaseAgent.process` 适配器，转发到更具语义的方法（如 `explore`、`synthesize`），保持 BaseAgent 接口一致的同时暴露领域 API。
- 模块内通过 `from ..blocks._language import language_directive` 动态追加语言指令到 system prompt，使同一 Agent 可按 `language` 参数切换 en/zh 行为。
