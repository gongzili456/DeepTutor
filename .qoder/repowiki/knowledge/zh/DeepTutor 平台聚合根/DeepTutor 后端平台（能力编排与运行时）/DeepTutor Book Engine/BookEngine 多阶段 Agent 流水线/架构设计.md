本模块是 BookEngine 的 Agent 层，按 `__init__.py` 暴露五个类：`IdeationAgent`（Stage 1，将 `IdeationContext` 转为 `BookProposal`）、`SourceExplorer`（Stage 2 前置，并行 RAG 检索生成 `ExplorationReport`）、`SpineAgent`（旧版 Stage 2 骨架生成器，保留兼容）、`SpineSynthesizer`（新版 Stage 2，基于 ExplorationReport 的 Draft→Critique→Revise 三轮循环输出 Spine + ConceptGraph）、`PagePlanner`/`SectionArchitect`（Stage 3，把 Chapter 展开为 Block 序列）。

- 依赖方向单向向外：所有 Agent 继承 `deeptutor.agents.base_agent.BaseAgent`，通过 `stream_llm` / `get_prompt` 访问 LLM 与提示词；数据模型来自 `..models`（`BookProposal`、`Chapter`、`Spine`、`ExplorationReport`、`Block` 等），输入上下文来自 `..inputs`。
- `SourceExplorer` 内部再分两步：LLM 设计查询 → `asyncio.gather` 并发检索（`RETRIEVAL_CONCURRENCY=6`、`MAX_RETRIEVAL_CALLS=48` 限流），再对 KB / PageIndex / notebook / chat / quiz 来源做去重裁剪后汇总。
- `PagePlanner` 采用双轨架构：`plan_blocks_async` 走 LLM（`llm_json`），失败或禁用时回退到 `_TEMPLATES_V2` 静态模板；`PagePlanner` 是 `SectionArchitect(llm_enabled=False)` 的向后兼容别名。
- 提示词统一通过 `get_prompt(key)` 加载 YAML，未配置时回落到文件末尾 `_FALLBACK_*` 常量。
- 所有 LLM JSON 响应都经 `json_with_reasoning_retry` 或 `parse_json_response` 解析，并附带 `_coerce_*` 方法做字段裁剪、类型转换与去重，保证下游模型构造不抛异常。
