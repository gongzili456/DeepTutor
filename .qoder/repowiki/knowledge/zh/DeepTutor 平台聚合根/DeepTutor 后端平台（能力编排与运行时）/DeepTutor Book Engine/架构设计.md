本模块以 `engine.py` 中的 `BookEngine` 为统一入口，向上暴露 `generate()` / `stream()` 等 API，向下分层协作四个子域：
- `agents/`（agents_pipeline）：按阶段串联 ideation → source_explorer → spine_agent → page_planner，产出章节骨架与页面块类型序列。
- `blocks/`（blocks_catalog）：每种 BlockType 对应一个异步生成器，消费 RAG 检索结果与提示词模板，填充为最终 payload。
- `compiler.py` + `storage.py` + `progress.py`：把 agents 产出的骨架与 blocks 生成的页面原子写入 JSON 文件，并维护增量进度。
- `models.py` + `context.py` + `chat_sessions.py` + `streaming.py`：共享的 Pydantic 模型、聊天上下文序列化与 SSE 事件封装。

跨子域的耦合点集中在 `book/context.py`（全局上下文注入）、`book/language.py`（en/zh 双语言提示词加载）和 `book/event_hub.py`（发布订阅式事件总线），所有子模块通过它们而非直接互相引用来交换状态。
