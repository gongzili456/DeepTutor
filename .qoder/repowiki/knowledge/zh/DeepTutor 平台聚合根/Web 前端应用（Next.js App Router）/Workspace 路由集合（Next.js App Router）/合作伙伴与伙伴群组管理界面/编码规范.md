- 所有页面文件顶部声明 `"use client"`，并在文件头注释中用一句话说明该页面的职责。
- 异步数据加载在 `useEffect` 内发起，配合 `let cancelled = false` 守卫防止卸载后 setState，错误分支统一 fallback 到空数组或 loading=false。
- 用户可见文案一律通过 `useTranslation().t(...)` 获取，包括按钮、占位符和错误提示。
- 导航跳转统一使用 `next/navigation` 的 `useRouter()` 配合 `router.push`/`router.replace`，并手动 `encodeURIComponent` 路径参数。
- 对外部 API 的错误处理采用 `err instanceof Error ? err.message : t("Create failed")` 的统一模式，将异常消息回显到本地 error/toast 状态。
- 列表项卡片统一使用 `PartnerAvatar` 展示头像，并以 `border-[var(--border)] hover:border-[var(--ring)]` 的 Tailwind 类族维持一致的悬停样式。
