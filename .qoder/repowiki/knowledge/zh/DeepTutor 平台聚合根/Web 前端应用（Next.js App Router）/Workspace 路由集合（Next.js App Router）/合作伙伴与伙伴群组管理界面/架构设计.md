模块基于 Next.js App Router 的 `(workspace)` 路由组组织，全部为 `"use client"` 组件：
- `page.tsx`：合作伙伴总览 + 群组概览双区列表，通过 `@/lib/partners-api` 与 `@/lib/partner-groups-api` 并行拉取数据。
- `new/page.tsx`：五步表单向导（Identity → Soul → Mind → Library → Review），状态集中在本地 state，最终调用 `createPartner` 后跳转到 `[partnerId]`。
- `[partnerId]/page.tsx`：单伙伴详情页，使用 tab 切换 Chat / Configure / Channels / Archive；通过 `@/lib/partner-session` 与 `getPartnerWebContinuity`/`setPartnerWebContinuity` 实现跨浏览器会话同步，并用 `Suspense` 包裹以支持服务端渲染骨架。
- `groups/new/page.tsx` 与 `groups/[groupId]/page.tsx`：群组创建与运行页，复用 `DiscussionModePicker`、`PartnerAvatar` 等共享组件，并通过 `partnerGroupSessionKey` 做本地会话选择。

依赖方向单向向外：页面层仅消费 `@/lib/*-api` 与 `@/components/partners/*` 子组件，不反向引用其他 workspace 路由。UI 框架统一走 `@/components/layout/FeaturePage`（`FeaturePage`、`PageHeader`、`pageActionClass`、`pageGridClass`）。
