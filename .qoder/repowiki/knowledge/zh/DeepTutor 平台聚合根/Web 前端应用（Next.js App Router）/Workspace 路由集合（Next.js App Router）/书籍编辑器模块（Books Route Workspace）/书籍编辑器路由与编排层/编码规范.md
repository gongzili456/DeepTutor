- 路由段 `page.tsx` 仅 re-export 同名默认导出，真实逻辑集中在 `BooksRoute.tsx` 中，URL 参数由 `useParams` 读取。
- 异步副作用统一通过 `guard(actionName, fn)` 包装，捕获 `BookApiError` 后调用 `notify` 展示错误提示。
- 对服务端 revision 的读写走 `revisionRef` + `applyBookRevision`，所有写 API 通过 `currentRevision()` 传入 `expected_revision` 以处理并发冲突。
- 批量事件通过 `setTimeout` 去抖（`PAGE_REFRESH_DEBOUNCE_MS` / `BOOK_REFRESH_DEBOUNCE_MS`），并在组件卸载时清理定时器。
- 路由跳转统一通过 `bookRoute(bookId, pageId?)` 生成，避免硬编码路径字符串。
