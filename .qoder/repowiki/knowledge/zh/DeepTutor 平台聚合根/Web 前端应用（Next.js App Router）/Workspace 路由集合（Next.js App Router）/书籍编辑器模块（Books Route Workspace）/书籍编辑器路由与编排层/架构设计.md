模块以 `BooksRoute.tsx` 中的单一 `BookPageInner` 组件作为所有 `/books/[bookId]` 和 `/books/[bookId]/pages/[pageId]` 路由的实际实现；两个 Next.js route segment 的 `page.tsx` 仅做 re-export，把 URL 参数解析统一收口到这一个组件。

- 视图状态：通过 `View = 'list' | 'opening' | 'creator' | 'spine' | 'reader'` 在图书库、创建器、Spine 编辑器和阅读器之间切换，由 `handleSelectBook` 根据 book.status/can_edit/hasReadableContent 决定目标视图。
- 数据层：通过 `@/lib/book-api` 调用 REST API，通过 `useBookStream` + `reduceBookEvent` 订阅 BookEngine 的 WebSocket 事件，用 `useReducer` 维护进度时间线。
- 性能分层：区分 `PAGE_SCOPED_EVENTS`（单页刷新）与 `BOOK_SCOPED_EVENTS`（整书刷新），配合 `schedulePageRefresh` / `scheduleBookRefresh` 的定时器去抖，避免每个 block_ready 都拉取整书。
- 并发安全：使用 `revisionRef` 记录服务端最新 revision，所有写操作通过 `currentRevision()` 传入 expected_revision，409 冲突时自动回拉并重试一次。
- 依赖方向：组件 → `bookApi` / `learningLibrary` / `useBookStream` / `book-progress` / `book-errors`，UI 子树（BookSidebar、PageReader、SpineEditor、BookCreator 等）位于同目录 `components/` 中，本模块只负责编排与状态。
