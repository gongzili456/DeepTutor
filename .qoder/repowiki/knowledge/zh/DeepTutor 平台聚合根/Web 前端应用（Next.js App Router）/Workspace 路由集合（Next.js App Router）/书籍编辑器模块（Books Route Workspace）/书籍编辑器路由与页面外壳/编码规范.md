- 路由状态集中维护于 `BooksRoute.tsx` 的 `view` state，并通过 `router.push(bookRoute(...))` 与 URL 双向同步，组件本身不直接解析路由。
- 所有写操作使用 `guard(actionName, async () => {...})` 包装，统一处理 `BookApiError`、409 冲突重试、revision 更新和 `notify` 错误提示。
- 并发控制通过 `revisionRef` + `currentRevision()` + `expected_revision` 字段实现乐观锁，服务端返回 409 时重新拉取 book detail 后重试一次。
- WebSocket 事件按作用域分类：`PAGE_SCOPED_EVENTS` 触发单页去重刷新（`schedulePageRefresh`），`BOOK_SCOPED_EVENTS` 触发整书刷新（`scheduleBookRefresh`），避免每事件一请求。
- 新增 block 类型需同时出现在 `BlockRenderer.tsx` 的 switch 分支与 `CHANGEABLE_TYPES`/`INSERTABLE_TYPES` 白名单中，保持渲染与编辑能力一致。
- 用户可见文案一律通过 `react-i18next` 的 `t()` 函数包裹，禁止硬编码英文字符串。
