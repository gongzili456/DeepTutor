模块以 Next.js App Router 的 `page.tsx` 作为入口，仅做一层转发到 `BooksRoute.tsx`（实际组件），由该文件承担全部路由状态机：通过 `View = 'list' | 'opening' | 'creator' | 'spine' | 'reader'` 在图书库、创建器、Spine 编辑器、阅读器之间切换，并同步 URL 参数 `bookId`/`pageId`/`chat`。

- 数据层：通过 `@/lib/book-api` 调用 REST，通过 `useBookStream` + `reduceBookEvent` 订阅 BookEngine 的 WebSocket 事件；所有写操作经 `currentRevision()` + `expected_revision` 乐观并发控制，409 冲突时自动回拉最新 revision。
- 视图层：`components/` 下每个文件对应一个子界面——`BookLibrary`（列表）、`BookCreator`（意图+知识源+提案）、`SpineEditor`（目录确认）、`PageReader`（章节阅读）、`BookChatPanel`/`LearningCapturePanel`（聊天与学习捕获）、`BookSidebar`/`PageOutlineNav`（导航）。
- 内容块层：`components/blocks/` 是纯展示/编辑组件集合，由 `BlockRenderer.tsx` 根据 `block.type` 分派到 `TextBlock`/`QuizBlock`/`CodeBlock`/`AnimationBlock`/`FlashCardsBlock`/`ConceptGraphBlock`/`TimelineBlock`/`DeepDiveBlock`/`FigureBlock`/`InteractiveBlock`/`CalloutBlock`/`SectionBlock`/`UserNoteBlock`/`PlaceholderBlock`；`BlockBodyEditor.tsx` 为可编辑体提供统一编辑器。
- 依赖方向单向：route shell → 业务组件 → blocks；API、类型、i18n、通知等横切能力来自 `@/lib/*` 与共享 UI，本模块不向外暴露 API。
