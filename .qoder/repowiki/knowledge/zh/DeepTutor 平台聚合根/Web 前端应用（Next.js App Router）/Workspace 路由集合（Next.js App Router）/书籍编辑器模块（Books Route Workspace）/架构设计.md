本模块按 Next.js App Router 的目录约定组织三层：
- 路由层 `page.tsx` + `[bookId]/page.tsx` + `[bookId]/pages/[pageId]/page.tsx` 提供 `/learning/books`、单书视图与单页视图三个客户端入口；
- 编排层 `components/BookCreator.tsx`、`SpineEditor.tsx`、`PageReader.tsx`、`BookSidebar.tsx`、`BookChatPanel.tsx`、`LearningCapturePanel.tsx` 等组件在路由中组合，负责图书创建、大纲确认、章节阅读、实时编译流与状态管理；
- 内容层 `components/blocks/` 下的各类 Block 组件由 `BlockRenderer.tsx` 根据 `block.type` 分发渲染，供 `PageReader` 在页面视图中消费。
三者的耦合方向单向：路由 → 编排组件 → Block 渲染器，Block 不反向依赖路由或编排逻辑，从而保证块的可复用性。
