基于 Next.js App Router 的两级路由：
- `layout.tsx` 作为该段路由的根布局，通过 `QuizFollowupProvider` 与 `GeogebraTabProvider` 包裹子树，使笔记阅读侧也能复用工作区级的 quiz follow-up 与 GeoGebra tab 上下文。
- `page.tsx` 是 `/co-writer` 首页，使用 `FeaturePage` + `PageHeader` 构建 UI，调用 `@/lib/co-writer-api` 与 `@/lib/notes-api` 完成 list/create/import/pin/delete，并通过 `notifyCoWriterChanged()` 事件通知其他视图刷新；文档卡片通过 `Link` 跳转到 `/co-writer/:docId`。
- `[docId]/page.tsx` 是动态路由页，解析 `params.docId` 后渲染 `NoteWorkspace`，并动态加载 `NoteCompanion`（ssr: false）作为右侧伴生面板。
- `sampleTemplate.ts` 仅导出 `CO_WRITER_SAMPLE_TEMPLATE` 常量字符串，作为新建文档时的初始 Markdown 模板。
依赖方向单向向外：本模块只消费 `@/features/notes/components/*`、`@/lib/*` 与共享 context，不反向被这些库引用。
