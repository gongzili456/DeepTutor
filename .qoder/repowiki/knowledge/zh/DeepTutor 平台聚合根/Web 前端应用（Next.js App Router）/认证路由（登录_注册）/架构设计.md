基于 Next.js App Router 的 `(auth)` 路由组：`layout.tsx` 提供居中卡片布局；`login/page.tsx` 与 `register/page.tsx` 各自为独立客户端页面，通过 `@/lib/auth` 调用后端认证 API（`login` / `register` / `fetchAuthStatus` / `checkIsFirstUser`），并通过 `@/shared/auth/return-url` 中的 `inheritLoginHash` 与 `normalizeInternalReturnPath` 统一处理登录后回跳路径与 hash 保留。登录页在挂载时检查是否已认证或是否为空站（首个用户直接重定向到 `/register`），注册页则校验密码一致性并在成功后以 `?registered=1` 参数跳转登录。两个页面均使用 `react-i18next` 进行国际化，并通过 `Suspense` 包裹内容组件以支持流式渲染。
