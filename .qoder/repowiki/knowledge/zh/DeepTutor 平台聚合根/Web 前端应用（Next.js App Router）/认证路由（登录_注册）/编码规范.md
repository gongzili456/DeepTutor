- 页面组件顶部声明 "use client"，将表单状态、副作用与导航逻辑放在客户端执行。
- 所有用户可见文案通过 `useTranslation()` 的 `t(...)` 函数获取，不直接写死字符串。
- 表单提交统一采用 `useState` 管理 loading/error 状态，失败时设置 `setError(result.error ?? t("..."))`，成功时通过 `router.replace` 跳转。
- 页面挂载时在 `useEffect` 中调用 `fetchAuthStatus` 判断已登录态并自动重定向到目标路由。
- 样式统一使用 Tailwind 原子类配合 CSS 变量（如 `bg-[var(--card)]`、`text-[var(--foreground)]`）实现主题化。
