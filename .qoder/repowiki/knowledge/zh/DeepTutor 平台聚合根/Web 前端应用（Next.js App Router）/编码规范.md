- 页面路由按功能域拆分为 `(workspace)`、`(auth)`、`(utility)`、`(admin)`、`(settings)` 等 App Router 路由组，每个组自带 `layout.tsx` 注入该域所需的运行时上下文。
- UI 组件放在 `components/<domain>/`，纯函数式 API 客户端与状态逻辑放在 `lib/<domain>.ts`，避免页面直接调用后端接口。
- 跨页面共享状态通过 `context/` 下的 React Context 暴露，并由 `AppShellContext` 作为根上下文统一挂载。
- 前后端数据契约集中在 `contracts/`，新增或修改接口后需通过 `scripts/generate-contracts.mjs` 重新生成 TypeScript 类型。
- 国际化文案统一放在 `locales/<lang>/`，并通过 `i18n/` 下的 I18nProvider 与 ESLint 插件校验键值完整性。
