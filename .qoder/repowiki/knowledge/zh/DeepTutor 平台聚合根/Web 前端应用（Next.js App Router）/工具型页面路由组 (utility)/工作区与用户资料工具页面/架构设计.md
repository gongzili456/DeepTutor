基于 Next.js App Router 的 `(utility)` 路由组，分为两个并列子树：
- `profile/page.tsx`：独立的客户端页面，负责账户信息展示、头像上传/裁剪（Canvas + createImageBitmap）、密码修改与登出，通过 `@/lib/profile-api`、`@/lib/auth` 等模块与后端交互，UI 由 `FeaturePage` / `PageHeader` / `UserAvatar` 等共享组件构成。
- `space/`：以 `layout.tsx` 统一包裹 `<SpaceMain>` 布局，每个子目录（chat-history、cli-apps、journal、mcp、personas、questions、skills）仅包含一个薄壳 `page.tsx`，把渲染委托给 `@/components/space/*Section` 或 `SpaceDashboard`；`space/page.tsx` 作为仪表盘入口。
依赖方向单向向外：本模块只消费 `@/components/*`、`@/lib/*` 与 Next 内置 API，不暴露任何内部接口。notebook 子目录当前为空，尚未接入。
