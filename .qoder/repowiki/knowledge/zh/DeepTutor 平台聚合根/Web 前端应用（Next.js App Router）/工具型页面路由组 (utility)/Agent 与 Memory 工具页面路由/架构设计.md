模块由三个并列的 Next.js App Router 分组组成：
- `agents/`：极简布局 + 单一 `page.tsx`，通过 `FeaturePage` 包裹 `AgentsHub` 组件作为 Agent 控制台入口。
- `memory/`：按记忆层级组织路由——`l1`（文档级）、`l2/[surface]`（按 surface 分组的条目）、`l3/[slot]`（recent/profile/scope 三类槽位），另有 `graph` 可视化页与 `resolve` 跳转页；每个子目录自带 `layout.tsx` 仅渲染 `<main>` 骨架，滚动与内边距由各 page 自行负责。
- `knowledge/`：当前为空目录，预留知识类工具页面空间。

所有 memory 子页面均为 `'use client'`，并通过 `Suspense` 包裹使用 `useSearchParams` / `useParams` 的内层函数以兼容 Next.js app router 的客户端参数读取。`resolve/page.tsx` 是唯一直接调用后端 `/api/memory/resolve_entry/{id}` 的路由，根据返回的 `{layer, key, entry_id}` 重定向到对应 `/memory/{layer}/{key}?focus=...` 路径，充当跨层引用的统一入口。路由参数校验集中在各 page 内（如 `SURFACES` / `SLOTS` 白名单 + `notFound()`），组件实现则全部下沉至 `@/components/memory/*` 与 `@/components/agents/*`，本模块仅承担路由装配与 URL 契约。
