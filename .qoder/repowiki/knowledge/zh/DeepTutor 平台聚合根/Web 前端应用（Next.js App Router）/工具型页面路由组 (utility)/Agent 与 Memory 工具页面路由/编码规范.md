- 每个路由目录的 `layout.tsx` 只返回一个带背景色的 `<main>` 壳，不处理滚动或 padding，由具体 page 自行管理布局。
- 需要读取 URL 参数的 page 采用「外层默认导出包裹 `Suspense`，内层函数使用 `useSearchParams`/`useParams`」的双层结构。
- 动态段路由在读取参数后使用本地白名单数组（如 `SURFACES`、`SLOTS`）校验，非法值调用 `notFound()` 而非渲染错误 UI。
- 页面本身只做路由装配，实际 UI 通过导入 `@/components/memory/*` 或 `@/components/agents/*` 中的组件来呈现。
