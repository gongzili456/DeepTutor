基于 Next.js App Router 的客户端页面（`"use client"`），位于 `(utility)/settings/progress/page.tsx`，作为 settings 路由组下的唯一叶子页面。页面通过 `FeaturePage` + `PageHeader` 布局组件包裹内容，使用 `react-i18next` 进行国际化。数据层依赖两个外部 API：`@/lib/learning-records-api` 获取学习记录（`listLearningRecords`）和 `@/lib/reading-workspace-api` 获取阅读材料目录以映射 material_id 到标题。状态管理采用 React `useState` + `useEffect` 在挂载时并行拉取两份数据，错误处理区分加载态、空数据和网络异常三种 UI 分支，进度条通过内联 style 宽度实现并附带 `aria-*` 无障碍属性。
