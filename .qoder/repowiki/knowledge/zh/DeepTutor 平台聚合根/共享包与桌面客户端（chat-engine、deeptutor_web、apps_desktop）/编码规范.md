- Electron 主进程通过 `ipcMain.handle('desktop:*', ...)` 注册命名空间化的 IPC 频道，并在处理器内调用 `trustedShell(event)` 校验调用方必须是 shell 页面主帧。
- 渲染进程以 `WebContentsView` 承载，统一启用 `contextIsolation: true, sandbox: true, nodeIntegration: false, webSecurity: true`，并通过 `will-navigate` / `will-redirect` / `setWindowOpenHandler` 限制导航到同 origin 或外部 URL。
- 状态机通过 `status({ phase, step, message })` 集中更新 `state` 并 `publish()` 向渲染层广播快照，错误路径统一落盘到 `logs/runtime.log`。
- 用户数据与运行时文件写入采用原子模式：先写 `.tmp` 再 `rename`，配合 `mkdir(..., { recursive: true, mode: 0o700 })` 保证权限与一致性。
- 平台差异通过 `platform.mjs` 中的 `WINDOWS` / `edition()` / `agentMarker()` 等运行时常量分支，而非条件导入。
- 打包脚本遵循 `scripts/package.mjs` → `loadTarget()` → 动态 `import(platforms/<id>/package.mjs)` 的约定，新增平台只需在该目录下提供 `package.mjs` 与 `target.mjs`。
