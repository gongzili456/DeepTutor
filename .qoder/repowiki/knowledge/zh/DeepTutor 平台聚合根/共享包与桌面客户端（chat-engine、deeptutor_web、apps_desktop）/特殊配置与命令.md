`apps/desktop`：`npm start` 启动 Electron 开发窗口；`npm test` 运行 `node --test test/*.test.mjs`；`npm run build:runtime` 构建核心运行时；`npm run package [--target <id>]` 调用 `scripts/package.mjs` 产出平台安装包；`npm run icon` 用 Swift + Node 生成图标。`packages/chat-engine`：`npm run check` 类型检查，`npm run build` 编译到 `dist/`，`npm run test` 先 build 再跑 `dist/test/*.test.js`。
