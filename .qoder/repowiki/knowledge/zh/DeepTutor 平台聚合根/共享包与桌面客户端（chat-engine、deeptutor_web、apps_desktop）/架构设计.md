本模块由三个彼此独立、通过 npm 包或文件系统路径组合的子项目组成：
- `packages/chat-engine`：纯 TypeScript 库（`@deeptutor/chat-engine`），按职责分层——`core/` 定义 run-loop 与契约、`providers/` 封装 HTTP/SSE/One-shot 等模型调用提供者、`tools/` 暴露 ask-user/read-source/workspace 等工具、`native/` 隔离平台相关会话与事件合并逻辑、`transport/stdio.ts` 作为进程间通道；测试位于 `test/`，构建产物输出到 `dist/`。
- `deeptutor_web/__init__.py`：Python 包占位符，注释说明发布构建会注入 Next.js standalone 输出（`server.js`、`.next/static`、`public`），源码检出为空时 launcher 回退到 `web/`。
- `apps/desktop`：Electron 45 桌面壳，入口 `src/main.mjs` 负责单实例锁、用户数据目录（`OPEN_DEEPTUTOR_TEST_HOME` 可覆盖）、从 `seed/runtime.json` 或已安装 manifest 拉取并验证核心运行时、fork `supervisor.mjs` 作为 Node worker 运行实际 core，并通过 `WebContentsView` + `contextIsolation: true, sandbox: true, nodeIntegration: false` 加载渲染层；`preload.cjs` 提供受信任 IPC 桥，所有 `desktop:*` 频道在 `trustedShell` 校验来源后转发。
- 打包管线集中在 `scripts/`：`package.mjs` 动态加载 `platforms/<id>/package.mjs`（macos-arm64 / macos-x64 / windows-x64），各平台 target 脚本再调用 `lib/macos.mjs`、`signing.mjs`、`notarize.mjs`、`stage.mjs` 完成签名、公证与产物组装；`build-runtime.mjs`、`seal-runtime.mjs` 负责核心运行时构建与密封。
依赖方向：desktop → chat-engine（通过 bundle/manifest 机制消费其产物）、desktop → deeptutor_web（仅消费发布产物）；chat-engine 不反向依赖任何上层。
