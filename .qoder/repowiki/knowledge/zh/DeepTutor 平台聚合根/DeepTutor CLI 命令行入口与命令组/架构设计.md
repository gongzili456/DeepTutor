模块以 `__main__.py` 作为 `python -m deeptutor_cli` / `deeptutor` 的入口，委托给 `main.py` 中的 Typer 应用树：顶层 app 挂载 `chat`、`skill`(含别名 `skills`)、`plugin`、`config`、`session`、`provider`、`workspace` 七个子 Typer，并通过各子模块暴露的 `register(app)` 函数动态注册命令；同时通过 `deeptutor.modules.catalog.manifests()` 发现并动态 import 外部模块的命令（`module_path:attribute` 形式），实现插件式命令扩展。

- 核心能力入口：`main.run` 构造 `TurnRequest` 调用 `deeptutor.app.DeepTutorApp`，`common.run_turn_and_render` 负责事件流渲染；`chat.py` 实现交互式 REPL，维护 `ChatState` 数据类并在 `/` 命令路由中切换 capability、tool、kb 等。
- 共享基础设施集中在 `common.py`：Rich Console、`TurnStreamRenderer`（按 event type `_on_xxx` 分派的状态机）、`_SigintInterceptor`（SIGINT 中断 turn）、`ToolResultBuffer`（来自 `_tool_result.py`，环形缓冲最近 32 条 tool 结果供 `/show` 展开）、`build_turn_request`/`parse_config_items`/`parse_json_object` 等参数解析器。
- 资源管理命令各自独立成文件：`kb.py`、`notebook.py`、`memory.py`、`session_cmd.py`、`config_cmd.py`、`provider_cmd.py`、`workspace_cmd.py`、`plugin.py`、`module.py`，均遵循 `register(typer.Typer)` 模式。
- 初始化流程由 `init_cmd.py` + `init_wizard.py` + `setup_config.py` 协作完成；`doctor.py` 提供本地/在线就绪检查；`skill_login.py`、`skill_prompts.py` 支撑 skill 登录交互。
- 依赖方向单向向外：CLI 层仅消费 `deeptutor.app`、`deeptutor.runtime`、`deeptutor.modules.catalog`、`deeptutor.services.*`，不反向被业务模块引用。
