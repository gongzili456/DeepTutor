目录按用途划分为四个互不依赖的子树：
- `README/`：11 种语言的 README 副本，通过相对路径引用仓库根 `README.md` 和各子模块的说明，作为多语言入口。
- `figs/`：按主题分目录（`badges`、`logo`、`partners`、`system`、`web-dev`），其中 `system/generate_diagrams.py` 是唯一的生成脚本，使用纯 stdlib 动态构造 SVG 文本并写入 `system-architecture.svg` 与 `chat-agent-loop.svg`；其余 `.png`/`.svg` 均为预渲染产物，被 README 和文档站点直接引用。
- `releases/`：每个版本一个 Markdown 文件（如 `ver1-7-2.md`），历史版本归档在 `past_releases/`，文件名以 `verX-Y-Z.md` 命名并与 GitHub Release 一一对应。
- `roster/`：托管 stargazers/forkers 的 SVG 图表。

依赖方向单向向外：本模块仅被仓库根 README 与文档站点消费，自身不引入任何 Python 包或前端构建工具。
