- Python 代码风格由根级 `pyproject.toml` 统一约束：Black 行宽 100、Ruff 仅启用 E/F/I/B006，isort 通过 ruff.lint.isort 管理 first-party 包顺序。
- 可选能力以 `deeptutor[xxx]=={version}` 形式在 `[tool.deeptutor.optional-dependencies]` 中声明，并由 `full` profile 聚合，新增子包需同步注册到该列表。

- 运行时配置统一写入 `data/user/settings/*.json`，由 entrypoint 在容器启动时读取并导出为环境变量，而非通过 compose env var 硬编码。
