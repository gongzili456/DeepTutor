根目录作为聚合层不承载业务逻辑，而是通过以下机制把子模块装配在一起：
- Python 侧：`pyproject.toml` 定义 `deeptutor` 主包与 `deeptutor_cli` 命令入口（`deeptutor = deeptutor_cli.main:main`），并通过 `[tool.deeptutor.optional-dependencies]` 声明 server/web/partners/parse-* 等可选子包；`setuptools.packages.find` 同时发现 `deeptutor*` 与 `deeptutor_cli*`，使 backend、cli_tool、shared_packages 中的 Python 子项目被统一打包。
- 前端侧：`shared_packages/deeptutor_web` 作为 Next.js 资源占位包被主包 `package-data` 一并打入 wheel，由 `Dockerfile` 构建后在容器内由 supervisord 同时启动 FastAPI (:8001) 与 Next.js (:3782)，二者通过同一镜像内的反向代理通信。
- 运行时编排：`compose.yaml`（Podman Compose）是生产编排入口，`docker-compose*.yml` 提供 dev/sandbox-runner 变体；所有服务以 `read_only: true` + `userns_mode: keep-id` + `:U` 卷挂载运行，运行时配置集中于 `data/user/settings/*.json`，entrypoint 每次启动时读取并导出环境变量供后端与前端消费。
- 版本与发布：`build_metadata.py` / `build_support.py` 动态注入 `deeptutor.__version__`，GitHub Actions (`github_ci`) 调用这些脚本完成 PyPI、GHCR、Desktop 发布，并与 `tests` 模块的 pytest 用例联动验证。
