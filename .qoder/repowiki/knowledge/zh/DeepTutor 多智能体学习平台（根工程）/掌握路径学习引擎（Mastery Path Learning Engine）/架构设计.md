模块以 `models.py` 中的 Pydantic 模型（`LearningProgress`、`KnowledgePoint`、`QuizAttempt`、`ReviewTask` 等）为唯一数据契约，其他层围绕其组织：
- `service.py` 的 `LearningService` 是业务编排入口，组合评分、掌握度、调度与存储，对外暴露 `grade_and_record`、`record_qualitative`、`switch_module` 等原子操作。
- `grading.py` 提供纯函数式答案判定（choice/short/open 三种题型）与粗粒度错误分类，不依赖 I/O。
- `mastery.py` 通过 `compute_mastery` 将尝试历史映射为 0..1 掌握分数，采用近期加权 + 置信度上限策略，作为可替换的教学数学核心。
- `policy.py` 是无副作用的决策层，依据 `QUANTITATIVE_GATE` / `QUALITATIVE_TYPES` 判断是否掌握并输出 `NextStep`（answer_pending/review/probe/practice/assess/complete），构成“门控即游标”的核心范式。
- `scheduler.py` 的 `SpacedRepetitionScheduler` 按知识点类型维护间隔序列，生成 `review_queue` 供 `policy.due_reviews` 消费。
- `storage.py` 的 `LearningStore` 用 JSON 文件持久化，使用模块级 `_cas_lock` 保证跨实例 CAS 语义，并通过 `atomic_write_text` 原子写入。
- `prompts.py` 从 `prompts/{en,zh}.yaml` 加载多语言 LLM 提示词，支持区域码回退（如 zh-tw → zh → en → zh）。
依赖方向单向：service → {grading, mastery, scheduler} → models；policy 仅读 models；storage/prompts 被 service/policy 调用，无反向依赖。
