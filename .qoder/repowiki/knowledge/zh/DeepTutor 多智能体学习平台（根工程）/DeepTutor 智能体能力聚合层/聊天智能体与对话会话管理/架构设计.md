模块以 `__init__.py` 暴露三个对外入口：`ChatAgent`（继承 `BaseAgent`，走 RAG/Web Search + 流式/非流式生成）、`AgenticChatPipeline`（能力编排层）和 `SessionManager`（继承 `BaseSessionManager` 实现 JSON 会话存储）。`AgenticChatPipeline` 是核心：构造时加载 prompts（按 `language` 选择 `prompts/en|zh/agentic_chat.yaml`），通过 `ChatPromptAssembler` 把 system prompt 拆成带 `name` 的 `PromptBlock`（general/runtime_policy/loop/persona_style/memory/tools/skills/sources/notebooks/workspace 等），再组装消息并交给 `AgentLoop` 执行一轮“LLM 调用 → 工具分发 → 追加 tool result → 继续”的循环；循环内通过 `dispatch_tool_calls` 并行调度工具，支持 `ask_user` 暂停恢复、终止工具、以及轮次耗尽时的强制 finish。`agent_loop.py` 还处理流式输出中的 `<thinking>` 标签剥离、DeepSeek DSML 工具调用回退、以及每轮 `LLMRequestSnapshot` 快照用于 `context_budget.py` 计算上下文窗口占用。`capability.py` 将本模块注册为名为 `chat` 的 `BaseCapability`，其 `run` 仅创建 pipeline 并委派。依赖方向单向向外：pipeline → loop/prompt_blocks/context_budget → core.agentic / services.llm / runtime.providers，不反向被 core 依赖。
