本模块由两部分组成：
- `base_agent.py` 定义 `BaseAgent` 抽象基类，集中管理 LLM 配置（从 `agents.yaml` 与 `get_llm_config()` 加载）、统一调用接口 `call_llm` / `stream_llm`（封装重试、token 限制、多模态附件注入、`response_format` 能力探测）、Token 追踪（通过外部 `TokenTracker` 或类级共享的 `LLMStats`）以及基于 `PromptManager` 的提示词加载；子类只需实现 `process()`。
- `_shared/` 子包存放跨能力（chat/solve/quiz 等）复用的纯函数与数据契约：`capability_result.emit_capability_result` 将各能力的最终结果经 `StreamBus` 以统一信封发出并合并 `cost_summary`；`json_output.extract_json_object` 提供鲁棒的 JSON 提取（支持 fenced code block、raw decode）；`tool_composition.compose_enabled_tools` 以 `ToolMountFlags` + `AUTO_MOUNTED_TOOLS` + `_CONDITIONAL_MOUNT_FLAGS` 为核心，按固定优先级（用户开关 → 条件自动挂载 → 能力自有工具 → 常驻工具）计算每轮启用的工具列表，并通过 `builtin_whitelist` / `forced` / `suppressed` 参数对外部运行时做白名单、强制追加与抑制。
依赖方向单向向下：`_shared` 仅依赖 `deeptutor.tools.builtin`、`deeptutor.core.*` 与 `deeptutor.services.memory/notebook`；`base_agent` 依赖 `deeptutor.services.llm`、`deeptutor.services.prompt`、`deeptutor.config.settings`；`__init__.py` 通过 `importlib` 懒加载 `ChatAgent`、`SessionManager`，避免循环导入。
