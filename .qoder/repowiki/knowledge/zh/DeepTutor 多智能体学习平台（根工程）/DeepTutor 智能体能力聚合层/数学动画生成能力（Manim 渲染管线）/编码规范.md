- 每个 LLM Agent 继承 `BaseAgent`，通过 `get_prompt('system'/'user_template')` 从 `prompts/{language}/{agent}.yaml` 加载提示词，并以 JSON 响应格式解析为 Pydantic 模型。
- 管线各阶段统一使用 `time.perf_counter()` 记录耗时并存入 `timings` 字典，再通过 `emit_capability_result` 一并返回。
- 对外暴露的配置与中间结果均使用带 `ConfigDict(extra='ignore'|'forbid')` 的 Pydantic BaseModel 建模，确保前后端契约稳定。
- 渲染与重试过程通过回调函数（`on_retry`、`on_render_progress`、`on_retry_status`）向 `StreamBus` 推送进度，trace 元数据统一通过 `build_trace_metadata` 和 `merge_trace_metadata` 注入。
- 可插拔组件（如 visual review）通过构造参数开关并在 `None` 时跳过，保持核心管线不依赖可选功能。
