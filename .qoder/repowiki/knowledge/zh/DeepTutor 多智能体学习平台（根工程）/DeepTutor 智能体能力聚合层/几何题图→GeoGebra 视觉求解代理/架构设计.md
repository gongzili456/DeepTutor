模块以 `VisionSolverAgent`（继承自 `BaseAgent`）为唯一入口，对外暴露 `process` 与 `format_ggb_block` 两个方法，保持与上层 `geogebra_analysis` 工具的契约不变。
- 提示词管理：通过 `prompts/geogebra.md` 加载模板，用 `{{ question_text }}` 占位符注入题干；当首次调用未产生可用命令时，追加 `## 修复` 段落作为 gated repair pass。
- 视觉调用：`_call_vision_llm` 构造包含文本与 base64 图片的 `messages`，经 `stream_llm` 流式获取响应后拼接。
- 输出解析：`_extract_json` 从 markdown 代码块或原始文本中提取 JSON，并容错处理注释与尾随逗号；`_coerce_commands` 将模型返回的 `commands` 标准化为 `{command, description}` 列表。
- 渲染：`format_ggb_block` 将命令序列包装为前端可识别的 `` ```ggbscript[page_id;title] ... ``` `` 代码块。
依赖方向单向：本模块仅依赖 `deeptutor.agents.base_agent.BaseAgent`，不反向引用上层工具层。
