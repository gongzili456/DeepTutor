- Agent 构造函数根据传入 language 参数归一化为 'zh' 或 'en'，再通过 prompt manager 按 agent 名 + 语言加载对应 YAML 提示词，避免在代码中硬编码多语言文本。
- 对外暴露的公开方法采用关键字参数风格（`*` 分隔），可选的 `emit` 回调用于向上传递流式事件，未提供时静默执行。
- 每个 LLM 调用都通过 `build_trace_metadata` 构造 trace 元数据，并在阶段开始/结束时发送 STAGE_START/STAGE_END 事件，中间 chunk 携带 derive_trace_metadata 派生的追踪信息。
- 长文本输入统一通过内部 `_clip_text` 工具函数截断并追加 `...[truncated]` 标记，防止超出模型上下文限制。
- LLM 返回结果先经 `clean_thinking_tags` 清理思维标签后再拼接为最终字符串，保证下游消费得到干净输出。
