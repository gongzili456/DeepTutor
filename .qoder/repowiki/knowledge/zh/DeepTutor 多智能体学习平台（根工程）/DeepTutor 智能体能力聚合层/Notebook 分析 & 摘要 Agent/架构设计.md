模块以两个独立 Agent 类为核心：`NotebookAnalysisAgent` 实现三阶段 reasoning loop（`_stage_thinking` → `_stage_acting` → `_stage_observing`），分别负责理解问题、基于 LLM 输出 JSON 选择最多 5 条记录、再结合选中记录的详细内容生成最终观察；`NotebookSummarizeAgent` 对单条 Notebook 输出做精简摘要。两者均通过 `deeptutor.services.prompt.manager.get_prompt_manager().load_prompts('notebook', <agent>, language)` 加载位于 `prompts/{en,zh}/` 下的 YAML 提示词，从而将语言与业务逻辑解耦。LLM 调用统一经由 `deeptutor.services.llm.stream` 的 `llm_stream` 异步迭代，并通过 `emit: EventSink` 回调向外广播 `StreamEvent`（THINKING/OBSERVATION/TOOL_CALL/TOOL_RESULT/STAGE_START/STAGE_END/RESULT），配合 `build_trace_metadata` / `derive_trace_metadata` 完成追踪埋点。`__init__.py` 仅暴露两个 Agent 类作为包级入口。
