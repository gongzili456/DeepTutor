- 每个 LLM 调用通过 `build_trace_metadata` + `new_call_id` 构造带 phase/label/call_kind 的追踪元数据，再经由 `stream.stage` 上下文和 `stream.thinking/progress/error/content` 上报进度。
- Agent 类继承自 `BaseAgent`，在 `__init__` 中指定 `module_name='visualize'` 与具体 `agent_name`，提示词通过 `get_prompt` 从 `prompts/{language}/` 下的同名 YAML 加载。
- LLM 返回的 JSON 先经 `extract_json_object` 提取，再用 Pydantic model 验证；对未知枚举值使用 `model_validator(mode='before')` 降级而非抛错，保证下游流程继续。
- 文本渲染类型（svg/chartjs/mermaid/html）统一走 `validate_visualization` 进行零成本本地校验，仅在失败时触发一次定向 repair 调用，避免无谓的 LLM 重试。
- 能力运行期间通过 `StatusI18n(self.name, context.language, module='visualize')` 获取多语言状态消息，所有面向用户的 progress/thinking 文案均经 `i18n.t` 翻译。
- 最终结果通过 `emit_capability_result` 统一封装，并以 `render_type` 作为前端路由判别字段，使同一能力可被不同 viewer 消费。
