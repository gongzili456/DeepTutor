根目录作为整个 DeepTutor 工程的装配层：
- 依赖与入口：pyproject.toml 声明 `deeptutor` Python 包与 `deeptutor_cli` CLI，并通过 optional-dependencies（cli/server/partners/parse/graphrag/rag-lightrag/dev/all）把 deeptutor_core、agents、capabilities、book_engine、co_writer、knowledge、learning、multi_user、partners、runtime、services、tools、utils、api、cli、web_frontend、tests 等子模块统一纳入同一 wheel。
- 运行期编排：Dockerfile 采用多阶段构建，将 Next.js 静态产物与 Python 依赖合并进单一 production image，由 supervisord 同时启动 FastAPI 后端（:8001）与 Next.js 前端（:3782），entrypoint.sh 在启动时从 data/user/settings/*.json 加载运行时配置并导出环境变量，使前后端共享同一份 JSON 驱动的配置源。
- 容器编排：compose.yaml 定义 deeptutor 与可选 pocketbase sidecar，使用 userns_mode: keep-id + read_only rootfs + tmpfs 实现 rootless 安全部署；data 目录以 bind mount 形式持久化用户工作区、知识库与日志。
- 开发/测试：.pre-commit-config.yaml、pytest 配置、requirements.txt 与 scripts/ 提供统一的代码质量与测试入口，tests 覆盖所有业务子模块。
- 发布：MANIFEST.in、CITATION.cff、THIRD_PARTY_NOTICES.md 与 assets_and_docs 中的 GitHub Actions 流水线共同支撑 PyPI 与 GHCR 制品分发。
