模块由三个相互协作的层次组成：
- `base.py` 定义 `SubagentBackend` 抽象基类，通过 `detect()` 和 `consult(..., on_event=...)` 两个异步方法统一封装任意本地 CLI（Claude Code、Codex、Gemini、Kimi、opencode/MiMo）或 Partner 后端的安装检测与问题咨询流式事件回调，屏蔽具体 CLI 参数与 JSON 事件差异。
- `config.py` 使用 `dataclass(slots=True)` 建模 `BackendConfig` 与 `SubagentSettings`，以 `subagent.json`（位于 `get_path_service().get_settings_file` 指向的用户目录）作为唯一持久化源，提供 `load_subagent_settings`/`save_subagent_settings`/`settings_from_dict` 等安全默认值 + 类型强制转换的读写 API，并通过 `get_consult_budget()` 暴露全局预算查询。
- `models.py` 实现后端选项发现层：每个后端对应一个 `_xxx_options()` 协程，注册到 `_PROVIDERS` 映射中；`list_backend_options()` 用 `asyncio.gather` 并发探测所有后端，`sync_backend_options(kind)` 针对 Claude Code（调用 `claude_models.sync_claude_models`）、opencode 家族（`models --refresh`）和 Codex（读取 `$CODEX_HOME/models_cache.json`）执行差异化刷新，返回 `BackendOptions` / `ModelOption` 供 UI 渲染。
依赖方向单向：`models.py` → `registry`/`process`/`claude_models`，`base.py` → `config`/`types`，`config.py` 仅依赖 `path_service`，无循环依赖。
