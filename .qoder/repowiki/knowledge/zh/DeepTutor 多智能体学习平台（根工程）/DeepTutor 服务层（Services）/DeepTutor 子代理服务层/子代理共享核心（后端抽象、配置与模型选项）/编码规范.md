- 后端扩展采用“提供者函数 + 映射表”模式：新增后端只需添加 `_xxx_options()` 协程并在 `_PROVIDERS` 字典中注册，不修改其他代码。
- 配置数据类统一使用 `@dataclass(slots=True)` 声明，并通过独立的 `_coerce_*` 函数对 JSON 输入做宽松解析与边界裁剪（如 `CONSULT_BUDGET_MIN/MAX`）。
- 对外暴露的公共 API 通过模块级 `__all__` 显式声明，内部辅助函数保持私有命名（下划线前缀）。
- CLI 探测与版本获取统一经由 `probe_version([backend.cli_command, "--version"])` 完成，失败时记录警告日志并降级为可用但不可用状态。
- 每个后端选项构造器都遵循相同字段集：`kind`、`display_name`、`available`、`version`、`models`、`efforts`、`allow_custom_model`、`synced_at`、`detail`，并以 `to_dict()` 序列化供 API 消费。
