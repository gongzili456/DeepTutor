模块由三个职责清晰的文件组成，构成子代理驱动层的基础设施：
- `types.py` 定义跨边界的数据契约——`SubagentEvent`、`ConsultResult`、`DetectResult` 数据类及事件通道常量（`EVENT_TEXT`/`EVENT_REASONING`/`EVENT_TOOL`/`EVENT_TOOL_RESULT`/`EVENT_LOG`/`EVENT_RESULT`/`EVENT_ERROR`），被上层 consult 工具与 API 消费，使后端实现无需感知具体 CLI。
- `process.py` 提供底层原语：`stream_process_lines` 通过 `asyncio.create_subprocess_exec` 启动子进程，用两个 `_pump` 协程分别读取 stdout/stderr 并写入共享 `asyncio.Queue`，按到达顺序 yield `(channel, line)`，最终以 `("exit", returncode)` 结束；`_terminate` 采用 terminate→等待 grace period→kill 的优雅终止策略；`probe_version` 用于快速检测 CLI 是否可用。
- `sessions.py` 基于 JSON 文件（`subagent_sessions.json`，路径来自 `path_service`）维护 `(chat_session_id, connection)` 到后端 session id 的映射，提供 `get_session`/`remember_session`/`forget_connection` 接口，在连接断开时清理对应条目。
依赖方向单向：`sessions.py` 依赖 `path_service`，`process.py` 仅依赖 stdlib，`types.py` 零外部依赖；三者共同被更上层的 subagent 后端（如 Claude Code、Codex 等）复用。
