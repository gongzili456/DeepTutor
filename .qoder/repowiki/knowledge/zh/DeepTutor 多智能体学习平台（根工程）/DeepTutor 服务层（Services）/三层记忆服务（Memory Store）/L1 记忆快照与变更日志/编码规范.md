- 每个 surface 的适配器都是独立的只读函数，通过 `_READERS` 字典集中注册并由 `read_entities` 统一分发，新增 surface 只需添加条目。
- 所有外部 I/O 调用（文件读取、SQLite 查询、YAML 解析）都包裹在 try/except 中，失败时返回空结果或跳过该条目，保证快照扫描不会因单个源损坏而中断。
- 实体通过组合关键业务字段调用共享的 `_sha1` 生成短指纹，确保同一内容在不同运行间产生稳定标识。
- 持久化采用幂等设计：`save_state` 使用 `.json.tmp` 临时文件再 `os.replace` 原子替换，`append_changes` 对空变更列表直接 return 避免写空日志。
- `ChangeEntry` 与 `Entity` 均为纯 dataclass，并提供 `to_dict()` 方法供序列化使用，I/O 逻辑完全隔离在 store/adapters 中。
