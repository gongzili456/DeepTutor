模块以 `store.MemoryStore` 为唯一对外门面，按三层职责划分：
- L1 层：`trace.py` 将 `TraceEvent` 以 JSONL 形式按 surface/天追加到 `<memory_root>/trace/<surface>/<date>.jsonl`，由 `ids.new_trace_id` 生成 ULID 风格 ID。
- L2/L3 层：`document.Document` 表示带脚注引用的 Markdown 文档，`parse/serialize` 是纯函数；`paths` 提供 per-user 路径解析（通过 `PathService` 上下文变量延迟绑定），`ops` 提供 Add/Edit/Delete 操作及原子写入。
- 整合层：`consolidator/` 子包实现 L1→L2 (`update_l2`) 与 L2→L3 (`update_l3`) 的 chunk-based 增量整合，模式位于 `consolidator/modes/{update,audit,dedup,merge}.py`，共享运行时在 `_runtime.py`，提示词按语言分置于 `prompts/{en,zh}/` YAML。
- 快照层：`snapshot/` 维护每个 surface 的 `state.json`（实体指纹+标签）和 append-only `changes.jsonl`，用于增量 diff 与审计回溯。
- 配置：`settings.py` 用 frozen dataclass 定义 `MemorySettings` 树，从 `data/user/settings/main.yaml` 的 `memory:` 子树加载并做类型强制与范围钳制。
依赖方向单向：`store → consolidator/document/ops/paths/trace/snapshot`，顶层 `__init__.py` 仅暴露 `MemoryStore`、`get_memory_store`、`Surface`、`L3Slot`、`TraceEvent` 等稳定 API。
