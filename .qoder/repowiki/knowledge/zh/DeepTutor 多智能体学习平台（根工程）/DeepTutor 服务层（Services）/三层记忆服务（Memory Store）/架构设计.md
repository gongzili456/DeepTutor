本模块以 `store.py` 中的 `MemoryStore` 为唯一对外入口，所有调用方（API 路由、LLM 工具、surface 事件钩子）均经此门面访问三层记忆。
- L1 层：`trace.append` 追加原始事件 JSONL；`snapshot` 子模块按 surface 扫描工作区实体、计算指纹差异并持久化状态与变更日志，供 L2 整合时感知上游变化。
- L2/L3 层：`document`/`ops` 提供纯函数式解析与编辑；`consolidator` 在 `update_l2` / `update_l3` 中由 LLM 生成 ops 并经 `apply_ops` 原子写入，写路径通过 `paths.l2_file` / `paths.l3_file` 解析到 per-user 目录。
- 并发与一致性：`MemoryStore` 按文件路径维护 `asyncio.Lock`，确保同一文档的并发写入串行化；所有磁盘写入走 `_atomic_write`（先写 .tmp 再 replace）。
- 启动期迁移：`migrate_v1_if_needed` 与 `migrate_partner_surface_if_needed` 在首次加载时处理旧版结构与 surface 重命名，保证新旧数据共存。
- 隔离机制：用户级隔离由 `paths.memory_root` 基于 `PathService` 上下文变量懒解析实现，`MemoryStore` 本身无状态。
