模块以 `factory.py` 为入口，维护 `_ENGINE_LOADERS` 名称→类加载器的映射（通过延迟导入函数如 `_mineru_class()`），对外暴露 `get_parser`、`is_engine_available`、`list_engines` 三个 API；每个引擎子包（`mineru/`、`docling/`、`markitdown/`、`pymupdf4llm/`、`text_only/`）遵循相同结构：`engine.py` 实现 `Parser` 协议（`name`、`needs_local_models`、`is_available`、`resolve_config`、`supported_formats`、`signature`、`is_ready`、`parse`），`config.py` 用 frozen dataclass 封装配置并通过 `runtime_settings` 读取持久化设置，`__init__.py` 仅做再导出。依赖方向单向：引擎 → 上层 `..base`/`..signature`/`..types`，不反向引用工厂；第三方库（docling、mineru、markitdown、pymupdf4llm）全部在 `is_available`/`parse` 内延迟 import，保证未安装时仍可枚举引擎。`_install.py` 提供 `BackgroundJobManager`，以固定白名单执行 `pip install` 或 `docling-tools models download`，通过线程泵出 stdout 并以 cursor 协议增量推送日志；`_versions.py` 用 `lru_cache` + `importlib.metadata.version` 缓存包版本用于签名计算。MinerU 子包额外拆分 `backend.py`/`cloud.py`/`local.py`/`readiness.py`/`models.py` 以区分本地 CLI 与云 API 两条路径。
