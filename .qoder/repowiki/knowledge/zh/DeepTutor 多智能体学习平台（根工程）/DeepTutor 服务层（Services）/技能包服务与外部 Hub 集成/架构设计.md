模块以 `service.py` 中的 `SkillService` 为核心，实现两层技能存储：只读的内置层（`deeptutor/skills/builtin/`）与可写的用户层（`data/user/workspace/skills/`），通过 `_resolve_skill_dir` 按名称覆盖解析；每个技能是含 YAML frontmatter 的 `SKILL.md` 目录，支持 `requires.bins/env/sandbox` 可用性门控与 `always: true` 的提示词注入。

- `hub.py` 定义 `SkillHubProvider` Protocol 及 `ClawHubProvider`（HTTP `/api/v1`）、`CommandProvider`（外部 CLI 包装）两种提供者，配合 `install_from_hub` 编排 verify→fetch→install 流程，使用 zip-slip 防护、压缩比限制、后缀白名单等边界将包安全落地到临时目录后交由 `SkillService.install_tree` 原子替换。
- `credentials.py` 在 settings 目录中以 `skill_hub_auth.json`（0600 权限）持久化各 hub 的 bearer token，供 publish/update 使用。
- `taxonomy.py` 集中声明 EduHub 分类维度（track/language/stage/form/audience/domains）及其双语标签，作为发布表单与 API 校验的唯一数据源。
- 依赖方向单向向外：本模块仅通过 `path_service` 获取工作区/设置路径，并通过 `services.sandbox` 延迟导入检查执行沙箱能力，避免循环依赖。
