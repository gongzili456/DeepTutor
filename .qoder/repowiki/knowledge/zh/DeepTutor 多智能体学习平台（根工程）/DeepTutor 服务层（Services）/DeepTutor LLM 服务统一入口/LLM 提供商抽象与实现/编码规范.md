- 每个提供商类通过 `@register_provider("<name>")` 装饰器在模块加载时向 registry 注册自身标识。
- `complete` 方法内部将实际 SDK 调用封装为局部 `_call_api` 协程，并通过 `self.execute_with_retry(_call_api)` 复用基类的重试、熔断与指标上报逻辑。
- `stream` 方法返回 `AsyncStreamGenerator`，逐块产出 `TutorStreamChunk`，并以一个 `is_complete=True` 的终止 chunk 结束流。
- 模型参数优先从调用方 kwargs 中读取，回退到 `self.config.model`，缺失时抛出 `LLMConfigError`。
- 对第三方 SDK 的 streaming 响应使用 `Protocol` 类型（如 `OpenAIStream`、`AnthropicStream`）配合 `cast` 进行静态类型标注，避免直接依赖 SDK 内部结构。
- provider 间差异化的 kwarg 通过白名单/黑名单方式处理（如 Anthropic 的 `_DISALLOWED_KWARGS` 过滤），保证同一套调用入口可适配不同 SDK。
