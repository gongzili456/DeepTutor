- 每个搜索引擎实现一个继承自 `BaseSearchProvider` 的类，并通过 `@register_provider('name')` 装饰器声明自身名称，由 `providers/__init__.py` 统一注册。
- 提供商通过类属性 `requires_api_key`、`supports_answer`、`display_name`、`description`、`BASE_URL`、`API_KEY_ENV_VARS` 声明能力与元数据，供注册表与 UI 展示使用。
- 搜索结果统一封装为 `SearchResult` 与 `Citation` 数据类，并由 `WebSearchResponse` 聚合返回，provider 不直接返回原始 dict。
- 对于 `supports_answer=False` 的原始 SERP 提供商，答案生成交由 `AnswerConsolidator` 处理，按 provider 选择专属 Jinja2 模板或回退到通用格式化。
- 配置与凭据通过 `resolve_search_runtime_config()` 从 Settings > Catalog 获取，provider 构造函数中通过 `_get_api_key()` 自动解析，避免硬编码密钥。
