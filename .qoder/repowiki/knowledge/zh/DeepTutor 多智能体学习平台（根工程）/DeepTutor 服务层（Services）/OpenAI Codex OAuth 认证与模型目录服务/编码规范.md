- 所有对外错误统一通过 `CodexAuthError(code, public_message, http_status)` 抛出，调用方据此映射 HTTP 状态码。
- 持久化数据类（`CodexCredentials`、`CatalogSnapshot`、`CodexModel`）均提供 `to_dict` / `from_dict`，且 `from_dict` 对类型做严格校验，失败时转为带明确 code 的 `CodexAuthError`。
- 并发安全通过 asyncio `Lock`（登录操作、刷新、目录同步、推理入口）与文件系统 `threading.Lock` + 文件级独占锁双重保障，写路径一律使用 `_atomic_write_json` 原子替换。
- 敏感凭据与目录缓存统一存放在 `user_root/private/openai-codex/*.v1.json`，并通过递增的 `generation` 字段实现乐观并发检测。
- 所有外部输入（state、token、catalog JSON、HTTP 响应）在进入领域对象前都经过白名单式类型检查，拒绝 bool 混入 int、空字符串、越界数值等畸形值。
- 上游接口参数集中在 `constants.py` 中声明（Issuer、Client ID、Scope、URL、端口、超时、大小上限），业务代码不内联字符串字面量。
