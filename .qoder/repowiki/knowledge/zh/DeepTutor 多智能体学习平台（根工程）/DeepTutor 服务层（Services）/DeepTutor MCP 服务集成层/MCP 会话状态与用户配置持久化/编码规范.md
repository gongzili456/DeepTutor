- 对外暴露的异常统一继承自自定义错误类（如 `UserMcpError(ValueError)`），并通过 `code` 字段携带机器可读的错误码，便于上层分类处理。
- 所有 I/O 操作（读 JSON、写 JSON）均包裹 try/except 并记录日志后降级返回空结果或空配置，保证外部调用方不因磁盘损坏而崩溃。
- 用户输入校验集中在专用函数（如 `_assert_self_service_allowed`、`validate_mcp_url`）中，通过抛出带 code 的异常来拒绝非法 server name、transport 或 URL。
- 写路径一律采用「临时文件写入 → fsync → os.replace」的原子替换模式，避免并发编辑导致配置丢失或部分写入。
- 模块通过 `__all__` 显式声明导出符号，并在包 `__init__.py` 中集中 re-export 各子模块的公共 API，形成单一入口。
