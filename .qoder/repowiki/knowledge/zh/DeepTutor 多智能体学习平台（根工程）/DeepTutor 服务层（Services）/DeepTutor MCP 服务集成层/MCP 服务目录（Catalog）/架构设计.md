模块由三个文件构成清晰的分层：`models.py` 定义不可变数据模型 `McpCatalogEntry`、`CredentialField`、`BuiltServer` 及枚举常量（类别、层级、传输方式），并在 `__post_init__` 中强制三条不变式——stdio 条目不可 self-service、凭据目标必须匹配传输类型、secret 值不进入配置；`loader.py` 负责从同包下的 `vendor/curated.json` 解析条目，通过 `@lru_cache(maxsize=1)` 缓存结果，提供 `search_catalog`（带 cursor 分页）、`category_counts`、`get_entry`、`reset_catalog_cache` 等纯函数 API；`__init__.py` 统一对外暴露这些符号。依赖方向单向：`loader` → `models` → `deeptutor.services.mcp.config` / `secrets`，调用方只看到 `MCPServerConfig`，对数据来源完全隔离，保证请求路径零网络访问。
