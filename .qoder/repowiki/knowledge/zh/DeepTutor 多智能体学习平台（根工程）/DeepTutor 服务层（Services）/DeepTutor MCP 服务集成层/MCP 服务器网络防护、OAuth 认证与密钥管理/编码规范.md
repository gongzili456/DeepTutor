- 所有敏感数据按 `(owner_id, server)` 维度落盘到 `private/mcp*` 子目录，文件名经 `_SAFE_NAME_RE` 白名单校验后拼接为 `<server>.json`。
- 文件写入统一采用 tmp 文件 + `os.fsync` + `os.replace` 的原子替换模式，并在 finally 中清理临时文件。
- 对外暴露的公开接口集中在文件末尾的 `__all__` 列表中显式声明，未列出的内部函数/常量视为私有。
- 需要阻塞 I/O 的函数（如 DNS 解析、磁盘读写）同时提供同步与 `asyncio.to_thread` 包装的异步版本，供事件循环调用。
- 读取损坏或权限不足的 secrets/OAuth 文件时记录 warning 日志并降级为空数据，而非向上抛出异常中断连接。
