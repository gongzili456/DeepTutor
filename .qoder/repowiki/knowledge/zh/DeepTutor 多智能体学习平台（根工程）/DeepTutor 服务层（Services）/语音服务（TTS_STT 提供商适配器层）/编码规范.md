- 所有外部 HTTP 调用统一使用 `httpx.AsyncClient` 并以 `config.request_timeout` 设置超时，错误经 `_raise_for_provider` 转换为 `VoiceProviderHTTPError`。
- 认证头通过 `build_auth_headers(auth_style, api_key)` 集中生成，避免在各适配器中重复拼接 Authorization 或自定义 header。
- URL 拼接统一走 `join_audio_path` / `_join_api_path`，自动处理 base_url 尾部斜杠、查询串保留与已含 `/audio/` 路径的兜底逻辑。
- 配置对象使用 `@dataclass(slots=True)` 声明，并通过 `provider_name` + `adapter` 字段配合工厂函数选择具体实现。
- 适配器类继承 `BaseTTSAdapter` / `BaseSTTAdapter` 抽象基类，以 `async def synthesize/transcribe` 作为唯一契约方法。
- 对第三方网关的特殊行为（如 OpenRouter 回退、Gemini voice 提示）通过独立辅助函数（`_openrouter_tts_hint`、`_chat_audio_format`）封装，不污染主流程。
