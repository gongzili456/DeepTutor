- 每个可持久化设置域都遵循「DEFAULT_* 常量 + load/save 成对方法 + _normalize_* 归一化器」的模式，确保读回的数据结构稳定。
- 服务类采用类级 `_instances` 字典 + `get_instance(...)` 工厂实现基于 Path 的单例，保证同一 settings 目录只持有一个实例。
- 进程环境变量覆盖通过独立的 `_apply_*_process_overrides` 方法集中映射到字段，并以 `include_process_overrides` 开关控制是否生效。
- 数值型配置一律经 `_coerce_int` / `_coerce_clamped_int` / `_coerce_port` 等强制转换与范围钳制后再落盘，防止非法值污染配置文件。
- 对外暴露的模块属性通过 `__getattr__` 懒加载重导出，仅在首次访问时才 import `provider_runtime` / `test_runner`，避免顶层循环导入。
- JSON 写操作统一使用临时文件 + `os.replace` 或 `atomic_write_json`，保证多进程并发下的文件完整性。
