本模块作为 `deeptutor/services` 包的核心子模块，按职责拆分为独立文件并通过 `__init__.py` 的 `__getattr__` 懒加载机制暴露顶层 API，避免导入重型依赖。
- 认证 (`auth.py`)：以配置驱动（`load_auth_settings`/`load_integrations_settings`），默认关闭；支持本地 bcrypt+PyJWT (HS256) 与可选 PocketBase 模式（通过 `pocketbase_client.py` 调用 `/api/collections/users/auth-refresh` 校验令牌并缓存 60s）；用户持久化委托给 `multi_user.identity`，首注册用户自动授予 admin。
- 路径管理 (`path_service.py`)：`PathService` 单例集中定义 `data/user` 下的完整磁盘布局（workspace、settings、memory、notebook、co-writer、book、chat/* 等），通过 `get_path_service()` 优先返回多用户隔离实例，否则回退到默认实例；提供 `ensure_*` 方法自动创建目录。
- 文件 IO (`file_io.py`)：无外部依赖，使用 `tempfile.NamedTemporaryFile` + `os.fsync` + `replace` 实现 JSON/文本的原子写入，保证并发安全。
- HTTP 生成工具 (`generation_http.py`)：抽象 OpenAI/Volcengine 等图像/视频生成提供商共用的鉴权头构造、URL 拼接与错误提升，供 imagegen/videogen 适配器复用。
- Provider 注册表 (`provider_registry.py`)：以 `ProviderSpec` dataclass 集中声明所有 LLM 后端（openai、anthropic、gemini、ollama、vllm、各网关等），通过 `PROVIDERS` 元组顺序决定匹配优先级，并提供 `find_by_name/find_by_model/find_gateway` 路由函数。
- PocketBase 客户端 (`pocketbase_client.py`)：按需导入 `pocketbase` SDK，维护全局单例客户端与 60s 令牌缓存，提供健康检查 `ping_pocketbase`。
依赖方向单向向下：auth → pocketbase_client/config；path_service → runtime.home；provider_registry 仅依赖 pydantic；file_io 零外部依赖。
