- 每个后端继承 `SandboxBackend` 并声明类属性 `level: IsolationLevel`，由 `SandboxService.isolation_level` 统一上报以驱动权限门控。
- 执行请求同时携带 `command`（shell 字符串）与 `argv`（参数向量）两种拼写，`ExecRequest.__post_init__` 强制二者等价，确保新旧 runner 滚动部署时行为一致。
- 所有异步方法返回统一的 `ExecResult` 数据类，命令级失败走 `exit_code`/`stderr`，仅沙箱自身错误填充 `error` 字段，调用方据此区分业务失败与基础设施故障。
- 配置项集中通过 `SandboxSettings.from_env()` 从环境变量解析，并以 frozen dataclass 暴露给后端构造器，避免散落的全局状态。
- 资源限制采用 best-effort 双层防护：上层 `asyncio.wait_for` 超时杀进程，下层 runner 侧车通过 `resource.setrlimit` 设置 RLIMIT_AS/RLIMIT_CPU/RLIMIT_NOFILE。
- 对外暴露的 API 均通过 `__all__` 显式导出，内部辅助函数保持私有命名（以下划线开头）。
