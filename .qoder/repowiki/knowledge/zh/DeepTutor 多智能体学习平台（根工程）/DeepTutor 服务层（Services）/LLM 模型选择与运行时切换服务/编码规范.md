- 对外暴露的选择对象使用 `@dataclass(frozen=True, slots=True)` 定义为不可变值对象，并通过 `from_payload` 类方法统一做类型转换与参数校验。
- 对 catalog 的读取采用防御式遍历：先检查 `isinstance(..., dict)` 再安全 `.get()`，遇到缺失键时跳过而非抛错，保证鲁棒性。
- 运行时切换遵循 activate/reset 成对模式：`activate_llm_selection` 返回 `(config, token)`，调用方在 finally 中调用 `reset_llm_selection(token)` 恢复上下文。
- 模块通过包级 `__init__.py` 显式 re-export 公共 API 并维护 `__all__`，内部函数以下划线前缀标记为私有。
