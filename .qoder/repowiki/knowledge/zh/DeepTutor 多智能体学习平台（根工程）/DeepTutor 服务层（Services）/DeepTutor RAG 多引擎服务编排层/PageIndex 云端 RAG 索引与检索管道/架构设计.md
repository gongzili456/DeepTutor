模块按职责拆分为四个文件：`pipeline.py` 暴露 `PageIndexPipeline` 类，实现与 `LlamaIndexPipeline` 同构的 RAG 接口（`initialize`/`add_documents`/`search`/`delete`），负责 KB 目录解析、文件过滤（仅支持 `.pdf/.md/.txt/.docx/.pptx/.xlsx/.csv` 等）、调用 client 提交并轮询处理状态、聚合各文档树大纲；`client.py` 是薄封装的异步 HTTP 客户端，基于 `httpx.AsyncClient` 提供 `/doc/` 提交、`/doc/{id}/` 查询与删除，内置 `wait_until_ready` 轮询逻辑和统一的 `_json` 响应校验；`config.py` 通过 `RuntimeSettingsService` 加载 `pageindex.json` 中的 `api_key` 与 `api_base_url`，未配置时抛出 `PageIndexNotConfiguredError`；`storage.py` 维护本地 `version-N/pageindex_docs.json` 清单（文件名→云端 `doc_id`）及 `meta.json`，复用上层 `index_versioning` 版本目录约定以兼容 UI。依赖方向单向：pipeline → client + storage + config，不反向依赖外部服务。
