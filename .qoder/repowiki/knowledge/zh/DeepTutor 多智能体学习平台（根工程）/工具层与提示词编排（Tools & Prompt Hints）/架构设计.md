模块以 `tools/__init__.py` 的 `_LAZY_EXPORTS` 字典作为统一入口，通过 `__getattr__` 实现按需导入，避免在注册阶段加载重型依赖；所有对外暴露的类（BrainstormTool、RAGTool、WebSearchTool、CodeExecutionTool、ReasonTool、PaperSearchToolWrapper、GeoGebraAnalysisTool、ReadSourceTool、ReadMemoryTool、WriteMemoryTool、ListNotebookTool、WriteNoteTool、ExecTool 等）均继承自 `deeptutor.core.tool_protocol.BaseTool`，通过 `get_definition()` 声明 `ToolDefinition`（名称、参数、类型），通过 `execute(**kwargs)` 返回 `ToolResult`，从而被上层工具注册表自动发现。

- 职责分层：`builtin/` 仅定义 Tool 子类并委托到同目录或同级文件中的纯函数实现（如 `brainstorm.py`、`rag_tool.py`、`web_search.py`、`reason.py`、`paper_search_tool.py`、`exec_tool.py`、`list_notebook.py`、`write_note.py`、`partner_memory.py`、`media_gen_tool.py`、`tex_chunker.py`、`tex_downloader.py`、`github_query.py`、`cron_tool.py`、`mastery_tool.py`、`solve_tool.py`），使每个工具保持“薄包装 + 厚逻辑”的结构。
- 提示词系统：`prompting/` 子包从 `hints/en` 与 `hints/zh` 下的同名 YAML 文件加载 `ToolPromptHints`，按语言优先、英文回退的策略读取 `short_description`、`when_to_use`、`input_format`、`guideline`、`note`、`phase`、`aliases` 等字段；`ToolPromptComposer` 提供 list / table / aliases / phased 等多种渲染格式，供 chat persona 与工具列表展示复用。
- 领域子包：`vision/` 专注几何题图像解析（block_parser 提取 GGBScript 代码块、ggb_validator 校验 GeoGebra 语法、coord_transform 坐标变换、image_utils 图像处理）；`question/` 提供考试题目生成入口（exam_mimic.py 转发至 `agents.question.AgentCoordinator`）。
- 依赖方向：本模块向上暴露 `BaseTool` 实例给工具注册表，向下依赖 `core/tool_protocol`、`services.sandbox`、`services.llm`、`knowledge.manifest`、`capabilities.*`、`agents.vision_solver` 等子系统，自身不持有全局状态；服务依赖一律在 `execute` 内部延迟 import，以避免 tools→services→runtime→registry→tools 循环导入。
