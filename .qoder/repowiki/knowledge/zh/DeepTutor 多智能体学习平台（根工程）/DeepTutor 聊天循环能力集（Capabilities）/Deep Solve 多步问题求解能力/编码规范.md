- solve 工具统一通过 `_resolve_session_id(kwargs)` 从 `_solve_session_id` 解析会话键，并在缺失时返回统一的 `_no_session_result()` 失败响应。
- 工具返回结果使用 `_json_result(payload, meta_key=..., extra_meta={...})` 构造 `ToolResult`，将结构化 payload 序列化为 JSON 并通过 metadata 透出供上层消费。
- 步骤列表由 `_parse_steps` 清洗后强制以 `S1/S2/…` 服务器生成 id 写入，禁止模型直接控制存储键。
- 所有可被模型调用的状态变更方法（`set_plan`、`replan`、`mark_done`）都返回明确的布尔或对象信号，由工具层再包装成带 `instruction` 字段的自然语言反馈。
- 进程级状态通过模块级 `OrderedDict` + `get_session` 懒创建并提供容量上限淘汰，避免在长驻进程中累积会话。
