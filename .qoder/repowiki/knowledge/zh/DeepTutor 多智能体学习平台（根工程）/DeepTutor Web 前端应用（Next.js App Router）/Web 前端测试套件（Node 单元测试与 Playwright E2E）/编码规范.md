- 单元测试统一使用 `import test from "node:test"` 与 `import assert from "node:assert/strict"`，并以 `test("描述", () => { ... })` 形式组织用例。
- 被测对象通过相对路径从 `../lib/*` 或 `@/components/*` 导入，避免在测试中引入框架层，确保测试只验证纯逻辑。
- 对外部依赖（如 `fetch`、`t()` i18n 函数）通过局部变量替换或 fake 实现进行隔离，例如用 `fakeT` 返回带前缀的 key 以便断言翻译映射。
- 测试数据通过本地工厂函数（如 `user(...)`、`field({...})`、`page(...)`）构造，集中定义并复用，避免在断言中散落硬编码对象。
- E2E 用例使用 `test.describe` 分组（如 Accessibility & Semantics、Error Handling & UX Signals），并通过 `page.route` 拦截 API 注入模拟响应。
- JSON fixture 以语义化键（如 `cli`、`mcp`）组织多来源的 trace 事件，供多个测试文件共享加载。
