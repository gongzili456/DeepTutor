- 每个区块页面都通过 `SpaceSectionHeader` 组件统一渲染标题、描述、可选 action 与 meta 元信息，保持各 section 视觉一致。
- 数据获取采用 `useEffect` + `useState` 的自包含模式：组件内定义 `load()` 回调，在 `useEffect` 中调用并在 finally 中重置 loading/error 状态。
- 用户可见文案一律通过 `useTranslation().t(...)` 包裹，禁止硬编码中英文字符串。
- 长耗时或重型子模块（如 Markdown 渲染器）使用 `next/dynamic({ ssr: false })` 按需加载，减少首屏体积。
- 危险操作（删除会话/技能/Agent）先弹出 `window.confirm` 确认，再执行副作用并在完成后刷新列表。
- Dashboard 卡片通过声明式 `GROUPS` 数组配置（key/href/icon/title/blurb/unit/tile/load），UI 仅负责遍历渲染，新增功能只需追加条目。
