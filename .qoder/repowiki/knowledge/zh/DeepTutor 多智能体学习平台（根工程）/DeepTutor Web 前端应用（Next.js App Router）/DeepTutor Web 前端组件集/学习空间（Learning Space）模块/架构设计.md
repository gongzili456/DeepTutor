模块以 `SpaceMain.tsx` 作为布局壳，根据 pathname 在普通文档容器与 full-bleed 模式之间切换，并提供统一的“回到 Hub”导航；`SpaceDashboard.tsx` 是 `/space` 的枢纽页，通过声明式 `GROUPS` + `DashboardItem` 配置表驱动各功能卡片，每个卡片自带 `load()` 异步计数并独立失败隔离。

每个业务区块（ChatHistorySection、NotebooksSection、QuestionBankSection、PersonasSection、SkillsSection、McpStoreSection、MyAgentsSection）都是独立的 React 客户端组件，统一使用 `SpaceSectionHeader.tsx` 渲染标题区，并通过 `@/lib/*-api` 调用后端数据、通过 `useTranslation` 做 i18n。

导入相关能力集中在 `ImportWizard.tsx`（多阶段状态机 intro→scanning→select→importing→done/error）、`ScopePicker.tsx` 与 `ScopeEditorModal.tsx`（按项目/日期范围定义 agent scope），以及 `EduHubImportModal.tsx`（从 EduHub 安装技能）。依赖方向单向：本模块 → `@/lib/*-api`、`@/components/common/*`、`@/context/AppShellContext`，不反向被 lib 引用。
