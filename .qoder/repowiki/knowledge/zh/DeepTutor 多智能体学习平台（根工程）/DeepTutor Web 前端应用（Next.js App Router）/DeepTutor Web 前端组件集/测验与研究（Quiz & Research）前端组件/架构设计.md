模块按功能分为两个并列子目录：`quiz/` 实现测验交互流，`research/` 实现深度研究的配置与大纲编辑。

- `quiz/QuizViewer.tsx` 是核心容器，维护当前题目索引、答案状态、笔记条目 ID、书签、分类、AI 判流结果等本地 state；通过 `@/lib/quiz-question-type` 判断题型并自动评分，调用 `@/lib/notebook-api` 的 `lookupNotebookEntry`/`upsertNotebookEntry` 将答案、图片、AI 判词持久化到 notebook，并通过 `recordQuizResults` 上报完成结果。AI 判卷走 `startQuizJudge` 的流式接口，句柄保存在 `judgeHandlesRef` 中以便取消。
- `quiz/FollowupChatComposer.tsx` 是一个自包含包装器，复用主聊天页的 `ChatComposer`，但把发送路由到 `useQuizFollowupController().sendMessage`，并自行加载 KB/LLM/附件等数据，使 follow-up 标签拥有与主聊天一致的 UI 能力。
- `quiz/QuizFollowupTabBody.tsx` 渲染 follow-up 标签页主体：固定上下文卡片（问题/答案/AI 判词）+ 可滚动消息列表 + 底部 composer；通过 `useFollowupThread` 订阅控制器状态，并在首次打开时根据 `followup_session_id` 调用 `getSession` 回填历史消息。
- `quiz/QuizConfigPanel.tsx` 提供自定义/仿试卷两种模式，支持拖拽比例条调整各题型数量、PDF 上传与解析路径输入，使用 `CollapsibleConfigSection` 折叠展示。
- `research/ResearchConfigPanel.tsx` 暴露研究模式（notes/report/comparison/learning_path）、深度（quick/standard/deep/manual）及手动模式的子主题数与迭代次数滑块，同样以 `CollapsibleConfigSection` 包裹。
- `research/ResearchOutlineEditor.tsx` 管理生成的研究大纲条目，支持增删改、确认锁定、在 researching/done 状态下自动折叠。

依赖方向：本模块仅向上消费 `@/context/QuizFollowupContext`、`@/lib/*` 工具与共享 UI 组件（MarkdownRenderer、composer-field），不向外暴露 API，由上层 SessionViewerPanel 或 Playground 组合使用。
