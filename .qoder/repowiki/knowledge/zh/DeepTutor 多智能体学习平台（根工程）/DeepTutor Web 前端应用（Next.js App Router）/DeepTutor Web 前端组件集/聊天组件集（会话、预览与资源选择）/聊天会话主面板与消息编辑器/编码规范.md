- 所有组件顶部标注 "use client" 并以 `export default memo(function ...)` 形式导出，保持纯函数组件风格。
- 外部交互一律通过 props 回调（如 `onSend`、`onSelectCapability`、`onOpenAttachment`）上抛，组件自身不持有业务状态。
- 跨组件命令式通信采用 `forwardRef` + `useImperativeHandle` 暴露 handle（如 `ComposerInputHandle`、`SessionViewerPanelHandle`），而非直接操作 DOM。
- 重型预览组件（PDF、Image、SVG、Markdown、GeoGebra 等）统一通过 `next/dynamic({ ssr: false })` 按需加载，首屏零开销。
- 可复用的配置区段通过 `composer-field.tsx` 中的 `Field` 与 `CollapsibleConfigSection` 封装，所有 capability 配置面板遵循相同的折叠头部 + body 结构。
- UI 颜色与尺寸全部基于 CSS 变量（`var(--primary)`、`var(--muted-foreground)` 等）和 Tailwind 原子类，避免硬编码色值。
