本模块按功能域划分为三个并列子目录：`home/` 实现会话编排（Composer、消息列表、能力/模型/人设选择器、右侧活动与网页查看器），`preview/` 通过 `previewerFor.ts` 根据 MIME 类型路由到具体渲染组件并统一以滑出式 Drawer 承载，`space/` 提供空间入口菜单；顶层若干 Picker 组件（书籍、历史会话、Agent、问答库、人设、记忆）被 home 与 preview 共同复用，作为单轮对话中附加上下文的通用入口。三者之间不直接互相 import，而是由上层页面组合调用，形成“输入 → 上下文选择 → 消息渲染 → 附件预览”的单向数据流。
