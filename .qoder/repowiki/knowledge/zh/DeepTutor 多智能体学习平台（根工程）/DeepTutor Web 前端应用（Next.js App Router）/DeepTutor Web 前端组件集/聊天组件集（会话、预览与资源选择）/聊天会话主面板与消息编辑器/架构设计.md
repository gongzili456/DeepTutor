模块以 `ChatComposer.tsx` 为顶层编排组件，组合 `ComposerInput`（带 @mention 与 `/persona` 斜杠命令）、`AgentSelector`、`KnowledgeSelector`、`ModelSelector`、`PersonaSelector`、`ContextBudgetChip`、`CapabilityConfigCard` 等子选择器，并通过 `ContextReferenceTree` 统一展示书籍、笔记本、历史会话、问题库、记忆文件等引用；发送按钮受 `capabilityNeedsConfig` / `isStreaming` 状态门控，必要时通过 `prefillInputRef` 反向注入文本到输入框。

`SessionViewerPanel.tsx` 提供浏览器风格的右侧面板：用 `ViewerTab` 联合类型区分 file/web/quiz-followup/geogebra/subagent 五种 tab，通过 `forwardRef` + `useImperativeHandle` 暴露 `openFileTab/openWebTab/openQuizFollowupTab/openGeogebraTab/openSubagentTab/focusActivityHome` 等命令式 API；面板宽度通过 CSS 变量 `--viewer-width` 在拖拽时直接写入 DOM，避免 React 重渲染抖动；各预览内容通过 `next/dynamic` 懒加载 PDF/Image/SVG/Markdown/Docx/Xlsx/OfficeText/Fallback 等预览器。

`SessionActivityPanel.tsx` 作为 Activity Home 承载工具使用、知识基、Space 引用与附件卡片，并复用 `buildSessionActivity` 从 lib 层聚合数据；`ChatMessages.tsx` 负责消息气泡、附件内联、AskUserOptions、TracePanels 及流式事件渲染。

依赖方向单向向下：composer → selector/input → shared UI；viewer panel 仅消费 `UnifiedChatContext` 与 `lib/session-activity` 数据，不反向影响 composer。
