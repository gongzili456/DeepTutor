- 所有组件顶部标注 "use client" 以声明为客户端组件。
- 可复用 UI 组件统一暴露 `collapsed?: boolean` 属性，分别渲染紧凑图标版与展开文本版两种样式。
- 通过 `useTranslation()` 的 `t(...)` 函数对所有用户可见文案进行 i18n 处理，包括 aria-label、title 和提示文本。
- 需要鉴权的组件先通过 `useAuthStatus()` 检查 `enabled` / `isAdmin` / `authenticated`，不满足条件时直接返回 null 隐藏自身。
- 访问控制采用 Context + Hook 模式：定义 `CapabilityAccessValue` 接口并通过 `createContext` 提供默认值，消费方统一通过 `useCapabilityAccess()` 获取。
- 对外部不可用场景使用显式的占位 UI（如 `LockedFeatureNotice`）而非静默隐藏，保证功能可见性并引导用户联系管理员。
