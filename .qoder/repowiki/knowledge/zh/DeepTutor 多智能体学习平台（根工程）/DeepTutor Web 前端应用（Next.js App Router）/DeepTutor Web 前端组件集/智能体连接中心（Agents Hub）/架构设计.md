模块由三个 React 客户端组件构成：`AgentsHub.tsx` 作为页面级组合器，并列渲染 `ConnectedAgents`（实时连接的本地 CLI/伙伴）和来自 `@/components/space/MyAgentsSection` 的历史导入智能体；`ConnectedAgents.tsx` 是核心业务组件，通过 `@/lib/subagents-api` 的 `detectSubagents`、`listSubagentConnections`、`connectSubagent`、`disconnectSubagent`、`listConnectablePartners` 等函数完成状态加载与操作，内部嵌套一个 `ConnectModal` 子组件处理新增连接的表单与校验；`agent-icons.tsx` 集中维护各后端（claude_code、codex、gemini、kimi、opencode、mimo、partner）的品牌 SVG 图标，并通过 `agentGlyph(kind)` 工厂按 kind 字符串解析出对应组件，供卡片与选择器复用。依赖方向单向：UI → subagents-api 与 space/partners 共享组件，图标模块无外部依赖。
