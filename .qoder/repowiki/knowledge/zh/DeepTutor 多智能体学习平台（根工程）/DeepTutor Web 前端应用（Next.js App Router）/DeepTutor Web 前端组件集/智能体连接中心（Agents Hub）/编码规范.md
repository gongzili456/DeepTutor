- 所有组件顶部声明 "use client" 以启用浏览器端交互与状态。
- 文案统一通过 `react-i18next` 的 `useTranslation` + `{ zh, en }` 对象形式进行中英切换，避免硬编码字符串。
- 对外部 API 调用使用 `Promise.all` 并行加载多类数据，并以 `.catch(() => [])` 降级空数组保证 UI 始终可渲染。
- 异步操作采用 `try/finally` 包裹 loading/busy 状态，确保无论成功或失败都恢复 UI。
- 品牌图标通过 `agentGlyph(kind)` 工厂按 kind 字符串返回对应 SVG 组件，未知 kind 返回 null 由调用方回退到通用 Cpu 图标。
- 用户确认型危险操作（如断开连接）先弹出 `window.confirm` 再执行，并在按钮上通过 `disabled` 与旋转 Loader2 反馈进行中状态。
