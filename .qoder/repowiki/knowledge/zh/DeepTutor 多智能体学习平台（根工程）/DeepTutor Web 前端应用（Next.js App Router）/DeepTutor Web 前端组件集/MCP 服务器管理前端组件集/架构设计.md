模块以 `surface.ts` 中的 `McpSurface` 接口为核心抽象，定义两种配置面：`ADMIN_MCP_SURFACE`（全量 registry 写、允许 stdio）和 `SPACE_MCP_SURFACE`（per-server 逐条写入、仅远程传输），所有业务组件通过该对象而非布尔 flag 区分权限与行为，新增场景只需新增常量。
- 顶层页面组件：`McpAdminRegistry.tsx` 作为管理员折叠面板入口，组合 `McpServerList` 与 `McpServerForm`；`McpCatalogBrowser.tsx` 实现分页搜索、分类/等级筛选、条目详情与安装流程。
- 列表与行：`McpServerList.tsx` 渲染服务器卡片并内嵌展开的 `McpToolList` 与编辑态的 `McpServerForm`；`McpServerRow.tsx` 负责单行展示、启用切换、删除与状态徽章。
- 表单与编辑器：`McpServerForm.tsx` 根据 `surfaceAllows` 动态显示 stdio 或远程字段，调用 `testMcpSurfaceServer` 进行连接探测；`KeyValueEditor.tsx` 复用键值对输入。
- 样式与状态：`styles.ts` 集中 13px 密度下的 input/select/label/chip 类名；`McpStatusBadge.tsx` 展示连接状态。
- 依赖方向单向向下：组件 → `@/components/mcp/surface` → `@/lib/mcp-api`（HTTP 请求）与 `@/lib/mcp-store`（校验/本地化工具），不反向引用上层路由。
