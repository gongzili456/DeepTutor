- 通过注入 `McpSurface` 常量（`ADMIN_MCP_SURFACE` / `SPACE_MCP_SURFACE`）在组件中区分部署级与用户级行为，避免使用 `isAdmin` 布尔分支。
- 表单字段统一采用 `inputClass` / `selectClass` / `labelClass` / `chipClass` 等集中定义的 Tailwind 类名，保持 13px 密度一致的视觉风格。
- 所有用户可见文案通过 `useTranslation().t(...)` 包裹，包括占位符、错误提示与按钮标签。
- 异步操作（保存、测试、安装）使用 `saving/testing/probing` 等本地状态配合 `Loader2` 旋转图标呈现加载态，并在 finally 中清理。
- 错误信息统一通过 `describeMcpError(err, t)` 转换后以红色边框区块展示，成功结果则以绿色区块列出检测到的工具数量。
- 服务端差异通过 `surface.writes === 'registry' | 'per-server'` 在 `loadMcpSurface` / `writeMcpSurface` / `testMcpSurfaceServer` 中集中分派，组件侧无需感知 API 形状差异。
