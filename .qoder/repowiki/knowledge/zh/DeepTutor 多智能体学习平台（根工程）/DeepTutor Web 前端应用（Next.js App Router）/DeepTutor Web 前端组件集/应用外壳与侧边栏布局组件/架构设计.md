模块分为两层：`layout/AppShell.tsx` 作为根壳，通过 `SidebarDrawerContext` 暴露 `close()` 能力，在 `<768px` 时将 sidebar 以遮罩+抽屉形式渲染，并在路由切换或 Escape 键时自动关闭；桌面端则以 flex row 并列展示 sidebar 与 main。`sidebar/SidebarShell.tsx` 是侧边栏骨架，维护展开/收起状态、PRIMARY_NAV/SECONDARY_NAV 配置表（含 `requires: Capability` 权限门控）、Recents 折叠持久化，并提供 `footerSlot` 插槽注入登录态相关按钮。`WorkspaceSidebar` 与 `UtilitySidebar` 是两种具体装配：前者接入 `useUnifiedChat` 管理会话列表、排序（running 优先）、重命名/删除/新建会话，后者仅做基础 session CRUD 并挂载 Profile/Admin/Logout。`BookRecent`、`CoWriterRecent` 为独立最近项组件，各自拉取数据并通过 `formatRelativeTime` 显示时间；`SessionAvatar` 用确定性哈希从固定图标集中挑选稳定头像；`VersionBadge` 用于版本标识。依赖方向单向：具体 Sidebar → SidebarShell → AppShell 的 drawer context；不反向引用业务页面。
