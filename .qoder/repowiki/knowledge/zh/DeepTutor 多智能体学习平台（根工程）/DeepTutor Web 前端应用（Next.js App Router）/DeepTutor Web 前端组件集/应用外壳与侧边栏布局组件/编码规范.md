- 导航项以声明式数组（`PRIMARY_NAV` / `SECONDARY_NAV`）定义 `href`、`label`、`icon`、可选 `tooltipKey` 与 `requires: Capability`，由 SidebarShell 统一渲染并做权限门控。
- 移动端侧边栏通过 `inert` + `translate-x-full` 实现不可见即不可聚焦，配合遮罩点击与 Escape 键关闭，避免 JS 未就绪时的交互泄漏。
- 侧边栏子视图（WorkspaceSidebar / UtilitySidebar）统一通过 props 向 SidebarShell 传入 sessions、activeSessionId、onNewChat/onSelectSession/onRenameSession/onDeleteSession，并以 `footerSlot={(collapsed) => ...}` 函数形式注入随收起状态切换样式的底部按钮。
- 最近项组件（BookRecent、CoWriterRecent）采用相同模式：本地 state 缓存、带取消标记的异步加载、按 `updated_at` 排序后 slice(limit)，并在 collapsed 模式下直接返回 null。
- 所有用户可见文案通过 `useTranslation().t(...)` 获取，包括 tooltipKey 与确认对话框，保证 i18n 一致性。
- 活跃路由判断统一使用 `pathname.startsWith(item.href)`，而非精确匹配，使 `/home/*` 等嵌套路由也能高亮对应菜单项。
