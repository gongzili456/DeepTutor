- 所有可写状态变更都通过 `mutateCatalog` 传入的不可变更新函数对 `draft` 副本进行修改，再在保存时整体提交，避免直接 mutate 全局 catalog。
- UI 偏好更新采用“先本地写 AppShellContext/localStorage，再异步 PUT `/api/v1/settings/ui`”的双写模式，保证即时生效与后端持久化一致。
- 多语言文案统一通过 `tr({ zh, en })` 或 `useTranslation().t` 获取，不在组件中硬编码中英文字符串。
- 服务类型通过 `ServiceName` 联合类型（llm/embedding/search/tts/stt/imagegen/videogen）约束，新增服务需同时扩展该类型及默认 catalog 构造器。
- 搜索 provider 的可见字段由 `search-providers.ts` 的声明式表驱动决定，而非在表单中硬编码条件分支，以保持前后端字段约定一致。
- 可复用的设置行/区块通过 `shared.tsx` 中的 `SettingRow`、`SettingSection`、`SettingsPageHeader` 组合，而不是在各页面重复实现相同布局。
