- 所有数据请求统一通过 `@/lib/api` 的 `apiFetch` + `apiUrl` 组合发起，URL 模板形如 `/api/v1/memory/doc/${layer}/${key}`，避免硬编码路径。
- 用户可见文本一律通过 `react-i18next` 的 `useTranslation` 返回的 `t()` 函数获取，包括按钮、提示、错误消息等。
- 重型子组件（如 MarkdownRenderer）使用 `next/dynamic` 配合 `{ ssr: false }` 进行按需加载，减少首屏体积。
- 长耗时后台任务通过 `useMemoryRun` Hook 暴露 start/cancel/undo/clear 接口，并在 localStorage 中以 `dt:memory:active-run:${layer}:${key}` 键持久化 runId 以支持刷新重连。
- SSE 事件流采用 `ReadableStream` + `TextDecoder` 缓冲，按双换行切分块后再匹配 `data:` 前缀行，解析 JSON 时忽略异常块以保证鲁棒性。
- Surface 集合（chat/notebook/quiz/kb/book/partner/cowriter）在多处（导航数组、类型定义、常量）集中声明并保持同步，新增 surface 需同时更新这些位置。
