模块以 React 客户端组件形式组织，围绕三层记忆模型（L1 工作区镜像、L2 按 surface 摘要、L3 跨 surface 综合）划分职责：
- 入口与导航：`MemoryHub.tsx` 作为总览页，聚合 overview 与各 surface 的 snapshot 计数，并以卡片形式引导到 /memory/l1、/memory/l2、/memory/l3；`MemoryArchivedBanner.tsx` 用于 v1 归档提示。
- L1 工作区：`MemoryL1Workbench.tsx` 是 L1 专用页面，左侧 rail 枚举 `SURFACES`（chat/notebook/quiz/kb/book/partner/cowriter），右侧复用 `MemorySection.tsx` 中的 `L1View` 展示 snapshot/changes/kb queries，并通过 `focusRef` 支持从 L2/L3 文档跳转定位实体。
- L2/L3 工作区：`MemoryWorkbench.tsx` 是 L2/L3 通用工作区，根据 layer 选择不同导航表（L2_NAV/L3_NAV），中心区域渲染 Markdown 预览（通过 `prepareDocForRender` 将 `surface:id`、`m_<ULID>`、裸 surface 名改写为跨层链接或本地锚点），并提供行号视图与原始编辑模式；右侧嵌入 `MemoryRunPanel` 执行 LLM 任务。
- 共享内容面板：`MemorySection.tsx` 是大屏内嵌版，包含 TabStrip（L1/L2/L3）、DocList、DocPane、StreamPanel 以及 L1 子视图（SnapshotList/ChangesList/KbQueriesList），被 `MemoryL1Workbench` 和外部 Space 页面复用。
- 运行状态与事件流：`useMemoryRun.ts` 是核心自定义 Hook，封装 run 生命周期（start/cancel/undo/clear）、通过 `/api/v1/memory/runs/{id}/events` 的 ReadableStream SSE 解析事件序列（seq 去重、cursor 推进），并用 `localStorage`（`dt:memory:active-run`）持久化 runId 实现页面刷新后重连；`MemoryRunPanel.tsx` 消费该 Hook，将事件分组为 turn 卡片（llm_io_start/delta/end + system 事件），并提供 budget/iterations/LLM 模型选择器。
- 依赖方向：UI 组件 → `useMemoryRun` Hook → `@/lib/api`（`apiFetch`/`apiUrl`）→ 后端 `/api/v1/memory/*`；Markdown 渲染通过 `next/dynamic` 懒加载 `@/components/common/MarkdownRenderer` 以避免 SSR 开销；所有文案经 `react-i18next` 的 `t()` 国际化。
