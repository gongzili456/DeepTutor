- 所有组件均标注 `'use client'` 并在模态中通过 `PickerShell` + `PickerHeader` 包装，保持统一的弹出面板外观与无障碍属性（`labelledBy`）。
- 跨组件共享的笔记本选择状态集中在 `useNotebookSelection` 钩子中，UI 组件只通过 props 传递状态与回调，不直接调用 notebook API。
- 异步操作采用 try/catch + finally 模式管理 loading 状态（如 `loadingNotebooks`、`loadingRecordsFor`），错误统一 `console.error` 输出。
- 集合类状态（已展开笔记本、正在加载的笔记本、选中记录）统一使用 `Set<string>` 或 `Map<string, ...>` 以保证 O(1) 查找与不可变更新（通过 new Set/Map 构造新实例）。
- 用户可见文案一律通过 `useTranslation().t(...)` 获取，包括按钮标签、空状态提示与 SSE 错误消息。
- SSE 事件流通过本地 buffer 累积并按最后一个 `\n\n` 切分后再逐条 `JSON.parse` 解析，避免中间不完整分片导致解析失败。
