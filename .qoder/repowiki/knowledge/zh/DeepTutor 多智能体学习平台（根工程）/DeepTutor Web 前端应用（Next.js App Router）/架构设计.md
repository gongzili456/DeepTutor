以 `app/` 下的 Next.js App Router 作为页面入口，按 `(auth)`、`(workspace)`、`(utility)`、`(admin)` 四个路由组划分权限域；根 `layout.tsx` 在 `<AppShellProvider>` 中包裹 `<I18nClientBridge>`，使所有子路由共享全局 Shell、主题与国际化上下文。业务 UI 集中在 `components/`，按 chat/knowledge/memory/settings/space/mcp/partners 等业务域组织，并通过 `context/` 中的 `UnifiedChatContext`、`AppShellContext` 等跨页面共享状态。数据访问统一收敛到 `lib/` 下的 API 封装（如 `session-api.ts`、`knowledge-api.ts`、`mcp-api.ts`、`book-api.ts`），被各组件与 hooks 复用。多语言由 `i18n/` 提供 Provider 与客户端桥接，翻译资源位于 `locales/`。构建与开发流程由 `scripts/` 中的 Node 脚本驱动（dev、build、i18n 审计、品牌图标生成、路由体积预算检查），测试套件覆盖 Node 单元测试与 Playwright E2E 审计。
