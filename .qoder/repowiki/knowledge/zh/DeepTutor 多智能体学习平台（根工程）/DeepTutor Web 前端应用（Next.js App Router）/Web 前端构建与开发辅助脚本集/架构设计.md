该模块是一组独立的 Node/ESM CLI 脚本，按职责单一文件组织，无共享库：
- `dev.mjs` 作为 Next 开发服务器的包装入口，通过 `child_process.spawn` 启动 `next dev`，并基于 cgroup v2 内存限制与 `NODE_OPTIONS` 注入 `--max-old-space-size` 以控制渲染 worker 的 V8 堆上限。
- `build-brand-icons.mts` 在构建时读取 `simple-icons` 包与 `lib/brand-slugs.ts` 中的白名单，生成 `lib/brand-icons.generated.ts`（包含 `BRAND_ICONS`、`MCP_ICON_SLUGS`、`CLI_ICON_SLUGS`），将第三方 SVG 路径编译进产物。
- `i18n_audit.mjs` 与 `i18n_parity.mjs` 分别扫描 `app/`、`components/` 下的 `.tsx` 提取未翻译 UI 字面量，以及对比 `locales/en` 与 `locales/zh` 下 JSON key 的一致性，均通过 `process.exit` 返回非零退出码供 CI 使用。
- `route_budgets.mjs` 解析 `.next/server/app` 下的 `_client-reference-manifest.js`，计算各路由 chunk 总大小并与硬编码的 `ROUTE_BUDGETS_KB` 比较，用于防止路由体积膨胀。
- `probe-right-edge.mjs` 使用 Playwright 对本地页面截图右侧 70px 条带，检测水平滚动溢出。
- `run-node-tests.mjs` 调用 `tsc -p tsconfig.node-tests.json` 编译后，通过 `register-node-test-aliases.cjs` 劫持 `Module._resolveFilename` 使 `@/` 别名指向 `dist/node-tests`，再以 Node 内置 `--test` 运行 `*.test.js`。
依赖方向单向：所有脚本仅依赖 Node 标准库、Next 构建产物或 `simple-icons`/`playwright` 等开发依赖，不反向引用应用源码。
