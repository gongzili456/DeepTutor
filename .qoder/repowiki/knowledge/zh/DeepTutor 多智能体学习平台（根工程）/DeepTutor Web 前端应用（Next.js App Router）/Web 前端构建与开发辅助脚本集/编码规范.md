- 每个脚本独立承担单一职责并以 CLI 形式暴露，通过命令行参数（如 `--strict`、`--file`、`--show-all`）控制行为，而非配置文件。
- 脚本统一使用 `path.resolve(process.cwd())` 定位 web 根目录，再通过相对路径拼接 `app/`、`components/`、`locales/`、`.next/` 等子目录，避免硬编码绝对路径。
- 失败场景通过 `console.error` 输出诊断信息并以非零 `process.exit` 终止，便于被 npm script 或 CI 捕获。
- 文件遍历采用递归 `readdirSync` + 后缀过滤（`.tsx`、`.json`、`_client-reference-manifest.js`、`.test.js`）的模式，跳过 `node_modules`、`.next` 等目录。
- 相对路径输出统一通过 `path.relative(root, p).replaceAll('\\', '/')` 规范化，保证跨平台一致的文件名展示。
