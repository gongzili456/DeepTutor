- 页面级路由文件保持极简：`agents/page.tsx` 仅定义滚动容器与最大宽度，实际内容委托给 `@/components/*` 组件。
- 需要交互或浏览器 API 的页面统一在文件首行添加 `'use client'` 指令，并以 `useState/useEffect/useCallback` 管理本地状态。
- 所有用户可见文案通过 `react-i18next` 的 `t()` 函数包裹，避免硬编码字符串。
- 异步操作采用 try/catch 后静默忽略错误（catch 块为空注释），并通过 `loading`/`error`/`busy` 等状态驱动 UI 分支。
- 列表类页面使用 `pendingId` 标记当前正在操作的条目，配合 `disabled` 与透明度变化实现乐观更新与防抖。
- 样式统一基于 Tailwind CSS 自定义 CSS 变量（如 `var(--background)`、`var(--border)`、`[scrollbar-gutter:stable]`）而非固定色值。
