该模块由 Next.js App Router 的 `(utility)` 路由组中的四个并列子目录组成，每个子目录对应一个独立的工具页面：`agents/` 通过 `layout.tsx` 提供共享的 `main` 容器布局，`page.tsx` 仅作为壳并委托给 `@/components/agents/AgentsHub`；`knowledge/page.tsx` 与 `notebook/page.tsx`、`profile/page.tsx` 均为客户端组件（顶部声明 `'use client'`），直接内联业务逻辑并通过 `@/lib/*-api` 模块调用后端接口。其中 `notebook/page.tsx` 使用 `next/dynamic` 以 `ssr: false` 懒加载 Markdown 渲染器，并用 `Suspense + Loader2` 包裹以处理流式加载；`profile/page.tsx` 在 `useEffect` 中先校验认证状态再重定向到 `/login` 或首页。四个页面均遵循“路由页只负责布局与状态编排，UI 细节下沉到 `@/components/*` 与 `@/lib/*`”的分层约定。
