本模块作为设置中心的顶层路由集合，由 layout.tsx 提供 SettingsProvider 状态上下文与 SettingsMain 侧边栏/导航外壳，并在根 page.tsx 渲染 SettingsHub 入口；各子目录（agents、appearance、attachments、capabilities、chat、document-parsing、embedding、image、llm、mcp、memory、mineru、models、network、search、status、stt、tools、tts、video）各自以独立 page.tsx 暴露一个设置子页，所有子页共享同一份 SettingsContext 中的配置状态，从而在切换不同设置分组时保持全局配置一致。旧的状态页面通过重定向收敛到设置主页，形成单一入口。
