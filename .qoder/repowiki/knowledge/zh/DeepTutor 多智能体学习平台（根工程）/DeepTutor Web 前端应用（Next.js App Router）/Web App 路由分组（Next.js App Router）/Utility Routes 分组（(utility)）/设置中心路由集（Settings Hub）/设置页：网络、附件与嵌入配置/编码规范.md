- 每个设置页面以 `"use client"` 开头，通过 `apiFetch(apiUrl(...))` 调用 GET 加载、PUT 保存对应 `/api/v1/settings/*` 端点，并在响应非 2xx 时优先读取 `detail` 字段作为错误信息。
- 页面维护 `payload`（服务端快照）与 `draft`（本地草稿）两份状态，用 `normalizeDraft` 归一化后在 `useMemo` 中逐项比对计算 `dirty`，再经 `registerExtension('<key>', { dirty, save })` 暴露给全局 Settings 工具栏统一保存。
- 表单字段使用共享的 `SettingSection` / `SettingRow` / `inputClass` 组合呈现，数值输入通过服务端返回的 `bounds` 或常量限定 `min`/`max`。
- 异步副作用统一采用 `let cancelled = false` 配合 `useEffect` cleanup 标志，避免组件卸载后 setState 导致警告。
- 保存函数通过 `useRef` 持有最新 draft/corsText，使闭包中的 `save` 始终读取最新值，再由 `useCallback` 稳定导出供 `registerExtension` 使用。
