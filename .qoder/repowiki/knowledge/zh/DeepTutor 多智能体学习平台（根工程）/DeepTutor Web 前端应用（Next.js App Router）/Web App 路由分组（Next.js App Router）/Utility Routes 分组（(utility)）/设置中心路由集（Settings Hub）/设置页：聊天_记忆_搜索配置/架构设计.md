基于 Next.js App Router 的 `(utility)/settings` 路由组，每个子目录 `chat/`、`memory/`、`search/` 对应一个独立的 `page.tsx` 客户端组件（均声明 `'use client'`），通过共享的 `@/components/settings/shared` 中的 `SettingsPageHeader`、`SettingSection`、`SettingRow` 等 UI 原语渲染表单。
- `chat/page.tsx` 是纯门面，委托给 `SettingsSectionGrid` 按 `categoryKey="chat"` 动态加载通用设置区块。
- `memory/page.tsx` 自包含完整状态管理：通过 `apiFetch(apiUrl("/api/v1/memory/settings"))` 拉取并维护本地 `MemorySettingsDTO`，使用 `registerExtension("memory", { dirty, save })` 将脏检查与保存逻辑注册到全局 SettingsContext，支持撤销/确认式保存；字段控件 `NumberRow`/`ToggleRow`/`SelectRow` 在组件内定义并通过 `patch(key, value)` 局部更新嵌套 DTO。
- `search/page.tsx` 仅承载标题并复用 `ServiceConfigEditor` 通用服务配置编辑器，以 `service="search"` 接入。
依赖方向单向向下：页面 → 共享 settings UI 组件 → 底层 `@/lib/api` 与 `SettingsContext`，不反向引用其他设置页。
