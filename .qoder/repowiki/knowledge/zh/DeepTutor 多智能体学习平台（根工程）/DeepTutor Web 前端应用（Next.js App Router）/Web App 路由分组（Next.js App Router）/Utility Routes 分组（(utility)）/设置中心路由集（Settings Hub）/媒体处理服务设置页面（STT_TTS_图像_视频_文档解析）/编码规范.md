- 每个设置子路由的 `page.tsx` 都是单一默认导出的客户端组件，先渲染 `SettingsPageHeader` 再用 `useTranslation` 提供标题与描述文案。
- 简单服务配置页面统一复用 `ServiceConfigEditor` 并传入 `service` 标识符（stt/tts/imagegen/videogen），避免重复编写表单逻辑。
- 需要复杂交互的页面（如 document-parsing）通过本地 `useState` 管理 loading/error/busy 状态，并使用 `useCallback` 包装异步操作，最后用 `finally` 重置 busy。
- 可选功能以“可用/不可用”双态呈现：当后端返回 `available: false` 时渲染 `NotInstalledSection`，并提供一键安装按钮与 `PIP_HINT` 提示。
- 后台耗时任务统一通过 `useBackgroundJob` Hook 封装：POST 启动 → 定时轮询 status 接口获取增量日志 → 完成后回调刷新数据，支持 cancel。
- 所有用户可见字符串均通过 `react-i18next` 的 `t()` 包裹，包括错误消息、按钮标签与帮助说明，保证多语言可替换。
