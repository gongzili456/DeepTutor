- 每个子路由仅暴露一个默认导出的函数式组件作为页面入口，并在文件顶部声明 `"use client"`。
- 所有网络请求通过 `apiFetch(apiUrl("..."))` 发起，错误分支统一以 `t("Failed to ...")` 形式呈现给用户。
- 设置页通过 `useSettings().registerExtension(key, { dirty, save })` 向全局设置栏注册脏状态与保存动作，并在卸载时注销。
- 后端返回的数据在写入 state 前用自定义 `isValidXxxDTO` 守卫进行运行时结构校验，失败则设置 loadError 而非直接渲染。
- UI 文案全部经 `useTranslation().t(...)` 包裹，支持 zh/en 双语切换。
- 表单字段采用局部 patch 函数（如 `patchSimple`、`patchChat`、`patchResearching`）不可变地更新嵌套 settings 对象，再整体 PUT 回服务端。
