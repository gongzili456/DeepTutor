该模块基于 Next.js App Router 的 `(utility)/settings` 路由组组织：`layout.tsx` 作为共享布局，通过 `SettingsProvider` 注入全局设置上下文，并挂载一次性的 `SettingsTourOverlay` 以跨子路由维持引导覆盖层；`page.tsx` 是设置中心入口，渲染 `SettingsHub` 导航卡片；`appearance/page.tsx` 是客户端页面（`"use client"`），通过 `useSettings()` 读取/更新主题、语言、响应语言及代码块相关偏好，并使用 `shared` 中的 `SettingSection`/`SettingRow`/`Toggle`/`ThemePreviewCard` 等组件构建 UI，同时通过 `next/dynamic` 以 `ssr: false` 懒加载 `RichCodeBlock` 预览；`status/page.tsx` 仅做服务端跳转 `redirect("/settings")`，保留旧书签与引导回退路径。依赖方向单向向下：路由层 → `@/components/settings/*` 共享组件与上下文，不反向引用业务数据层。
