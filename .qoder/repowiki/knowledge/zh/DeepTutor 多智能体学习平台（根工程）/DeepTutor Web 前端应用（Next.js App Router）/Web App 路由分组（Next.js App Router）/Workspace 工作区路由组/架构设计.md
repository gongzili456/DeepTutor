通过 `layout.tsx` 在 `(workspace)` 路由组根层注入 `AppShell`（含 `WorkspaceSidebar`）、`CapabilityAccessProvider`、`UnifiedChatProvider` 与 `CapabilityGate`，使所有子页面共享同一应用外壳、侧边导航与权限/聊天上下文；`page.tsx` 作为 `/` 入口将带 `session`、`capability`、`tool` 查询参数的旧链接重定向到 `/home/[sessionId]`，实现向后兼容。各子模块（book、co-writer、partners、playground、home）以并列目录形式挂载在该布局下，彼此解耦，仅依赖父级提供的共享上下文与 UI Shell。
