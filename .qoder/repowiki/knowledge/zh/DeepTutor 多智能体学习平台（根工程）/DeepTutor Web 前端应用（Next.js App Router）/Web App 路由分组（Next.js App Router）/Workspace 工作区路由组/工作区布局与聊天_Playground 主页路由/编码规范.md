- 页面级组件统一标注 `"use client"` 并在顶部集中声明 React hooks 与第三方库导入，保持客户端逻辑与布局层分离。
- 通过 `AbortController` + `ref` 模式管理长连接请求的生命周期，在组件卸载或切换时调用 `abort()` 避免悬挂请求。
- 对 SSE 响应采用统一的 `event:\n\ndata:` 分块解析：用 `TextDecoder` 累积 buffer，按 `\n\n` 切分后分别匹配 `event:` 与 `data:` 行再 `JSON.parse`。
- 能力/工具的图标与文案通过顶层 `Record<string, LucideIcon>` 与 `Record<string, string>` 映射表集中维护，并提供 fallback 回退到通用图标/标题函数。
- 需要用户确认的配置型能力（Quiz/Visualize/Research）采用「编辑即失效确认」模式：修改任一字段将重置 `capabilityConfigConfirmed`，发送前必须显式点击 Confirm。
- 重型 UI 组件（NotebookPicker、HistorySessionPicker、各类 ConfigPanel 等）一律通过 `next/dynamic` 配合 `{ ssr: false }` 懒加载，减少首屏包体积。
