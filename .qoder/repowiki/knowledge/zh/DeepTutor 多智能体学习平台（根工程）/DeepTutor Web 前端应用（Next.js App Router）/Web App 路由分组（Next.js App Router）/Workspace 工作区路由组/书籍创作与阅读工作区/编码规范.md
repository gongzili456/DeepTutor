- 每个区块类型独立一个 React 组件文件置于 `components/blocks/`，由 `BlockRenderer` 基于 `block.type` 进行 switch 分派渲染。
- 新增可插入或可转换的块类型需同步维护 `INSERTABLE_TYPES` 与 `CHANGEABLE_TYPES` 两个常量数组，保持 UI 菜单与编辑器能力一致。
- 长耗时操作通过 `bookApi` 传入 `handleBookOperationEvent` 回调，将 `BookWsEvent` 统一送入 `useReducer(reduceBookEvent)` 驱动 `BookProgressTimeline` 展示进度。
- 所有用户可见文案通过 `useTranslation().t(...)` 获取，包括按钮、提示、错误消息和块类型名，确保多语言一致性。
- 异步副作用统一使用 `try/finally` 包裹 loading 状态（如 `creating`、`confirmingProposal`、`compilingPageId`），并在 finally 中刷新详情或重置状态。
- 树形选择（笔记本、问题、聊天会话）复用统一的 `ParentMap<P, C>` + `{ mode: 'all' | 'subset', ids }` 结构，配合 `toggleParent`/`toggleChild` 泛型函数处理全选/部分选/反选。
