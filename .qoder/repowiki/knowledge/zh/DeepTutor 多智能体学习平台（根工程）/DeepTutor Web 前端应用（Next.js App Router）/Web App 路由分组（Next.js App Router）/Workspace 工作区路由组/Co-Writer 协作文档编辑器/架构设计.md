模块基于 Next.js App Router 的 `(workspace)` 路由组，包含两个页面：`page.tsx` 是文档列表页（CRUD 入口），`[docId]/page.tsx` 是单文档编辑器页（核心）。编辑器采用左右分栏布局（editor/preview），通过 `localStorage` 持久化分割比例与滚动同步开关；内容变更经防抖（1500ms）调用 `updateCoWriterDocument` 自动保存到后端，并写入 `localStorage` 作为草稿缓冲以防刷新丢失。AI 编辑通过 `apiFetch` 直接 POST 到 `/api/v1/co_writer/edit_react/stream`，以 SSE 流式接收 `tool_call` / `tool_result` / `content` 事件并在选择浮层中展示 trace。编辑器内置撤销/重做栈（最多 50 条）、标题行内编辑、Markdown 工具栏、下载 `.md`、保存至 Notebook 等能力。模板内容集中在 `sampleTemplate.ts`，由列表页新建和编辑器“加载示例模板”共享。跨组件状态通过 `@/lib/co-writer-events` 的 `notifyCoWriterChanged` 事件广播刷新。
