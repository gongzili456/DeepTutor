- API 调用统一通过 apiFetch(apiUrl(...)) 发起，并在响应非 ok 时通过 readError 解析 detail 字段后抛出 Error。
- 授权载荷中的白名单字段（enabled_tools、mcp_tools）使用 null 表示默认策略、空数组表示全部拒绝、字符串数组表示显式白名单的三态语义。
- UI 中对可选项的增删操作一律通过 setGrant(prev => { const next = structuredClone(prev); ... return next; }) 进行不可变更新。
- 列表项选择状态通过 useMemo 将数组转换为 Set（如 kbIds、skillIds、partnerIds）以提升查找性能。
- 所有可编辑控件在 loading 或 saving 状态下通过统一的 controlsDisabled 标志禁用，保证提交期间 UI 一致性。
- 保存状态使用四态枚举 SaveState = idle | saving | saved | error 驱动底部状态栏与按钮文案/图标的切换。
