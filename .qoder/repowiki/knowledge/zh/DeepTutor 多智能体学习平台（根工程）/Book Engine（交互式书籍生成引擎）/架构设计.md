模块以 `engine.py` 中的 `BookEngine` 为进程级入口，按五阶段流水线组织：Stage 1 Ideation（`agents/ideation_agent` 生成 `BookProposal`）、Stage 2 Spine（`SourceExplorer` 并行检索 + `SpineSynthesizer` 合成章节树与概念图）、Stage 3-4 Page Compilation（`compiler.BookCompiler` 驱动各 `BlockGenerator` 产出页面）、Stage 5 Progress（`models.Progress`）。`BookEngine` 维护每个 book 的 `_BookRuntime`（`asyncio.Queue` + worker task），实现前台高优先编译与后台队列串行处理；所有进度通过 `streaming.BookStream` 经 `StreamBus` 推送给前端。

数据层由 `models.py` 的 Pydantic 模型（`Book`/`Spine`/`Chapter`/`Page`/`Block`/`ExplorationReport` 等）定义，`storage.py` 提供基于 `book_{id}/` 目录结构的 JSON 持久化（manifest/spine/progress/inputs/pages/assets），使用原子写入保证一致性。

内容生成采用注册表模式：`blocks/base.py` 定义抽象 `BlockGenerator` 与全局 `BlockGeneratorRegistry`，各 block 类型（text/callout/quiz/figure/code/timeline/deep_dive/concept_graph 等）在各自文件中实现并通过 lazy import 注册到 registry；`_llm_writer.py`、`_prompts.yaml`（`prompts/en|zh/`）封装 LLM 调用与提示词模板，`_rag_helpers.py` 复用探索阶段的 `SourceChunk` 避免重复检索。

依赖方向单向：`engine → compiler → blocks/{base, *_}`，`engine → agents/*`，`* → models`，`* → storage`；`kb_health.py` 在页面 READY 后惰性刷新 KB 指纹检测漂移。
