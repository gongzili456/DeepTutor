模块以 `main.py` 中的 `FastAPI` 实例为唯一入口，通过 `lifespan` 钩子在启动时初始化 LLM 客户端、EventBus、Partner Manager、Cron、PocketBase 连接并完成 v1→v2 记忆迁移，在关闭时按相反顺序释放 MCP、LLM 池、Agentic 池等资源；`run_server.py` 使用 uvicorn 启动应用，处理 Windows 事件循环切换、端口读取、开发热重载排除目录以及 WS 帧大小配置。

路由按领域拆分为 `routers/` 下的独立模块（chat、auth、knowledge、sessions、tools、mcp_settings、voice、unified_ws 等），每个模块暴露一个 `router = APIRouter()` 并在 `main.py` 中集中 `include_router`，按 `/api/v1/<domain>` 前缀组织，并通过 `dependencies=[Depends(require_auth)]` 或 `require_admin` 实现统一的鉴权边界；WebSocket 路由因无法使用 FastAPI 依赖而在处理器内部调用 `ws_require_auth`。

静态文件通过自定义 `SafeOutputStaticFiles` 白名单校验后挂载到 `/api/outputs`，避免路径穿越；CORS 根据 `AUTH_ENABLED` 动态选择严格模式或允许任意 origin。

`utils/` 提供跨路由共享的基础设施：`progress_broadcaster` 单例按 KB 名广播进度、`task_id_manager` 与 `task_log_stream` 管理任务 ID 与日志流、`tool_options` 封装工具参数解析。

依赖方向单向向下：API 层仅依赖 `deeptutor.services.*`、`deeptutor.agents.*`、`deeptutor.multi_user.*` 等业务层，不反向被业务模块引用。
