模块由三个核心部分组成：
- `edit_agent.py`：定义 `EditAgent(BaseAgent)`，封装 `process`（rewrite/shorten/expand）与 `auto_mark` 两个异步入口；通过 `get_prompt` 从 `prompts/{en,zh}/edit_agent.yaml` 加载多语言提示模板，并借助 `BaseAgent.stream_llm` 流式调用 LLM；可选启用 `rag_search` 与 `web_search` 工具，结果以 JSON 文件落盘到 tool_calls 目录。
- `storage.py`：实现 `CoWriterStorage`，按 `documents/doc_{id}/manifest.json` 布局持久化文档，使用 Pydantic 模型 `CoWriterDocument`/`CoWriterDocumentSummary` 校验数据，并通过 `deeptutor.services.file_io.atomic_write_text` 保证原子写入；提供 CRUD、列表、预览生成及 `_derive_title`/`_build_preview` 等辅助逻辑，并通过 `get_co_writer_storage()` 按 workspace_root 缓存单例。
- `prompts/en|zh/edit_agent.yaml`：存放 system/action_template/context_template/user_template/auto_mark_system/auto_mark_user_template 等多语言提示模板，由 agent 在运行时按 `language` 参数选择。
依赖方向单向向外：agent → storage → path_service/file_io；agent 同时依赖 `deeptutor.runtime.registry.tool_registry`、`deeptutor.tools.rag_tool`、`deeptutor.tools.web_search`、`deeptutor.services.llm.clean_thinking_tags` 完成外部能力集成。
