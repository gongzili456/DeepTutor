本模块以 Next.js App Router 的目录即路由约定组织页面：`app/(workspace)`、`app/(auth)`、`app/(utility)`、`app/(admin)`、`app/(settings)` 等路由组各自携带 `layout.tsx` 注入对应的工作区/权限/日历上下文；根级 `app/layout.tsx` 通过 `AppShellContext` 统一挂载侧边栏、主题、i18n 与全局 UI 状态。

- 页面层（`app/**`）仅负责路由装配与布局组合，业务逻辑下沉至 `components/`（按功能域如 chat/knowledge/memory/partners/reading 等）、`features/`（跨组件特性编排）与 `lib/`（纯函数 API 客户端、状态机、协议解析）。
- 跨页面共享状态通过 `context/` 下的 React Context（AppShell、Reading、PageCustomization、GeogebraTab、QuizFollowup）暴露，配合 `shared/` 中不依赖 React 的通用类型与存储抽象。
- 数据契约集中在 `contracts/`，由 `scripts/generate-contracts.mjs` 生成 TypeScript 类型供所有子模块消费，保证前后端接口一致性。
- 国际化通过 `i18n/` + `locales/` 集中管理，ESLint 插件 `eslint/i18n-plugin.mjs` 校验键值完整性。
- 构建与开发脚本位于 `scripts/`，统一处理品牌图标生成、PDF.js 资源拷贝、locale 压缩、类型检查与测试运行。
