- `BlockRenderer.tsx` 是唯一的入口与调度中心：接收一个 `Block` 对象，先处理 `pending`/`generating`/`error` 三种状态，再通过 `switch (block.type)` 分派到对应的子组件（TextBlock、SectionBlock、CalloutBlock、QuizBlock、UserNoteBlock、FigureBlock、InteractiveBlock、AnimationBlock、CodeBlock、TimelineBlock、FlashCardsBlock、DeepDiveBlock、ConceptGraphBlock），未知类型回退到 `PlaceholderBlock`。
- 每个 `XxxBlock.tsx` 都是独立的无副作用展示组件，仅依赖 `@/lib/book-types` 的 `Block` 类型和 `@/components/common/MarkdownRenderer` 进行 Markdown 渲染，不直接调用 API；所有副作用（删除、移动、改类型、生成、测验作答、补充练习）通过 props 回调向上传递，由父级容器管理状态。
- `BlockBodyEditor.tsx` 提供可编辑正文的通用编辑器，仅在 `EDITABLE_BODY_TYPES = ["text", "callout"]` 且存在 `onUpdateBody` 时启用，用于对纯文本质块的行内编辑。
- 交互型块（如 `QuizBlock`）内部维护本地选择态并通过 `useEffect` + ref 去重上报，避免重复触发 `onAttempt`；`PlaceholderBlock` 用 `LABELS` 映射表给出 Phase 2 占位提示。
- 依赖方向单向向外：本模块只消费共享 UI（Tooltip、MarkdownRenderer、i18n）与类型定义，不被其他业务模块反向引用。
