- 客户端组件统一以文件首行 `"use client"` 声明，并通过 `next/dynamic` 懒加载重型子组件（如 NoteReview、NoteCompanion），且设置 `ssr: false`。
- 所有用户可见文案通过 `useTranslation().t(...)` 获取，包括按钮、占位符、错误提示与空状态说明。
- 对后端写操作（pin/delete/save）采用 try/catch 捕获 Error 实例并以 `err instanceof Error ? err.message : String(err)` 归一化为字符串后写入本地 error state。
- 每次成功修改文档后调用 `notifyCoWriterChanged()` 广播变更，再触发 `refresh()` 拉取最新列表，保持多视图数据一致。
- UI 骨架通过 `FeaturePage` 与 `PageHeader` 组合，并使用 `pageActionClass()` 生成统一的按钮样式类名。
