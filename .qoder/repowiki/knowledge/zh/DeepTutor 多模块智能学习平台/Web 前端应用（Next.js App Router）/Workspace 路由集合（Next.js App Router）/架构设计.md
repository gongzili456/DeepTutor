以 `layout.tsx` 作为所有子路由的共享外壳：自上而下依次包裹 `CapabilityAccessProvider` → `PageCustomizationProvider` → `WorkspaceRuntimeBoundary` → `CalendarRuntime` → `TaskBoardRuntime` → `ChatRuntimeProvider` → `ReadingProvider` → `AppShell`（含 `WorkspaceSidebar` 与 `LayoutPageBar`），最后用 `CapabilityGate` 守卫每个页面。根 `page.tsx` 统一重定向到 `/chat`，使该目录成为工作区的单一入口点。各子目录（`chat/`、`co-writer/`、`learning/`、`partners/`、`calendar/`、`kanban/`、`whisper/`）仅负责自身路由与页面，不重复挂载全局运行时；跨子模块的协作通过这些 Provider 暴露的上下文（能力访问、阅读状态、聊天会话、任务板、日历、页面定制）完成。
