本模块是 Next.js App Router 的 `(utility)` 路由组，按业务域拆分为 agents、memory、notebooks、space、knowledge-bases、profile、personalization、session-handoff、settings/progress 等子目录；每个子目录各自维护独立的 layout.tsx/page.tsx 作为客户端入口。

跨子模块的统一编排集中在顶层 `layout.tsx`：所有子页面共享同一份运行时外壳——`AppShell` + `UtilitySidebar` + `LayoutPageBar`，并通过 `CapabilityAccessProvider` / `CapabilityGate` 做能力访问控制，通过 `WorkspaceRuntimeBoundary` 注入工作区 store（注释说明切换 workspace 时会 remount 子树），并由 `CalendarRuntime` 提供日历能力。该布局对所有子模块一视同仁，因此 agents、workspace_utilities、settings 等子模块在 UI 壳层与权限/工作区上下文上保持一致。
