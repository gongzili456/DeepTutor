- 对外暴露的持久化 API 统一通过 `get_path_service().get_co_writer_*` 获取路径，避免硬编码磁盘布局。
- JSON 落盘一律经由 `_atomic_write_json` / `atomic_write_text` 原子写，防止崩溃导致文件损坏。
- 共享状态（如 `_storages` 单例、`_STORE_LOCK`、history 读写）通过模块级函数封装，类内部不直接持有全局变量。
- 错误场景抛出领域异常（`DocxConversionError`、`RevisionConflict`），而非裸 raise Exception。
- 重型第三方库（`python-docx`、`fcntl`/`msvcrt`）采用运行时 import，使主入口可被无该依赖的环境导入。
- 多语言文案集中在 `prompts/{en,zh}/` 下的 YAML 模板中，代码侧仅通过 `get_prompt(key)` 按 `self.language` 选择。
