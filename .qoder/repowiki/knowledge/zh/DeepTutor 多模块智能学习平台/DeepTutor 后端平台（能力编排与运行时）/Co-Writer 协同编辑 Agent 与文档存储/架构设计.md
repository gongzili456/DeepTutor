模块由四个职责清晰的子文件组成：
- `edit_agent.py`：继承 `deeptutor.agents.base_agent.BaseAgent` 的 `EditAgent`，封装 rewrite/shorten/expand/auto_mark 等编辑动作；通过 `gather_context` 在调用 LLM 前可选地拉取 RAG（含 PageIndex）或 web_search 上下文，并将工具调用结果以 JSON 落盘到 per-user tool_calls 目录；所有操作经 `append_history` 写入带裁剪上限的审计历史。
- `storage.py`：`CoWriterStorage` 基于文件系统 + manifest.json 实现文档 CRUD，使用进程内 `_STORE_LOCK` + 跨进程 `.write.lock`（fcntl/msvcrt）保证并发安全，并通过 `expected_revision` 实现乐观锁冲突检测；文档根路径通过 `PathService.get_co_writer_*` 解析到当前用户的 workspace 下。
- `docx_converter.py`：纯函数式 Markdown ↔ DOCX 转换器，`python-docx` 通过 `_docx_module()` 延迟导入以避免启动时加载 OOXML 栈；对上传的 .docx 做 ZIP 成员数/大小/压缩比校验，失败时回退到通用文本提取器。
- `prompts/en|zh/`：按语言分目录存放 system / action_template / context_template / auto_mark_* 等 YAML 提示词模板，由 `BaseAgent.get_prompt` 根据 `self.language` 自动选择。
依赖方向单向向外：本模块依赖 `deeptutor.agents`、`deeptutor.services.*`、`deeptutor.tools.*`、`deeptutor.notes.*`，不被同层其他模块反向引用。
