- 所有外部 ID（book_id/page_id）在落盘前经 `_safe_book_id` / `_safe_page_id` 校验，非法字符直接抛 `ValueError` 而非静默清理。
- JSON 读写统一走 `_read_json` + `_atomic_write_json`，读取失败返回 None 并记录 warning，保证旧数据或损坏文件不会中断流程。
- 长生命周期状态（Book、Spine、Page、Progress、Inputs、ExplorationReport）一律以 Pydantic model 序列化为 `.json` 文件，加载时再 `model_validate` 回对象。
- 异步工作流通过 `BookStream(stage=STAGE_*)` 发布结构化事件，并在关键节点调用 `storage.append_log(op=...)` 追加只读日志。
- 可配置行为集中在 dataclass（如 `CompilerOptions`、`_BookRuntime`）中，构造函数接受可选依赖注入（`storage`、`path_service`），未传入时使用 `get_*` 工厂获取默认实例。
