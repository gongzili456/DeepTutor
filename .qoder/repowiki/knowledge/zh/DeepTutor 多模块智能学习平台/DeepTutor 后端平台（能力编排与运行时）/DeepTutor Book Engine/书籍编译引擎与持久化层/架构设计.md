模块由三层组成，依赖方向单向自上而下：
- `engine.py` 中的 `BookEngine` 是进程级编排器，维护每个 book 的 `_BookRuntime`（`asyncio.Queue` + in-flight 表 + worker），串联 Ideation → Source Exploration → Spine Synthesis → Overview 注入 → Page Shell 创建 → 队列式编译等阶段；通过 `CONSECUTIVE_PAGE_FAILURE_LIMIT` 对 provider 级故障触发断路器暂停整本书。
- `compiler.py` 中的 `BookCompiler` 是被 `BookEngine` 委托的纯编译单元，负责按页规划（`SectionArchitect`）、按类型分发到 `BlockRegistry`、并发/顺序执行 block 生成、重试（指数退避）以及桥接段落注入；对外暴露 `compile_page` 供前台请求与后台 worker 复用。
- `storage.py` 中的 `BookStorage` 提供同步 API，所有写操作经 `atomic_write_text` 原子替换，目录布局为 `book_{id}/manifest.json, spine.json, progress.json, inputs.json, learning_captures.json, log.md, pages/{page_id}.json, assets/...`；通过 `get_book_storage()` 按 workspace root 做单例缓存。

边界约定：`BookEngine` 持有 `BookStorage` 并构造 `BookCompiler(storage=...)`，编译器不反向感知引擎；事件流统一走 `streaming.BookStream` 与 `event_hub`，不在本模块内广播。
