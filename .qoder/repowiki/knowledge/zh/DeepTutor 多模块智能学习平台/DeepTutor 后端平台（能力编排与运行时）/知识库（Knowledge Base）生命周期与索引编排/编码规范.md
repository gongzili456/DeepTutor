- 所有 JSON 持久化（`kb_config.json`、`.progress.json`、`.indexing-run.json`、`metadata.json`）统一通过 `deeptutor.services.file_io.atomic_write_json` 写入，避免并发读写产生半截文件。
- KB 类型常量集中在 `kb_types.py`，并通过 `is_connected_kb` / `external_root_of` / `supports_rag_retrieval` 等判别函数访问，禁止在业务逻辑中直接比较字符串字面量。
- 长耗时 I/O（文件哈希、RAG 调用）通过 `asyncio.to_thread` 切换到线程池执行，避免阻塞 FastAPI 事件循环。
- 面向用户的提示文本采用 i18next 风格的 `message_key` + `message_params` 模板（如 `"Processing documents with {{provider}} provider..."`），由前端 `t()` 渲染，后端只保留英文模板。
- 模块级重型依赖（`KnowledgeBaseManager`、`RAGService`、`ProgressTracker` 等）在函数体内 `import`，由 `__init__.py` 的 `__getattr__` 和类方法内延迟导入，避免包加载时的循环依赖。
- 外部资源变更（权限错误、目录不存在）统一包装为 `DataVolumePermissionError` 并通过 `format_data_volume_permission_error` 生成可读信息后重新抛出。
