- 新增功能以独立目录 + `modules/manifests/<id>.json` 声明的方式注册，禁止直接 import 业务模块而绕过 manifest 校验。
- 对外暴露的能力统一实现 `core.capability_protocol.TurnCapability` 接口并通过 `capability_registry` 注册，而非被其他模块直接引用。
- 跨模块通信使用 `core.stream.StreamEvent` + `events.event_bus.EventBus` 发布结构化事件，禁止跨进程直接共享对象。
- 所有 LLM 调用与工具执行均通过 `services.llm` 与 `tools` 层的工厂/注册表访问，禁止在各业务模块内硬编码 provider 客户端。
