- 对可能产生循环引用的第三方模块（如 `ChannelManager`、`TurnEngine`、`KnowledgeBaseManager`、`get_event_bus`）采用函数体内局部 import，而非文件顶部导入。
- 配置字段通过 `PartnerConfig` dataclass 声明并在 `merge_config` 的 `_MERGEABLE_FIELDS` 元组中显式白名单，未列入的字段不可被 API 覆盖。
- 敏感字段（token/secret/password/api_key 等）在序列化时经 `mask_channel_secrets` 替换为 `***`，仅在 `include_secrets=True` 或 `mask_secrets=False` 时暴露原始值。
- partner id 与 soul id 统一走 `_slugify_id` → `slugify_partner_id`/`slugify_soul_id`，将非 ASCII 字符折叠为连字符，纯 CJK 名称回退到基于 SHA1 的稳定短标识。
- 磁盘写操作采用「临时文件 + replace」原子模式（`tmp_path.with_suffix(...).write_text(...)` 后 `.replace(path)`），保证 config.yaml 不出现半写状态。
- 对外暴露的类与常量集中在 `__init__.py` 的 `__all__` 中集中导出，模块使用者只依赖该包级接口而非内部子模块路径。
