- 脚本统一以 `from __future__ import annotations` 开头并使用 `argparse` 暴露命令行参数，根路径通过 `Path(__file__).resolve().parents[1]` 推导。
- 可复用的 CLI 输出通过 `_cli_kit.py` 中的 `banner`/`log_success`/`log_error` 函数集中处理，避免在各脚本中硬编码前缀。
- 模块元数据与依赖源单一地存放在 `deeptutor/modules/manifests/*.json`，`build_modules.py` 与 `sync_module_requirements.py` 共同消费该目录，禁止直接维护 requirements 或 wheel 清单。
- requirements 文件一律以 `# Generated by scripts/sync_module_requirements.py; edit module manifests.` 注释开头，并通过 `-r ../core.txt` 和 `-r <dependency>.txt` 的相对引用链组织。
- 构建产物通过 `pip wheel --no-deps --no-build-isolation` 在临时目录内完成，并在最后用 zipfile 遍历 wheel 内容校验文件归属，防止多模块覆盖同一路径。
