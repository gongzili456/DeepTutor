## 3. 每周验收清单

### 第 1 周

- [ ] 白纸画出九步链路并标注输入输出
- [ ] 解释 `emit` / `subscribe` / `stage`
- [ ] `mini_core` 正常与异常都输出稳定 `DONE`
- [ ] 闭卷默写 `UnifiedContext` 与 `StreamBus` 签名

### 第 2 周

- [ ] 模型真实调用新工具成功
- [ ] 关闭开关后 schema 消失
- [ ] 声明名集合 == 注册名集合的测试通过
- [ ] 能说出发现与分发两处校验的必要性

### 第 3 周

- [ ] 纯文本路径测试通过
- [ ] 一次工具调用路径测试通过
- [ ] 超轮次强制收尾测试通过
- [ ] 能解释能力层不直接调 LLM 的原因

### 第 4 周

- [ ] 三阶段能力在 CLI 可运行
- [ ] 非法配置被拒绝
- [ ] 终态含 `response` 与 `cost_summary`
- [ ] 取消后无「已完成」终态

### 第 5 周

- [ ] 同一 submission 只执行一次
- [ ] 重连可重放且不重复执行
- [ ] 取消后不再产生模型调用
- [ ] 能画出事件从能力到消费者的路径

### 第 6 周

- [ ] wheel 安装成功
- [ ] installed / approved / enabled 三态可区分
- [ ] 禁用后能力消失且无导入错误
- [ ] 能说出模块与插件的信任边界差异

### 第 7–8 周

- [ ] 空目录项目跑通一轮对话
- [ ] 具备工具调用与两条能力路径
- [ ] 具备落盘与重放
- [ ] 移植 solve 成功（不看原文件）
- [ ] 八道答辩题全部能答
