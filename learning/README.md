# 学习工作区

本目录是**个人学习档案区**，用于维护学习路线、每周进度、实验记录与答辩证据。

## 1. 隔离边界

| 位置 | 用途 | 约定 |
| --- | --- | --- |
| `learning/` | 学习计划、进度、笔记 | 只在这里写入；不参与打包、不被测试收集 |
| `/tmp/deeptutor-learning/` | 每周动手代码（`mini_core`、重建项目） | 仓库外，避免污染 checkout |
| `docs-for-dev/` | 产品与契约文档 | 学习期间只读，不因学习而修改 |
| `deeptutor/`、`web/` | 产品源码 | 默认只读；需要验证时用分支 |

三条硬规则：

1. **本目录不放可执行代码**。不放 `test_*.py`、不放 `__init__.py`，避免被 pytest 或打包工具误收集。
2. **实验不落地到仓库**。每周「造」的产物统一放在仓库外的工作区，仓库里只留结论与证据链接。
3. **不改写产品文档**。阅读中发现文档与代码不一致，记录到 `PROGRESS.md` 的「卡点」列，不改 `docs-for-dev/`。

> 注意区分：`learning/`（本目录，文档）≠ `deeptutor/learning/`（Mastery Path 学习引擎，产品代码）。

## 2. 目录结构

```text
learning/
  README.md          # 本文件：范围、规则、当前状态
  ROADMAP.md         # 学习路线：六周计划 + 两周重建
  PROGRESS.md        # 进度看板、每周清单、答辩记录
  notes/
    TEMPLATE.md      # 单周笔记模板
    week-01.md       # 按周创建，命名 week-NN.md
```

## 3. 每周流程

固定三次，比例 **读 : 追 : 造 ≈ 1 : 1 : 2**：

| 场次 | 时长 | 产出 |
| --- | --- | --- |
| 读 | 45–60 min | 一页笔记：这一层的输入 / 输出 / 失败路径 |
| 追 | 45–60 min | 一条真实事件序列 + 一张调用链表 |
| 造 | 90–120 min | 仓库外可运行代码 + 一个测试 |

每周收尾：

1. 复制 `notes/TEMPLATE.md` 为 `notes/week-NN.md` 并填写。
2. 更新 `PROGRESS.md` 的状态看板与验收清单。
3. 做一次闭卷默写；写不出的接口，标为下周复习项。
